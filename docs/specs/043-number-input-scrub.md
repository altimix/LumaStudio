# 数値入力欄の左右ドラッグ

Issue: #43

プロパティパネルのクリップ数値入力欄は、文字入力に加えて主ボタンの左右ドラッグで値を変更できる。通常のクリック、ダブルクリックによる全選択、Tab移動、数値入力、Enter確定は従来どおり動作する。フォーカスの有無にかかわらず、横方向の移動が3px以上かつ縦方向以上になったときだけスクラブを開始し、右で増加、左で減少する。フォーカス済みの欄も同じドラッグ操作で変更できる。未確定の入力がある場合は有効な値を先に確定し、採用値を開始点として1回分のドラッグ履歴を作る。2pxにつき各欄の `step` 1単位を適用し、`min` と `max` を越えない。

1回のスクラブは1回のUndo / Redoとして記録する。各中間値はジェスチャー開始時点の完全なプロジェクトから再構成し、短い長さへ一度移動してから戻した場合も、フェード、音量・不透明度キーフレーム、トランジションを失わない。開始値へ戻して終了した場合、上限・下限で値が変わらなかった場合、および3px未満のクリック操作では履歴を追加しない。素材の残り時間などにより要求値が正規化された場合は、スクラブ終了時に実際に採用された値を入力欄へ表示する。Escape、pointercancel、ウィンドウのフォーカス喪失、ページ非表示、コンポーネント破棄では、プロジェクト、履歴、選択中の音量ポイント、表示範囲を開始前へ戻す。終了したスクラブのイベント監視は残さない。

トラックがロック中の欄、無効化された欄、または別の編集ジェスチャー中は開始しない。リンク済み映像・音声の開始位置、素材の開始位置、長さ、再生速度は、スクラブの途中経過を含む全更新で同期を維持する。トランスフォーム、色、タイミング、音量、クロップ、基本マスクの共通数値欄で同じ入力部品を使用する。プロジェクト保存形式は変更しない。

## フォーカス中のUndo / Redo（#134）

クリップの数値欄・スライダーにフォーカスが残っていてもCtrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Yでプロジェクト履歴を操作する。入力途中のUndoは有効な値を確定してからその変更を戻し、Redoで復元できる。不正値・変化のない入力は表示を採用値へ戻し、前の無関係な変更を取り消さない。IME変換中、キーの連打、別のジェスチャー中は履歴を操作しない。文字原稿など通常のテキスト入力と、次に挿入する素材の既定設定は従来の入力操作を保つ。
