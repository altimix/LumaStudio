# 数値入力欄の左右ドラッグ

Issue: #43

プロパティパネルのクリップ数値入力欄は、文字入力に加えて主ボタンの左右ドラッグで値を変更できる。通常のクリック、文字選択、Tab移動、数値入力、Enter確定は従来どおり動作する。フォーカスされていない欄では、横方向の移動が3px以上かつ縦方向以上になったときだけスクラブを開始し、右で増加、左で減少する。既にフォーカスされた欄のドラッグはブラウザー標準の文字選択として扱う。2pxにつき各欄の `step` 1単位を適用し、`min` と `max` を越えない。

1回のスクラブは1回のUndo / Redoとして記録する。開始値へ戻して終了した場合、上限・下限で値が変わらなかった場合、および3px未満のクリック操作では履歴を追加しない。Escape、pointercancel、ウィンドウのフォーカス喪失、ページ非表示、コンポーネント破棄では、プロジェクト、履歴、選択中の音量ポイント、表示範囲を開始前へ戻す。

トラックがロック中の欄、無効化された欄、または別の編集ジェスチャー中は開始しない。リンク済み映像・音声の開始位置、素材の開始位置、長さ、再生速度は、スクラブの途中経過を含む全更新で同期を維持する。トランスフォーム、色、タイミング、音量、クロップ、基本マスクの共通数値欄で同じ入力部品を使用する。プロジェクト保存形式は変更しない。
