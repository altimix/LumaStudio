# YouTube制作スタジオ


## 編集と書き出し

新規プロジェクトでYouTube横動画（1920×1080、16:9）またはShorts（1080×1920、9:16）を選ぶ。共に30fpsで開始し、既存のシーケンス設定から変更できる。MP4にはそれぞれ明示したプリセットを設ける。Shortsは180秒以内を検証し、超過部分を暗黙に切り捨てない。縦型シーケンスを確認して書き出す。自動の人物追跡・リフレームはこの仕様には含まない。

## API設定と操作

- メインプロセスから固定の `https://api.openai.com/v1/` のみへ接続する。リダイレクトを許可しない。
- APIキーの直接入力とネイティブダイアログの.env選択。ユーザー設定はElectron safeStorageでWindowsユーザー用に暗号化する。設定済みかと利用元だけを返す。
- 初回のキー候補はOPENAI_API_KEY環境変数、明示されたLUMA_ENV_FILE、ポータブルEXEの隣またはアプリルートの.env、起動ディレクトリの.env。保存済み設定が優先し、解除後に.envのキーを勝手に復活させない。
- キーをプロジェクト、ビルド、ログ、AI生成プロンプトへ含めない。APIエラー本文をそのまま表示しない。401、403、429、通信失敗を日本語で表示する。
- 実行ボタンの周辺と設定画面で外部送信とAPI利用料を説明する。1ジョブずつ処理し、進捗、中止、通信タイムアウトを扱う。閉じた画面や別プロジェクトへ古い結果を適用しない。

## 日本語字幕

- 元素材の音声をタイムラインの順に、in点・速度・音量・フェード・ミュート・ソロを適用してミックスする。MP4と共通の音声フィルターを使う。
- 文字起こし本文はgpt-transcribe、時刻取得はwhisper-1。APIの分離と照合条件は016-japanese-transcription.md参照。用語ヒント120文字以内。16kHzモノラルWAVの300秒窓（各9.7MB程度）にし、前後1秒の文脈を付ける。単語の中点が属する区間で重複を除き、元のシーケンス秒へ戻す。最大12時間、6000字幕。
- 日本語の句読点を考慮した改行を入れる。通常は24文字、縦型は14文字を目安に2行、5秒までの単語群にまとめる。単語タイムスタンプがない場合はセグメントを分割し、区間内を按分する。認識と時刻は編集者が修正できる。
- 原稿の開始・終了秒、本文、検索/一括置換。SRT/VTT保存。字幕は任意の時点で専用トラックのテロップへ適用し、プレビューとMP4へ焼き込める。再適用は自動字幕タグを持つテロップのみを置き換え、通常のタイトルを維持する。ロックと2000クリップ/24トラック制限を尊重し、1回のUndoで戻す。
- 編集者が入力した改行をSRT/VTTとタイムラインの字幕に保持する。自動折り返しは入力された各行の中で行い、行を結合しない。
- 字幕ブロックを壊す先頭・末尾・連続改行による空行は、本文を修正するよう具体的に案内して拒否する。
- 再適用先は、以前の自動字幕があるトラックを名前より優先する。改名後や24トラック使用時も同じトラックを使い、ロック保護を維持する。
- 字幕や検索ワードの入力エラーを入力中に表示し、適用・保存・コピーを停止する。不正な入力からフォーカスを外した場合は、受理済みの値を欄へ戻し、未反映の文字を残さない。Shortsのシーケンス縦横比はメインプロセスでも検査する。

## 投稿素材

- 原稿からResponses API（gpt-6-astra、store=false、Structured Outputs）でタイトル3案、概要本文、チャプター、検索ワード10個、画像用プロンプトを作る。文字起こし内の命令に従わず、内容に根拠のある表現を指示する。
- 生成結果のタイトル・概要本文・章見出し・検索ワード・画像指示は空白だけの値を拒否し、再生成を案内する。拒否した結果で保存済みの投稿素材を置き換えない。
- チャプターは0秒から開始、3件以上、昇順、最後も含めて各10秒以上。短尺や条件不成立の場合は概要欄へ付けず、その理由を示す。投稿文は編集、個別/一括コピー、TXT保存できる。
- 投稿文・画像プロンプトの連続入力は、同じ入力欄からフォーカスを外すまでを1つのUndo履歴として扱う。長文の入力で文字ごとの履歴が増えない。
- Image API（gpt-image-2）で1536×864または864×1536、high品質、2MB未満のJPEGを1枚ずつ生成する。動画の参考画像と内容を使い、[104 サムネイル](104-youtube-thumbnails.md)に従う。プロンプトを編集し、画像を確認して保存する。生成した画像はユーザーデータ配下の素材として保持する。YouTubeへの自動投稿は行わない。
- optionalな `Project.youtube` に原稿と投稿素材、サムネイル素材IDを保存する。version 1の旧プロジェクトは引き続き読み込める。音声編集の変更検出キーが違う場合は時刻が古いと表示し、再認識前の字幕適用/投稿文生成を止める。画像をプロジェクトJSONへ埋め込まない。

## 検証

単体検証でタイムコード、チャプター条件、日本語の改行、字幕の容量/ロック/Undo、古い結果、APIエラーの秘匿、暗号化設定を確認する。実FFmpegでミックスと分割位置を確認する。Windowsの実ウィンドウではAPI応答のみを模擬して、設定→認識→字幕適用→保存/再読込→投稿文→画像保存→横/縦MP4までを検証する。CIでは実キーと課金APIを使わない。実API検証は別途、許可された.envと小さな日本語検証音声で行い、実行できない場合は未確認と記録する。

既存の正逆再生のPCM回帰検証も維持する。CIで検出した通常速度の補充遅延に対し、サンプル境界に合う実効1倍速の音声は短いPCMブロックへ直接ミックスし、毎ブロックのOfflineAudioContext生成を省く。速度変換・端数サンプルには従来の再サンプリング処理を使う。チャンネル・in点・境界・音量・フェードの一致を確認する。
