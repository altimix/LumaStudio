# モザイク・ガウスぼかしの数値欄を左右ドラッグで調整

Issue: https://github.com/altimix/LumaStudio/issues/99

動画・画像クリップの「ビデオ」にあるモザイクとガウスぼかしの中心 X・中心 Y・幅・高さ・粗さ／強さは、他のプロパティと同じ数値入力部品を使う。フォーカスしていない数値欄を左右にドラッグすると、2pxにつき0.1%ずつ値を変更する。開始条件、文字入力、Tab移動、Esc、ポインター中断は `043-number-input-scrub.md` に従う。各欄の既存の上下限と単位を維持する。

1回のドラッグは1回のUndo / Redoとする。途中の値は開始時点のプロジェクトから再構成し、開始値へ戻った場合は履歴と未保存状態を開始前へ戻す。トラックがロックされている場合、ほかの編集ジェスチャー中、またはエフェクトが無効の場合は変更しない。数値欄へフォーカスすると再生を停止し、入力する時刻を固定する。

この変更でモザイクをぼかしたり、ガウスぼかしの画質や保存形式を変更したりしない。範囲、プレビュー、写真保存、MP4書き出しの既存結果を維持する。
