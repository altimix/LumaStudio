# BGMの調整方法と右クリック音量調整

Issue #48。音量の調整場所を分かりやすくし、会話の後ろへ置くBGMを素早く小さくする。

- オーディオの「音声の自動調整 → 調整方法」に「BGM音量 −20 dB（10%） 会話中心・おすすめ」と「BGM音量 −15 dB（約17.8%） 音楽を少し大きく」を追加する。「音量を適用」で解析を行わず同じプリセットを適用する。会話の最適化／ノーマライズとその解除は従来どおり使える。
- 新しく追加するBGMとその試聴の初期音量を10%（−20 dB）にする。BGMパネルでは%とdBを併記する。既存プロジェクトの音量は保持する。
- −20 dBは会話中心の動画向けの出発点とする。元の曲ごとに音量が異なるため、声を聞きながら微調整する説明を表示する。これは相対的なクリップ音量であり、−16 LUFSのノーマライズや会話時の自動ダッキングとは異なる。

- タイムラインの右クリックの「BGM音量調整」に、−20 dB（10%）と−15 dB（約17.8%）を表示する。音声がない選択ではこのグループを表示しない。音楽用のトラック名やフォルダには依存せず、音声のあるクリップへ使用できる。
- クリップの音量100%を0 dBとし、倍率は `10^(dB/20)`。音量へ加算せず、この値へ設定する。現在の設定にチェックを表示し、同じプリセットを繰り返しても音量・履歴を変えない。
- 複数選択では音声だけに一括適用する。リンクした映像を選んだ場合は音声側へ適用し、映像の値は変えない。音声トラックが1つでもロックされていれば全体を変更しない。
- 位置・尺・速度・フェード・ミュート・会話処理・ノーマライズ・選択・再生ヘッドを維持する。音量の変更は1回のUndo/Redoにまとめ、通常のプロジェクト保存とプレビュー・書き出しへ反映する。
- 「音量を細かく調整」で対象の音声を選択し、右側の「オーディオ」プロパティへ移動する。従来の音量スライダーと%数値欄を使う。
- 右クリック、Shift+F10、矢印・Enter・Escape、小さいウィンドウ内でのメニュー操作を維持する。
- モデルで正確な倍率・複数選択・リンク・ロック・繰り返し適用・Undo/Redoを検証する。Windowsパッケージで右クリックとプロパティへの移動、保存再読込、プレビュー音声、実MP4の音量比と元ファイル保持を検証する。
