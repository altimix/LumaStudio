# 映像を見ながら字幕を編集

Issue: #55

YouTube制作スタジオの日本語字幕タブを左右に分け、左に既存の映像・音声プレビュー、右に字幕一覧を表示する。プレビューの再生エンジンは同時に一つだけ生成する。プレビュー上の素材移動・図形編集は無効とする。

字幕番号を押すと画面を閉じずにその字幕へ移動する。「前の字幕」「次の字幕」で一覧のページも追従する。「この字幕を反復再生」で選択区間を繰り返し確認できる。停止・タブ変更・閉じる・AI実行・不正な字幕入力で再生を止める。

プレビュー下に保存された編集中の字幕原稿を表示する。タイムライン映像への字幕反映は従来どおり「字幕をタイムラインに適用」で確定する。入力の確定・検証、保存、Undo/Redo、APIジョブ中止を維持する。

字幕の開始がタイムライン終端以降なら、反復ボタンを無効にして理由を表示する。字幕の終了だけが終端を越える場合は、再生できる部分を終端まで反復する。不正な入力を元に戻した直後の移動は一度止め、次の字幕移動は受け付ける。

反復区間は字幕適用と同じフレーム丸めを用いる。丸め後に1フレーム未満しか残らない字幕は反復しない。判定とループの開始・終了に同じ丸め後の時刻を使用する。

反復終了は区間の終了を含まない。時計の通知中に同期的に開始へ戻し、プレビューはシーク後の時刻を描画する。終端を越えた映像やシーケンス終端の黒フレームを反復時に挟まない。

動画の反復開始フレームをデコードしている間は、区間内の直前の合成映像を保持する。赤・緑・青に切り替わる実動画で字幕選択と各区間の反復を検証し、黒画面や次の区間の色が混ざらないことを画素で確認する。
