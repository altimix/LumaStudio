# YouTube投稿素材のコピーとGPT-6 Astra

Issue: #59

## 目的

タイトル・概要欄画面のすべてのコピーボタンからWindowsのクリップボードへ投稿文を渡す。投稿文生成の標準モデルは `gpt-6-astra` とする。

## 動作

- タイトル案ごとのコピー、チャプター付き概要欄、検索ワード、一括コピーで、クリック時点の編集済みデータを使う。入力欄からコピーへ直接移動しても、確定前の古い値をコピーしない。
- 有効なチャプターは時刻・見出しとともに概要欄へ含める。短尺など条件を満たさない場合の本文のみの出力と案内は維持する。
- 検索ワードはカンマ区切り、一括コピーはタイトル案・概要欄・検索ワード・サムネイル用プロンプトを含む。
- 成功はダイアログ内の常に見えるステータス領域に対象名と貼り付け方法を表示する。失敗はエラーを表示し、再試行・テキスト保存へ案内する。
- Windows版は送信元を検証する既存のIPCラッパーを通じた `copy-text` のみを公開する。Rendererへ読み取り機能や任意のElectron APIは公開しない。ブラウザー権限の拒否ポリシーも維持する。
- 空白のみ、文字列以外、NULを含む値、100,000文字超を拒否する。Windowsの改行表現を考慮して書き込み結果をメイン側で確認し、書き込み失敗・不一致を成功扱いしない。
- ブラウザー版は標準のClipboard APIを使用し、許可されない環境では同じ失敗案内を表示する。

## 投稿文モデル

- 標準モデルを正確に `gpt-6-astra` とし、API設定と投稿文画面にも表示する。
- Responses API、構造化JSON、`store: false`、出力上限6,000トークンを維持する。定型の投稿文生成には対応済みの `reasoning.effort: low` を指定する。
- 文字起こし・時刻照合・画像生成のモデルはこの変更の対象外。モデルの利用権限がない場合に他モデルへ自動変更しない。
- 公式仕様: https://developers.openai.com/api/docs/models/gpt-6-astra 、https://developers.openai.com/api/docs/guides/latest-model （2026-09-09確認）。

## 検証

- 境界の不正入力、Windows改行、書き込み例外・不一致、APIのモデルと構造化出力契約を自動検証する。
- Windowsの実画面から全コピーボタンを実行し、OS側のクリップボードと貼り付け結果を照合する。字幕・投稿文の保存データは保持する。
- ダイアログ内の成功・失敗、入力確定直後の内容、APIキー未設定、失敗後の再試行、不正な送信元を確認する。
- クリップボードのテストは元の内容をメモリー内に退避し、テストが最後に書いた内容が残っている場合だけ復元する。元の内容をログや成果物に記録しない。
- 再現可能なCIではOpenAI応答のみを模擬する。ユーザーの `.env` による実API確認は別途行い、キーやユーザー素材を成果物に含めない。
