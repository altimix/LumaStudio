# 初めての動画編集

Issue #21。素材を読み込み、並べ、編集し、保存とMP4書き出しを使い分ける流れを日本語で案内する。

- ヘッダーの「使い方」と「ヘルプ」から4段階のガイドを開ける。素材読み込み、文字追加、新規作成、書き出し、ショートカットに移動できる。
- 素材を選択後、常設の「選択素材をタイムラインに追加」ボタンで追加する。操作が拒否された場合は成功通知で上書きしない。
- 空のタイムラインは、素材の有無に応じて次の操作を案内する。検索結果がない場合は条件をクリアできる。
- Undo / Redo 後も、復元先に存在する選択クリップを選択したままにする。消えたクリップの選択は除く。
- 「長さ」「素材の開始位置」と表記する。文字サイズを見つけやすくし、影・縁取りは折りたたみ式にする。
- Windowsの画面からガイド→新規→読み込み→追加→調整とUndo→保存→書き出しを検証し、小さいウィンドウでも操作が隠れないことを確認する。
