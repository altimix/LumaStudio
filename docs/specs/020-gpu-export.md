# GPUによる動画書き出し

Issue: #20

書き出し方式は「自動（おすすめ）」「CPU」とGPUから選ぶ。対応候補はNVIDIA NVENC、Intel Quick Sync、AMD AMFのH.264エンコーダー。FFmpegの一覧だけで判定せず、標準設定で実際に3フレームをエンコードし、初期化できた方式だけを選択可能にする。検出は8秒で打ち切り、同時要求をまとめ、結果を1分間保存する。再確認も可能。

自動選択はNVENC、Quick Sync、AMF、CPUの順。自動でGPUエンコードに失敗したらCPUで最初から再試行し、切り替えを表示する。明示的に選んだGPUが利用できない場合は理由とCPUへの変更を案内する。中止や失敗では既存ファイルを変更せず、全処理成功後に一時出力を置き換える。

今回高速化するのは映像のH.264圧縮。文字・映像の合成、色補正、音声の処理にはCPUを利用する。この範囲を画面に明記し、全処理がGPU化したと誤認させない。標準／高画質／ドラフトは方式に適した品質制御へ変換する。MP4・AAC、トラック順、テキスト、正しい素材区間、フェード、音声自動調整は従来どおり。

検証は実機にある全対応方式でMP4を生成し、CPU出力とフレーム・音声・長さを照合する。GPUのないCIではCPUの実処理と、GPU検出失敗、途中故障のCPU再試行、明示GPUの失敗、中止、既存ファイル保持を検証する。実機確認できないベンダーを確認済みと表示しない。

参考: NVIDIA Video Codec SDK FFmpeg guide、FFmpeg同梱エンコーダーのオプション情報。
