# 現在のコマを写真として保存

Issue #28。

- プログラムモニターのカメラボタン「現在のコマを保存」で停止し、その位置を固定する。シーケンス末尾では最後のコマに戻す。
- テロップ、図形、色調整、変形、フェード、トランジションを含む編集結果を、既存プレビューと同じ合成処理でPNG/JPEGへ保存する。操作用のガイド、選択枠、バッジは含めない。
- 保存する瞬間だけプロジェクト解像度で合成し、元のプレビュー画質設定は維持する。通常のプレビューと同じ再生用素材を使うため、非対応コーデックから作られたプロキシの情報量を超える復元は行わない。
- デコード済みの現在フレーム、画像、フォント、トランジションの準備完了を待ってから画像化する。WebGLを使えない場合も、写真保存時のワーカー合成は640pxへ縮小せずプロジェクト解像度で処理し、その寸法の結果が届くまで保存しない。20秒で準備できない場合やプロジェクト・再生位置が変わった場合はエラーを表示する。
- PNG（初期値）とJPEG（品質95）を選べる。OSの保存画面でフォルダと名前を指定する。プロジェクト名と `HH-MM-SS-FF` で命名し、同名があれば `_001` などを付けた未使用の名前を提案する。日本語・記号・長い名前を安全なファイル名へ変換する。
- 「プロジェクトの素材にも追加」は開くたびにチェック済み。保存成功後のみ素材一覧へ追加する。タイムラインやロック中のクリップは変更しない。通常の素材追加と同様にUndo/Redoと保存・再読込に対応し、Undoで保存画像は削除しない。
- 保存中は二重操作を防ぐ。キャンセルでは保存・素材追加を行わない。オンライン・オフラインを問わず、読み込んだプロジェクトが保持する元素材のパスには上書きしない。写真の保存後に素材読込だけが失敗した場合は、保存済みのパスと手動読込の案内を示す。途中でプロジェクトが切り替わった場合は、同じIDのプロジェクトでも追加しない。
- メインプロセスで画像形式、PNGヘッダー・寸法、サイズ上限、保存先拡張子、保護対象素材を検証する。PNG/JPEGとして再エンコードし、一時ファイルを完成させてから置換する。

## フォルダの記憶

- 写真の保存先を、保存成功後にユーザー設定 `frame-save.json` へ記録する。
- 素材の読み込み先は独立した `import-folder.json` に記録する。選択・ドロップで正常に読み込めた最初のファイルのフォルダを使用し、キャンセルや全件失敗では変更しない。
- 次回起動後も記憶する。フォルダ削除・設定破損・読取不能の場合、写真はOSのピクチャ、素材は書類フォルダへ戻る。設定保存の失敗は写真保存・素材読込の成功と区別して通知する。
- プロジェクトファイルの形式は変更しない。

## 検証

- `tests/frame-save.test.cjs`: 命名・連番、キャンセル、素材追加失敗、上書き保護、失敗時の一時ファイル掃除、不正画像、二重実行、独立したフォルダ記憶とフォールバック。
- `scripts/verify-frame-save.cjs`: 実ElectronアプリでPNG/JPEGの寸法と画素、コマ送り直後のフレーム、図形、1/4画質からの保存、チェック初期値と解除、キャンセル、上書き拒否、Undo/Redo、ロックしたタイムラインの保持、保存・再読込、再起動後のフォルダ記憶。
- `verify:packaged` に組み込み、Windows/macOSの配布アプリでも実行する。
