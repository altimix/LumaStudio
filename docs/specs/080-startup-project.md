# 初期プロジェクトと素材の同梱（Issue #80）

> 1.0.0以降の配布版は [素材なしのクリーン配布](101-clean-distribution.md) に従います。以下は旧版の仕様です。

配布ZIPは実行ファイルと「初期プロジェクト」フォルダを含む。フォルダ内の初期プロジェクト.lumaはmedia配下の相対パスを使用し、元のDownloadsや開発PCのパスに依存しない。起動時はこのテンプレートを新しいプロジェクトID・未保存先の状態で読み込み、保存先を選んで別ファイルへ保存する。未保存編集の復元確認は引き続き表示する。テンプレートがない通常ビルドは既存デモで起動する。

フォルダ外への相対パス・絶対パス・リンク経由の逸脱は拒否する。不正テンプレートはエラーを通知してデモを表示する。ユーザー提供のプロジェクト・素材はGitへ追加しない。bundle-startup-project.cjsで新規フォルダへコピーし、コピー前後とコピー先のSHA256を照合する。コピー中に更新があれば失敗し、完成扱いにしない。manifest.jsonに元プロジェクトと同梱ファイルのハッシュを記録する。

Windowsテストでは元素材を削除し、同梱フォルダを別の場所に移してから起動する。編集と別保存ができ、テンプレートが不変であることを確認する。

起動時に読み込んだテンプレートと全同梱素材のパスを保持し、プロジェクト保存・動画書き出し・投稿素材保存で上書きを拒否する。素材一覧から削除した後や別プロジェクトを開いた後も、この保護はアプリ終了まで維持する。
