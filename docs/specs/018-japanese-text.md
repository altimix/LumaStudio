# 日本語テキストの配置と装飾

Issue: #18

ミニマルの新規テキストは画面中央に配置する。プロパティの位置は左上を原点とするピクセル座標で表示し、1920×1080では960・540、1080×1920では540・960になる。保存済みの位置は従来の画面中心からの割合を保持して互換性を維持する。

停止中のプレビューで文字をドラッグできる。中央付近ではスナップし、移動は1回のUndoで戻る。Esc・ポインターキャンセル・フォーカス喪失では位置とドラッグ分の履歴を戻す。再生中・非表示・透明・ロック中の文字は移動対象にしない。複数の文字が重なる場合は描画順と同じ順で操作する。

Google Fontsの2026-09-08時点の日本語対応68書体を提供する。標準のNoto Sans Japanese（内部名Noto Sans JP）はライセンスとともに同梱する。他の書体はGoogle公式配布元の固定カタログから初回取得し、ハッシュ検証付きのローカルキャッシュとライセンスを保存する。任意URLやファイルパスはIPCで受け付けない。可変フォントの範囲と静的フォントの提供ウエイトを区別する。

フォント・太さ・影の有無／色／ぼかし／距離・縁取りの有無／色／幅を選べる。フォントサイズと効果サイズはシーケンスのピクセル単位で、プレビュー倍率と出力解像度に合わせて拡縮する。読み込み失敗は説明と再試行を表示し、プレビューや書き出しで未取得フォントを黙って代替しない。自動字幕にも同じ装飾を使える。

検証: カタログの全書体・太さ・ライセンス、キャッシュの破損／オフライン／重複取得、不正設定、縦横の中央配置、ネイティブのドラッグ・Undo・キャンセル・ロック、保存再読込、CanvasとMP4の画素を照合する。

フォントはsfntテーブルの範囲・重なり・必須テーブル・各チェックサムを確認してから保存する。全画面でも編集レイヤーを実際の映像表示領域に一致させる。
