# 再生ヘッドの現在位置を秒数で表示

Issue: https://github.com/altimix/LumaStudio/issues/140

タイムライン左上の固定欄に「現在位置 12.345 秒」を常時表示する。下段には既存のタイムコード（時:分:秒:フレーム）を残す。シーケンスの先頭を0秒とする総秒数で、1時間を超えても分・秒へ折り返さない。

再生、停止、定規のクリック、再生ヘッドのドラッグ、キーボードによるフレーム移動で同じ再生ヘッドの値を使う。表示はシーケンスFPSのフレーム位置へ丸め、小数第3位までとする。再生状態やシーク先、保存形式は変更しない。

タイムラインのスクロール中も固定欄を表示する。数字は等幅とし、更新によって周辺の操作部品が動かないようにする。読み上げ用のグループ名を付けるが、毎フレームの読み上げ通知は行わない。

実アプリで24/30/60 fpsの1フレーム移動、クリックとドラッグ、順逆再生と停止、長尺シーケンス、小さいウィンドウとスクロール中の表示を確認する。
