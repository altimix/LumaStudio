# タイムライン操作性（Issue #78）

- 下・右のスクロールバーは22px幅。中央でスクロール、両端の丸で時間ズーム／全トラック高さ64〜180pxを変更。ビュー変更は編集履歴に含めない。Esc・ポインター中断で元へ戻る。
- 範囲スライダーのつまみ20px、一般スクロールバー16px。
- 音量は保存済みの基本音量×カーブ倍率の実効値を表示。点のないラインは全体の音量0〜200%、点のあるラインは0〜400%。丸選択中のプロパティはその点、選択がなければ再生ヘッド位置を編集。他の点の実効音量を保持する。
- 丸は選択時に両端を表示。左右ドラッグ／←→は時刻（1フレーム、Shift併用10フレーム）、上下／↑↓は実効音量（1%、Shift併用10%）。隣点を越えない。Deleteは点だけ削除。Undo/Redo、ロック、保存、再生・書き出しの既存カーブ形式を維持。
- Altを押してドラッグを開始すると選択グループとリンク相手を新しいIDで複製。元素材を保持。1回でUndo、Escで取消。通常クリックでは複製しない。ロックと2000クリップ上限を維持。
- 吸着は移動グループの全始点・終点と、他素材の始点・終点／マーカー／再生ヘッド／0秒を比較する。フレーム丸めと吸着成功を区別し、負の開始時刻を作らない。
- 音量や点の位置が限界に達した後のキー・ドラッグ操作で、値が変わらない場合は未保存状態やUndo履歴を増やさない。ドラッグして元のカーブ・点の位置へ戻した場合も操作前の履歴と保存状態を保つ。
- 隣接点との最小間隔でも、選択した点の時刻を厳密に照合してプロパティの音量を適用する。プロパティ音量スライダーも開始時の状態を保持し、元の値への復帰・Esc・ポインター中断では不要な履歴を残さない。
- ポイント未選択のプロパティ音量編集は、再生ヘッド位置へ点を追加できる。元の補間音量へ戻した場合はカーブ全体を比較して余分な点を残さず復元する。タイムライン上で意図的に点の時刻を変える編集は保持する。
