# ベジェペンマスク

Issue: #41

## 目的

映像・画像クリップを、モニター上で作成した閉じたベジェパスに沿って非破壊で切り抜く。長方形・楕円マスクと同じく、元素材は変更しない。

## 操作

- プロパティの「マスク > 形」で「ベジェペン」を選ぶ。
- 「モニターでマスクを編集」を有効にし、素材上をクリックして点を追加する。最大32点とする。
- 3点以上で「パスを閉じる」を押すとマスクが有効になる。開いた作成途中のパスは保存できるが、映像を切り抜かない。
- 閉じたパスは「パスを開いて点を追加」で再び編集途中にできる。
- 点は「直線」または「曲線」。曲線点には入力・出力ハンドルを表示し、片側を動かすと反対側も点を中心に鏡映して滑らかさを保つ。
- 点とハンドルはドラッグで移動できる。点の削除後に3点未満になった場合は自動的に開いたパスへ戻る。
- 1回のドラッグは1回のUndo / Redoとし、`Esc`、ポインターキャンセル、ウィンドウ失焦、非表示化では開始前へ戻す。
- ロック中のトラックでは操作ハンドルを表示せず、変更しない。
- 境界のぼかし、内側・外側の反転、クロップは既存マスクと共通に合成する。

## 保存形式と検証

`clip.videoMask` に次を保存する。

```ts
type BezierVideoMask = {
  type: 'bezier'
  points: {
    x: number; y: number
    inX: number; inY: number
    outX: number; outY: number
    kind: 'line' | 'curve'
  }[]
  closed: boolean
  feather: number
  inverted: boolean
}
```

- 点の座標は素材に対する正規化座標 `0..1`。制御ハンドルは画面外の曲線も扱えるよう `-1..2`。
- `feather` は `0..0.5`、`inverted` は真偽値。
- 32点を超える配列、不正値、閉じた状態で3点未満の配列はRendererとメインプロセス双方で拒否する。
- 既存プロジェクトの `videoMask` が未指定、長方形、楕円の場合は従来どおり読み込む。

## プレビューと書き出し

- 共通コードでベジェ曲線を平坦化し、最大長辺512pxの8bitアルファマットを作る。
- プレビューはこのマットを元の映像アルファへ `destination-in` で乗算する。
- 書き出しは同じマットを一時PGMとして生成し、素材と同じアスペクト比で拡大して元のアルファへ乗算する。一時ファイルは成功・失敗・中止を問わず削除する。
- クロップ、パス、ぼかし、反転をマット生成時に合成する。回転、不透明度、フェード、トランジションは既存の後段処理を維持する。
- 開いたパスはクロップ以外を変化させない。

## 受け入れ確認

- 点追加、閉じる／開く、点移動、直線／曲線、制御ハンドル、削除が動作する。
- 保存・再読込、Undo / Redo、`Esc`取消、トラックロックが動作する。
- 不正・過大な点列を保存・書き出し境界で拒否する。
- 元アルファを持つ画像で、ベジェマットが既存アルファを上書きせず乗算される。
- 開発版とパッケージ版で、プレビューとH.264書き出しの代表フレームを画素比較する。

複雑な髪、モーションブラー、半透明素材での自然さは技術的な画素一致とは別の目視品質ゲートとし、このIssueだけでAdobe Ultraキー相当とは表現しない。

## 修飾キーと選択（Issue #52）

- モニター上部の「ペン」「ダイレクト選択」で切り替える。ペンではクリックで直線点、ドラッグで対称ハンドルを持つ曲線点を追加する。最初の点をクリックすると3点以上のパスを閉じる。
- ペンのShiftクリックは直前の点から水平・垂直・45度刻みに配置する。Shiftドラッグはハンドルの角度を45度刻みに制限する。素材の縦横比や回転にかかわらずモニター上の角度を基準とする。
- ダイレクト選択のShiftクリックは点を追加選択する。選択点をドラッグするとハンドルも含めて同じ移動量で平行移動する。Shiftで移動方向を45度刻みに制限し、境界では選択全体を止める。
- Ctrl（MacはCmd）を押している間は一時的にダイレクト選択になる。離すとペンへ戻る。押したまま入力欄へフォーカスを移して離した場合も解除する。Ctrl/Cmd＋空白クリックは選択を解除してダイレクト選択へ移り、描画を終了する。開いたパスは開いたまま残り、ペンへ戻すと続けられる。
- ハンドルは通常は点を中心に鏡映する。Alt（MacはOption）中は反対側を固定する。途中でAltを押した場合は押した時点の反対側を保つ。Shiftと併用でき、押下・解除はマウスを動かさずに反映する。
- 点追加とそのハンドル作成は1回のUndo / Redo。複数点の移動も1回とし、選択やツール切替だけでは履歴を追加しない。Esc・ポインターキャンセル・失焦・表示領域変更・シークはジェスチャーを取り消す。
- 選択状態とツールは保存しない。非対称ハンドルは既存の入力・出力座標のまま保存し、旧プロジェクトと互換を保つ。
- ペンで始点の画面上10px以内に近づくと始点と「パスを閉じる」を強調し、クリックで閉じる（3点以上）。Ctrl/CmdやShiftの選択操作では閉じない。
- 開いたパスの終点だけを始点の10px以内へドラッグして離すと、終点を始点へ統合して閉じる。重複点を残さず、始点の出力ハンドルと終点の入力ハンドルを保つ。閉じた後に3点以上残る4点以上のパスだけに適用し、Undo1回で開いた元のパスへ戻る。
