# プログラムモニターで動画・画像を直接配置

Issue: #65

別の素材の読み込みが完了しても、操作中の素材のドラッグを中断しない。素材寸法の通知は操作対象を照合して扱う。

100%を超えて拡大した素材も四隅から再調整できる。画面外にある角のハンドルはモニターの縁に表示し、実際の素材の角を使って拡縮を計算する。

モニターをクリックしたときにフォーカスを移す。素材一覧からの切り替え後のDeleteはタイムライン上の選択クリップに作用し、プロジェクト素材を削除しない。数値入力中に切り替えた場合は入力を確定してからドラッグの開始状態を取得する。

メイン画面のプログラムモニターで、停止中の動画・画像をクリックして選択し、ドラッグして移動できる。選択した素材の四隅にハンドルを表示し、反対側の角を固定したまま縦横比を保って拡大縮小する。実際に描画する素材の寸法、シーケンスの縦横比、回転、プレビューの表示サイズを座標計算に使う。スケールはプロパティと同じ10〜300%、位置は−200〜200%の範囲とする。

テキストと図形を含む重なり順を描画と一致させる。ロックしたトラックは変更せず、非表示・時間外・不透明度0の素材は操作対象にしない。映像にリンクした音声の位置や設定は変えない。既存の数値入力と同じx・y・scaleを更新し、保存形式を増やさない。

クリックだけでは履歴を増やさず、3px以上のドラッグを1回のUndo/Redoとして記録する。Esc、ポインター中止、フォーカス喪失、プロジェクト読込・再生位置・選択・表示寸法の変更で取り消し、ポインターキャプチャーとイベントを解放する。元の履歴や未保存状態を復元する。別の編集が確定した場合はそのプロジェクトと履歴を保持してドラッグを終了し、別の操作の変更を上書きしない。

素材が画面外にある場合にも、選択中の素材の位置と大きさをリセットできる。再生中は枠を隠す。テキストの直接編集、図形描画、プレビュー画質変更、全画面、トランジションの描画を維持する。切り離したサブ画面は従来どおり表示用とし、直接編集はメイン画面で行う。

座標計算は横型・縦型・異なる素材比率・回転・4つの角・上下限でテストする。Windows配布アプリでは選択・移動・拡縮・キャンセル・Undo/Redo・ロック・重なり・保存再読込と実MP4を確認する。
