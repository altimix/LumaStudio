# 終了時の3つの選択肢

Issue #49。Windowsの右上の×から、未保存の編集をその場で保存して終了できるようにする。

- 未保存の変更がある場合は「編集を続ける」「保存せずに終了」「保存して終了」の順で表示する。既定とキャンセルは「編集を続ける」。
- 「保存せずに終了」はプロジェクトファイルを書き換えない。従来の自動保存からの復元は維持する。
- 「保存して終了」は通常のプロジェクト保存を使う。既存プロジェクトは現在のファイルへ、新規は保存先を選んで原子的に保存する。成功後だけ終了する。
- 保存先の選択をキャンセルした場合、保存／自動保存の整理が失敗した場合、保存中に新しい編集が入った場合は編集画面を保持する。新しい編集があるときは再保存が必要なことを表示する。
- 保存中は待機画面を出し、キーボード操作やファイルのドロップ、×の連打で編集や保存要求を重複させない。終了要求に識別子を付け、古い応答では終了しない。
- 書き出し中は中止確認の後で、未保存の編集について同じ3択を表示する。中止確認で編集を続けた場合は書き出しも継続する。
- Windows配布アプリで3択の内容・既定・キャンセル、各分岐、新規／既存ファイル、保存キャンセル、書き込み失敗、二重終了、保存途中の変更、再起動を確認する。テスト用プロファイルだけで操作し、普段の編集や素材は変更しない。
