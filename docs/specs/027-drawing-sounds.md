# 図形と注目の効果音

Issue #27。プレビュー上で矢印・四角・丸を描き、タイムラインの編集可能な図形レイヤーとして扱う。

- 素材パネルの「図形」から種類を選びプレビューをドラッグする。キーボードでも中央への追加ボタンを使える。
- 図形はプロジェクトのピクセル寸法で保存する。矢印は描いた方向を保持する。縦長の矢印を短い横幅のキャンバスで切り落とさない。
- 追加後はドラッグ移動、右下ハンドルでサイズ変更、Inspectorで幅・高さ・線幅・線色・塗りつぶし、共通の位置・回転・長さ・不透明度・フェードを調整できる。
- 任意でピーン・チャイム・短いジングルを同時追加する。合成で作ったオリジナル音で外部素材やAPIを使わない。試聴と追加音量を選べる。
- 図形・音声・必要な音声トラックと素材の追加は1回のUndoで戻せる。音声は独立したクリップとして後から編集できる。
- 元素材を変更しない。生成音はバージョン更新で消えないアプリデータに保存する。保存・再読込・正逆再生・書き出しは通常のクリップと同じ処理を使う。
- 描画や変形はEsc・ポインター中止・フォーカス喪失で取り消す。ロックしたトラックに変更を加えない。準備中にプロジェクトが変わった場合は古い図形や音声を追加しない。
- 図形の描画関数をプレビューと書き出しPNGで共有し、Windowsのマウス操作・保存再読込・MP4の画素と音声を検証する。

- 描画中の矢じりも確定後と同じ座標で表示する。中止した音声準備が遅れて完了しても、次の描画の状態を消さない。
- 効果音の素材とクリップの長さを整数秒に切り上げ、別の合成音ファイルの末尾へ無音を足す。全対応FPSの境界に一致させ、追加後にFPSを変更しても余韻を切らない。音のサンプルと再生速度は変えず、試聴は元の長さを使う。

- 図形は移動・回転・拡大縮小を適用してからシーケンスの外側を切る。画面より大きい囲みでも、戻した辺を欠落させない。
- 効果音の試聴は選択変更・Esc・プロジェクト切り替えで中止する。新しい操作が古い準備の完了によって解除されないよう、プロジェクトと描画ツールの変更を同期して監視する。
- 図形・中央への追加・テキスト移動・タイムライン編集・再生ヘッドのドラッグは共通の操作所有権を取得する。準備中に別のドラッグを開始せず、終了時は自分の所有権だけを解除する。プロジェクトを開く際は実行中の操作を中止してから切り替える。
- 図形の追加先は表示中でロックされていない映像トラックから選ぶ。該当するトラックがない場合は表示とロック解除を案内し、図形・音・履歴を部分的に追加しない。
- 効果音の素材・クリップの表示名は選択欄と同じ日本語にする。内部ファイルパスを変えず、保存・再読込でも表示名を保持する。

## 初期設定と音の改訂（Issue #40）

- 起動時の描画設定は線色 `#ff0000`、チャイム、音量90%。効果音なし・種類・音量・線色は個別に変更できる。既存クリップの設定には適用しない。
- ポンを新規選択から廃止し、0.85秒の高く澄んだピーンを追加する。短いジングルは1.4秒の上昇する音列と終止の和音に改訂する。短い立ち上がりと余韻を持ち、ピークを抑えてクリップを防ぐ。チャイムの波形は維持する。
- 音ごとの改訂番号を永続ファイルのフォルダー名に含め、旧版のポン・ジングルを上書きしない。既存プロジェクトは保存済みのパス・表示名・音量で再生する。
- プロジェクト素材の初期表示はリスト。利用中はグリッドにも切り替えられ、検索・素材追加・削除の操作を維持する。プロキシ表示を追加ボタンと重ねず、ラベルがクリックを妨げないようにする。
- テキストの初期縁取りはタイトル・ミニマル・字幕すべて `#0064ff`（RGB 0,100,255）に統一する。初期線幅は4px。既存プロジェクトの個別設定色を維持する。
- 新しい字幕は下端余白を自動保持する。行数や文字サイズの変更、Inspectorの連続入力・スライダーでも再配置する。手動で位置・回転・スケール・テキスト枠を変えると自動配置を解除する。従来の保存字幕とロックしたトラックは自動移動せず、Undoとドラッグ取消で自動配置状態も戻す。

- ドラッグと中央への追加で同じフレーム切り上げを使う。1FPSの1.4秒ジングルには2秒の素材を用意し、2〜7FPSのピーンでも余韻を切り落とさない。パディングの上限は音の長さを整数秒に切り上げた値で検証する。
