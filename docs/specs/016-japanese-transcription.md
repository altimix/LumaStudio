# 016 日本語の最新モデル認識と字幕時刻


## API仕様と表示

- 2026-09-08に公式モデルページ・Speech to textガイドを確認。完成した音声の本文は `gpt-transcribe` を使用する。`languages[]=ja`、カンマ/読点で分けた `keywords[]`、文脈用prompt、既定JSONを送る。未対応のverbose_json/timestampsは送らない。
- 最新モデルは単語時刻を返さないため、同一音声を `whisper-1` のlanguage=ja/verbose_json/word+segmentで処理し時刻を取得する。Whisperには用語だけを渡す。認識済み全文は「前の文脈」と解釈され冒頭が欠けることがあるため渡さない。
- モデル名、認識と時刻取得の2回の課金、既存字幕の置換をUIとREADMEに表示。APIキーは既存の.env取込・Windows暗号化保存を使う。ログ・プロジェクト・CIへキーを出さない。
- 公式: https://developers.openai.com/api/docs/models/gpt-transcribe / https://developers.openai.com/api/docs/guides/speech-to-text

## ローカル時刻照合

- 本文は原則gpt-transcribe由来。最小区間でのフォールバック時のみ後述の時刻付き本文を採用する。日本語/英数字をNFKC・大小文字・カナ正規化し、編集距離で独立の時刻文字列に照合。単語内の文字はその測定単語区間内に配置し、訂正文字の短い欠落だけ隣接時刻で補間する。
- 最低一致率55%、長い欠落の拒否、昇順かつ範囲内の時刻、最大文字数・DP行列サイズを検証する。最後の文しか時刻がない結果を全文へ引き延ばさない。不一致は説明付きエラーとし、既存字幕・投稿文を保持する。
- 句読点・英語の単語境界・無音間隔を維持する。空の認識本文は時刻取得を呼ばない。キャンセル時は次のAPI呼出しを開始しない。
- 60秒窓・前後1秒の文脈・単語中点による重複除去・シーケンス秒への変換を使用。Issue #22で長時間の照合失敗を修正。

## 受け入れ検証

- API契約・最新本文の保持・専門用語・英語表記・無音区間・冒頭欠落・不正時刻・文字数制限・中止を自動検証。
- Windows実アプリで暗号化設定、2モデル要求、字幕編集、SRT/VTT、保存/再読込、日本語字幕入り横/縦MP4を検証（CIのAPIのみ模擬）。
- 利用者指定.envで自作の約17秒の日本語読み上げを実APIに送信。最新モデルで「Luma Studio」「75秒」「ノーマライズ」を認識し、独立の時刻を冒頭から末尾まで照合できることを確認。実素材全般の精度保証ではない。

本文一致率に加え、連続する置換・挿入を検査する。固有名詞など短い訂正は許可し、長い不一致区間を周囲の一致で正当化しない。照合できない場合は既存字幕を保持して再実行を案内する。

時刻取得がsegmentsのみの場合は、その実測区間内で本文を照合する粗い時刻のフォールバックを保つ。wordsが存在する場合の不正なデータは隠さない。本文側・時刻側の両方で長い不一致区間を拒否する。

## 長時間の認識と自動回復（altimix/LumaStudio #22）

- 最初から60秒ずつ認識し、本文と時刻が一致しない区間だけ二分割して再試行する。通常60→30→15→7.5秒。短い最終区間は8秒以下まで細分化する。API接続・認証・課金・中止エラーは分割で再試行しない。
- 最小区間でも本文が食い違う場合は、Whisperの実測時刻とその本文を採用する。最新モデルの本文を無関係な時刻へ引き延ばさない。採用区間数を保存し、字幕画面に表示する。不正時刻・壊れた応答は受け入れない。
- 認識は順次実行し、API要求ごとの音声は最大62秒。音声の12時間制限と字幕の24時間制限を撤廃し、RF64対応WAVで4GBを超える準備音声を扱う。作業用音声はディスクに保存するため、空き容量と処理時間が必要。音声全体をメモリに読まない。
- 字幕は最大10万件、YouTubeデータは保存時と同じ整形・インデントを含むUTF-8で12MiB以内。文字起こしを反映する前にプロジェクト全体を実際の保存形式で直列化し、15MiB以内で保存できることも確認する。プロジェクト全体の15MiB・タイムラインの2000クリップ上限は維持。大量字幕は40件ずつ表示し、SRT/VTTで全件保存できる。無限の容量・時間・認識精度を保証しない。
- 進捗は処理済みのシーケンス時刻で表示。自動再試行では追加のAPI利用料が発生する。全区間が成功するまで既存字幕は置換しない。中止・失敗時は一時音声を削除する。
- 2026-09-11に[公式File transcriptionガイド](https://developers.openai.com/api/docs/guides/speech-to-text)で25MB上限とWhisperの単語/区間時刻を確認。モデル・APIパラメータは既存契約を維持する。
- 72時間超・8642字幕の窓処理、実FFmpeg音声抽出、境界の重複除去、段階的再試行、最終フォールバック、保存再読込、キャンセル、API障害を自動試験する。API応答を模擬した試験は実音声の認識精度試験と区別する。
