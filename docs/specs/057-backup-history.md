# プロジェクト別バックアップ履歴（#57）
- 自動保存の完了時に、ユーザーデータ配下の backups に独立したスナップショットを作成する。プロジェクトIDごとに直近10世代を保持する。
- 一時ファイルを書き終えてから置換する。新しい版の保存完了後に古い版を整理し、素材原本と手動保存ファイルには触れない。
- 従来の起動時自動復元は維持する。手動保存や復元候補の破棄で通常の自動保存を消しても、世代履歴は残る。
- ファイル → バックアップ履歴でプロジェクト名・日時・クリップ数を確認し、任意の版を復元できる。現在の未保存編集がある場合は既存の保存確認を通す。
- 復元した版は未保存プロジェクトとして開き、元の保存先へ直接上書きしない。素材が見つからなければオフラインで開き、再リンクできる。
- 識別子・最大サイズ・プロジェクト形式をメイン側で検証する。壊れたスナップショットを一覧から除いても他の版を復元できる。復元中の失敗は現プロジェクトを変えず表示する。
- 素材のコピーは含まれない。旧バージョンの単一自動保存は起動時の復元候補として引き続き扱う。
