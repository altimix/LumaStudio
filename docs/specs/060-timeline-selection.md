# Vツールによるドラッグ範囲選択

Issue: #60

## 操作

- `V`で選択ツールに切り替える。タイムラインの空白を左ドラッグすると、半透明の四角い枠に触れる素材をまとめて選択する。左右・上下どちら向きでも、複数トラックをまたいでも使える。
- Shiftを押してドラッグを開始した場合は、開始前の選択へ追加する。ロックされたトラックの素材は新たな範囲選択の対象にしない。
- リンクした映像・音声は従来と同じ関連選択表示になり、その後の移動ではリンク相手も一緒に動く。
- 素材本体のドラッグは移動、端はトリム、音量ラインは音量編集のまま。レーザー・レートツール、再生ヘッドとルーラーのスクラブ、空白の右クリック操作を維持する。
- 4px未満の移動はクリックとする。通常の空白クリックでは選択を解除してその位置へ再生ヘッドを移す。Shift付き空白クリックは選択と再生位置を保持する。
- 範囲選択では再生を停止し、再生ヘッド・素材の位置・Undo/Redo履歴・保存状態を変更しない。
- ドラッグ中は画面の端で水平・垂直に自動スクロールする。始点はタイムライン上の位置に固定し、スクロール済み・ズーム済みの座標を正しく使う。
- Esc、pointercancel、キャプチャ喪失、フォーカス喪失、非表示、リサイズ、プロジェクトやズームの変更、アンマウントで選択枠とイベントを整理し、可能な場合は開始前の選択に戻す。

## 検証

境界・逆方向・複数トラック・ロック・追加選択の純粋な座標計算をテストする。Windows実画面ではV/C切替、選択枠、Shift、キャンセル、再生位置・履歴保持、選択後の移動とUndo、スクロールとズーム、右クリックを検証する。既存のマウススクラブ検証は、選択ツールの空白ドラッグが範囲選択に変わることを反映し、空白スクラブはレーザーツールで引き続き検証する。
