# ヘルプメニューと更新確認

Issue: https://github.com/altimix/LumaStudio/issues/4

## 利用者の操作

「ヘルプ」には「初めての動画編集」「ショートカットキー一覧」「アップデート」を置く。既存の編集ガイドと検索可能なショートカット一覧を維持する。キーボード図ではMac / Windows、通常 / Shift / CommandまたはCtrl / CommandまたはCtrl + Shiftを選択できる。各キーの説明は実際のshortcutCommandと同じ判定で表示する。図は主要キーの概略で、JIS / USの物理配列を保証しない。

起動して編集画面が準備できたら、GitHubのaltimix/LumaStudio最新安定版を確認する。新しい版と現在のOS・アーキテクチャに対応する公開済みアセットがある場合、タイトルバーに「更新あり」を表示する。勝手にダイアログを開かない。「アップデート」から手動の再確認と配布ページの表示ができる。

## 更新の範囲と境界

- 利用者が選択した範囲は「起動時に更新を確認し、ダウンロード・入れ替えを案内する」。自動インストール、アプリの置換、自動終了は行わない。
- メインプロセスが固定GitHub APIに接続する。プロジェクト・素材・APIキーは送信しない。Rendererから任意URLを受け取らない。
- 数字のバージョンを比較し、ドラフト・プレリリースを除外する。古い版への入れ替えを案内しない。配布名はWindows x64 EXE / Mac arm64 ZIPの規約に従う。
- 10秒でタイムアウトする。同時リクエストを共有し、成功結果は10分キャッシュする。手動再確認でキャッシュを更新できる。通信失敗は編集を妨げず、更新画面で日本語の説明を表示する。
- ダウンロード先は検証済みのタグから固定リポジトリのURLを組み立てる。外部から渡されたhtml_urlやアセットURLをそのまま開かない。
- 入れ替え前に保存・書き出し完了・アプリ終了を案内し、WindowsとMacの手順を区別する。未署名Macの起動案内と配布READMEへの説明も含める。

## 受け入れ条件

1. ヘルプの3項目をマウスとキーボードで開ける。メニュー操作がタイムラインを動かさない。
2. キーボード図の選択で再生や編集を発動しない。MacのCommandとWindowsのCtrlを区別し、既存の検索も使える。
3. 新版あり / 最新 / 対応アセットなし / 通信失敗を区別する。起動時の失敗は通知ダイアログを出さない。
4. バージョン比較、アセット選択、不正レスポンス、同時確認・キャッシュ・復旧を自動テストする。
5. 公開済み1.0.0は変更しない。本変更を配布したバージョンから更新確認が使える。
