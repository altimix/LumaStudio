# 図形の追加前の塗りつぶし・不透明度

Issue: #74。素材・エフェクトの「図形」タブに追加する。

- 四角と丸は塗りつぶしをON/OFFでき、線と塗りを別々に選色する。矢印は線だけを描く。
- 図形全体の不透明度を0〜100%で指定する。線と塗りの両方に適用する。
- 初期値は塗りなし・不透明度100%。線の色と効果音の既定値は維持する。設定は次に追加する図形に適用し、既存図形を変更しない。
- モニターのドラッグ中も塗りと不透明度を表示する。「中央に追加」とドラッグ描画は同じ生成処理を使う。
- 不透明度は共通の数値入力と折りたたみスライダーを使う。表示時間も直接入力・横ドラッグに対応する。追加前の設定はプロジェクトの変更履歴に入れない。
- 追加後はプロパティで線・塗り・不透明度を再編集でき、共通キーフレームで変化を記録する。保存、再読込、MP4へ反映する。
- 図形と効果音を1回のUndoで戻す。ロックしたトラックへ追加しない。不正値で部分的な素材追加を残さない。

モデルテストで透明度0、矢印の扱い、不正値、Undo/Redoを確認する。配布アプリでは両方の追加方法、描画中の見本、再編集、保存、実MP4との画素比較を確認する。
