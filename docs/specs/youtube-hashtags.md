# YouTube 概要欄のハッシュタグ

Issue #74。投稿文を生成すると、内容に直接関係するハッシュタグを3個提案する。投稿文の既存モデル設定を維持し、タイトル3案・検索ワード10個と別の構造化フィールドで取得する。検索ワードをそのままハッシュタグへ流用しない。生成した概要本文にはタグを重複させないよう指示する。

`YoutubeData.hashtags?: string[]` は既存プロジェクトとの互換性のため任意項目とする。保存形式のバージョンは維持し、プロジェクトの検証・保存・Undo/Redoに含める。生成応答では必須の3個。手動編集では0〜3個を許可し、空欄で付加を解除できる。タグは # に続くUnicode文字・結合文字・数字・アンダースコアで、#を除き80文字以内。重複・空白・記号・個数超過を拒否する。

UIは空白/カンマ/読点区切りを受け付け、NFKCで全角入力を正規化して # を補う。入力中の不正な原稿ではコピーを無効にする。確定直後のコピーも最新の状態を取得する。コピーされる概要欄のプレビューを表示する。

出力は「概要本文」「条件を満たすチャプター」「ハッシュタグ1行」の順で、間を空行で区切る。短尺などチャプター条件を満たさない場合にもタグは最後へ付ける。概要欄コピー、一括コピー、テキスト保存に共通の組み立て処理を用いる。本文・チャプター・タグ・区切りを含む5000文字制限を検証し、切り捨てない。

従来の本文は変更せず、hashtagsがない古いプロジェクトにはタグを勝手に追加しない。投稿文を再生成するか、ハッシュタグ欄へ入力すれば利用できる。

単体テストは出力順序、短尺、未設定、全角入力、重複・不正タグ、5000文字境界、生成形式の拒否を対象とする。Windows検証はOpenAI応答のみ固定し、編集直後のコピー、実クリップボード、全投稿文コピー、テキスト保存、保存読込・Undo/Redoを実処理で確認する。ライブAPIへの送信はこの修正の自動検証では実行しない。

参考：[YouTube公式ヘルプ](https://support.google.com/youtube/answer/6390658?hl=ja)。動画の概要欄にハッシュタグを追加でき、そのうち最大3個がタイトル付近に表示される。採用数3個はLuma Studioの初期設定であり、YouTube全体の個数上限を意味しない。
