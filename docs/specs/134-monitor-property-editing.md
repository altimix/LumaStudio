# モニターからの選択と数値編集

Issue: #134

停止中のメインプログラムモニターで映像・画像・図形・文字をクリックすると、対応するクリップと所属トラックを選択表示する。モニター操作が終わった時点で、そのトラックと再生位置付近をタイムライン内に表示する。選択で再生位置、プロジェクト内容、Undo履歴を変えない。重なりは既存の描画順に従う。ロック中の文字・図形も選択とトラック表示は可能とし、移動・変形・直接文字編集は拒否する。

文字はシングルクリックで選択し、ダブルクリックまたはF2で既存のインライン編集を開始する。Enterで改行、Ctrl/Cmd+Enterまたは外側クリックで確定、Escapeで取消。日本語IME、1回分のUndo/Redo、ロック保護、保存・再読込を維持する。

数値の直接入力、左右ドラッグ、スライダーの履歴はdocs/specs/043-number-input-scrub.mdに従う。フォーカス中もドラッグと履歴ショートカットを利用でき、フォーカスを外す操作を要求しない。

実アプリでシングルクリックとダブルクリックの区別、画面外トラックの表示、文字サイズ・位置・回転・効果・音量の履歴、フォーカス済み入力のスクラブ、入力途中のUndo、保存再読込、ロック、キャンセルを検証する。
