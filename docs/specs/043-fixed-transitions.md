# 動画の全体尺を変えないトランジション

Issue #43。隣接するカットへの効果追加・変更・解除では、クリップの開始・素材in点・長さ・速度や別トラックを動かさない。

- 新規の隣接接続は `mode: fixed` と効果の `duration` を保存する。効果区間はカット前後に分配し、奇数フレームでは後半へ1フレーム多く配る。効果は1フレーム以上、60秒以下、両クリップの半分以下（1フレームのクリップでは1フレーム）とする。
- FPS変更時は効果の長さと共通の編集点を新しいフレーム境界へ合わせ、リンク音声も同じ編集点を維持する。接続を保持できない変更は明確なエラーで拒否し、効果を黙って削除しない。
- 映像は効果に必要な前後の素材ハンドルを使う。素材の開始より前は最初のフレーム、終了より後は最後のフレームを複製する。補完はレンダリング時に行い、元素材やクリップの編集点を変えない。
- クロスディゾルブ・ページターン・ページピールで同じ区間計算を共有する。連続する複数の効果、速度変更した素材、静止画、透明な上下レイヤーにも適用する。
- 音声は使用可能なハンドルだけを再生する。ハンドルが重なる区間でコンスタントゲイン／パワーを適用し、両側が不足して重ならない場合はカットへフェードアウトしカットからフェードインする。音声を静止・ループさせず、セリフやBGMのタイミングを変えない。
- 音声の範囲と曲線は正逆プレビュー、MP4、文字起こし用音声で共有する。音声効果の長さ変更は文字起こしの古い時刻検知へ反映する。
- ロック・Undo／Redo・保存再読込を維持する。隙間を自動で詰めない。不正な接続や値を拒否し、切り離す編集で無効な効果を除く。
- `mode` のない既存プロジェクトは従来の重なり区間をそのまま解釈し、既存の完成尺を変えない。既に重ねた接続への効果変更でも配置を動かさず、長さは現在の重なりに従う。
- 実際のFFmpeg出力の尺・画素・音声を調べ、Windows上の適用、変更、解除、Undo、保存、プレビューとの一致を確認する。
