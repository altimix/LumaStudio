# テキストの文字揃えとコンパクトなプロパティ

Issue: #128

テキストのプロパティは文章、フォント、文字の太さ・サイズ、文字色・スタイル、文字揃え、縁取り、影の順に並べる。文章と装飾を基本の時間設定やキーフレームより先に表示する。影・縁取りの有効無効と色は常に表示し、有効時に幅・ぼかし・距離を共通の数値欄から調整できる。フォント検索と文字枠は必要なときに開く。説明段落を省き、日本語ラベル、ツールチップ、エラーと読み込み状態を残す。数値のドラッグ、スライダー開閉、入力開始時の停止、キーフレーム選択表示を維持する。

文字揃えは「左揃え」「中央揃え」「右揃え」「均等割付」の4ボタンで切り替え、選択中のボタンを明示する。文章枠がある場合は既存の余白を除く内側、枠がない場合は最長行の幅（最大でシーケンス幅の90%）を基準にする。文字全体の位置や回転・拡大率は変更しない。

均等割付は改行・折り返し後の各行を字間で広げ、最終行も含める。結合文字、絵文字などは書記素のまとまりを壊さない。空行はそのまま、1文字は中央とする。自然幅以上に広げられない行は既存の中央描画と最大幅の処理を維持し、枠付きの過大文字は既存のクリップとオーバーフロー表示を維持する。

保存はClipの任意フィールドtextAlign（left/center/right/justify）を使い、未指定の旧プロジェクトは中央揃えを維持する。不正な値は読み込み・書き出しで具体的に拒否する。共通のビジュアルキーフレームでは離散値として扱い、ポイント時刻で切り替える。プレビュー・静止画・時刻別のタイトル画像・動画書き出しは同じ描画を使う。Undo/Redo、ロック、分割・トリム、保存再読込を維持する。

検証では旧形式、文字揃えと字間、Unicode、異常値、履歴・ロック・キーの境界を確認する。配布アプリでは狭いパネル、影・縁取りの常時表示、フォント検索、全4種の保存再読込、実MP4のフレーム比較、キーフレームによる切替を確認する。
