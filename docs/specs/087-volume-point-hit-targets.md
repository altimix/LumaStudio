# 音量ポイントの位置と操作範囲

Issue: #87

- 丸の中心と音量ラインは素材内の時刻をそのまま横座標に対応させる。先頭0秒と終端は境界に置き、内側へ寄せない。
- 見える丸の半径は7px。透明なストロークを含む半径16pxの操作範囲を用意する。素材外へのクリック領域の侵入は既存のクリップ境界で遮る。
- 近接した操作範囲が重なる場合はポインターに最も近い点をドラッグする。
- 音量ラインのある素材は上部18pxで長さ変更、下部で音量操作を行う。
- 既存の点の左右移動、矢印キー、音量表示、Undo/Redo、ロック保護、保存された時刻は維持する。

検証: Windowsの音量自動化検証で境界座標、見える丸より広い操作範囲、上部トリム領域を確認し、既存の編集・保存・Undo検証も実行する。

- プロパティの「再生ヘッドに音量ポイントを追加」は、実際に追加されたフレーム時刻の点をアクティブにし、キーボードフォーカスを移す。同じ時刻に既存の点があればその点を選び、重複を作らない。プロパティの音量欄も選択した点に同期する。
- クリップの切り抜き範囲を枠線まで含め、右端の丸の中心でも素材移動ではなく音量操作を開始する。

- 最小表示幅5pxに拡張された短い素材でも、点の追加・ドラッグ・区間の選択はSVGの実表示幅から秒へ換算し、表示座標と編集時刻を一致させる。
