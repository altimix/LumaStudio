# BGMライブラリ

Issue #46。BGMフォルダの曲を選び、試聴してタイムラインへ追加する。

- 素材パネルの「BGM」に曲名・長さ・検索・試聴・停止・フォルダ選択・更新を表示する。選択したフォルダを端末に記憶し、初回はポータブルEXEの横または開発プロジェクト直下の `bgm` を検出する。
- サブフォルダを含むMP3/WAV/M4A/AAC/FLAC/OGG/OPUSを対象にする。リンク先をたどらず、深さ8・256フォルダ・2000曲まで。破損ファイルは一覧から除き、理由を示す。ユーザーの音楽をリポジトリや配布バイナリへ含めない。
- 試聴は選択切替・パネル終了・プロジェクト切替・タイムライン再生・Escで停止する。遅れて完了した読み込みが以前の曲を再生したり、別プロジェクトへ挿入したりしない。
- 長いフォルダ探索の途中でBGMタブを閉じて戻っても、進行中の探索結果を新しい画面へ返す。通常の一覧取得を同じ探索にまとめ、完了後は追加操作なしで曲を表示する。
- 一覧作成後にファイルや親フォルダが変わった場合も、読み込みの前後で実パス・通常ファイル・素材IDを照合する。リンク先・一覧にない素材・変更された曲をmediaプロトコルへ登録せず、更新を案内する。
- ドライブ直下や共有フォルダのルートを選んでもサブフォルダを探索する。探索中もディレクトリの読み込み前と音楽の解析前後で実パスを照合し、途中で差し替えられたリンク先を解析しない。
- 挿入先は現在の再生ヘッド。初期音量10%（−20 dB、Issue #48）、先頭0.5秒・末尾1秒のフェード（短い曲では調整）。試聴音量も同じ値で、追加後は通常の音量・フェード編集を使える。
- 初期選択は「動画の終わりに合わせる」。映像・画像・テキストの最終フレームまで、曲を切るか必要な回数だけ繰り返す。繰り返しの途中にフェードを入れず、曲頭と最後だけフェードする。再生ヘッド以後に映像がないときは1曲分。「曲をそのまま追加」も選べる。
- 音楽用トラック（BGMまたはミュージック）の空き区間を使い、競合やミュート・ロック時は新しいBGMトラックを作る。既存のクリップを移動・上書きしない。素材・トラック・全繰り返しクリップの追加は一度のUndo/Redoにまとめる。制限超過時は何も変更せず案内する。
- 時刻はフレーム境界と素材の実際の長さに従い、動画の終わりを延ばさない。素材は参照として保存し、元ファイルを変更しない。
- 見失った音楽が復元され、同じ素材IDで追加されたときは、プロジェクト内のオフライン素材も読み込み済みの情報へ更新する。元のクリップも再生可能になり、この更新を含めてUndo/Redoできる。
- フォルダ探索・非登録ID拒否・モデルの尺/繰り返し/ロック/Undo/容量をテストする。Windowsパッケージで日本語曲名・試聴・挿入・保存再読込・音量調整・MP4の映像と音声を検証する。
