# 1.10.4の正式配布

Issue: https://github.com/altimix/LumaStudio/issues/122

Issue #117 の動くマスクの中間キャッシュと Issue #120 の無編集MP4再圧縮省略を、1.10.4で配布する。適用条件、異常時の保護、実測値は `117-animated-mask-cache.md` と `120-direct-copy-export.md` に従う。GPUデコードの新しい経路と動くテロップの永続キャッシュはこの版に含めない。

- アプリ、ロックファイル、HTMLマニュアル、Windows / Macの起動ガイド、公式サイトを1.10.4へ揃え、1.10.3までの更新履歴を残す。
- 動くマスクの再書き出しは同じキーの検証済み中間データだけを再利用する。壊れたデータや変更した素材・設定では作り直し、使用中のデータを削除操作から守る。
- 再圧縮省略は無編集のH.264/AAC MP4に限り、通常の素材追加でできるリンク済み映像・音声ペアを含む。条件外の編集と可変FPSは従来経路を使う。元素材と既存出力は一時ファイル完成まで保護する。
- Apple M2 Proの短い生成素材による初回・再書き出しの総時間を、素材・寸法・FPS・品質・試行回数とともに条件付きで紹介する。ほかのPCや長尺素材への短縮倍率は保証しない。
- リリースPRの最終コミットでWindows / macOS CI、配布アプリの書き出し・再取り込み・音声再生、Website CI、Codexレビューを確認する。WindowsポータブルEXEでは同梱FFmpegの一時展開先を削除した後の音声再生も維持する。
- 最終ソースに一致するCI由来のWindows x64 EXEとMac arm64 ZIPを使い、内蔵版数、Mac署名、ガイド、ライセンス、メディアツールの対応ソース、SHA256を照合する。既存タグやリリースは上書きしない。
- GitHub Release公開後に公式サイトを配備し、PCと390px幅、マニュアル検索、SEO、404、Windows/Macの配布リンクとチェックサムをHTTPS本番で確認する。
