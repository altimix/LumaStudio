# 基本設定とプレビュー優先の配置

Issue: #54

プロパティのビデオタブ先頭に「基本設定」を置き、開始・長さ・素材の開始位置・速度を2列で表示する。テロップや図形でも開始・長さを先に調整できる。座標や保存形式、Undo/Redo、ロック保護は変えない。

クロップとマスクは未設定なら折りたたみ、見出しから展開する。設定済みの効果は表示して調整できる。

「ウィンドウ → プレビュー優先の配置」で両サイドパネルを折りたたみ、タイムラインを最小高さにする。「レイアウトを初期状態に戻す」で標準配置へ戻せる。配置は既存の保存機構で記憶し、編集内容やプロジェクトのUndoには加えない。

1280×720で基本設定とプレビュー優先配置を確認し、効果の展開後もクロップ・マスクの保存と書き出しを検証する。
