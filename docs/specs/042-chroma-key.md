# スポイト式クロマキー

Issue: #42

映像・画像クリップは、カラータブの「クロマキー」を有効にすると背景色に近い画素を透明化できる。背景色はカラーピッカーで指定できるほか、停止中のプログラムモニター全体をクリックし、露出・色補正・クロマキー・クロップ・マスクを適用する前の選択素材フレームから5×5画素をアルファ加重平均して取得できる。透明画素だけの場所、素材外、未準備フレーム、選択素材の時間外、再生中、ロック中は採色せず、具体的なメッセージを表示する。素材寸法の計測前もモニターのクリック対象を表示し、メタデータ上の寸法で素材範囲を判定する。

色の近さは輝度差の影響を抑えたCb/Cr平面の距離で判定する。「色の許容範囲」は完全に除去する距離、「境界のなめらかさ」は不透明へ戻る滑らかな区間で、どちらも0〜50%とする。緑・青の色かぶり除去は、キー色へ近い境界画素で周囲の赤・青または赤・緑を上回る成分を0〜100%抑える。元素材のアルファは上書きせず、クロママットと乗算する。

処理順は、素材フレーム → クロマキー／色かぶり除去 → 基本色補正 → クロップ／形状マスク → 不透明度／フェード → トランスフォーム／トランジションとする。プレビューはWebGL2を優先し、利用できない場合だけ同じ式のCPU処理へ切り替える。CPU処理はキー色と定数をフレームごとに1回だけ計算し、停止中または同じデコードフレームでは処理済み画像を再利用する。書き出しはFFmpegで同じCb/Cr距離、smoothstep、色かぶり除去を評価する。プレビュー用の「キーマットを表示」は選択クリップを黒背景上へ単独表示し、変形・クロップ・マスクで除外された範囲を含む透明領域を黒、残す領域を白として表示する。保存後も設定を保持するが、書き出す映像を白黒マットには変更しない。

クロマキー設定は分割・複製・保存再読込で保持し、1回の操作をUndo / Redoできる。音声クリップへは複製しない。トラックロック中は変更できない。クロップ、長方形・楕円・ベジェマスク、元の透明度、フェード、トランジションとの合成を破壊しない。

この機能は「Ultraキーに匹敵する」とはまだ表記しない。実写の髪、眼鏡、半透明素材、速い動きのぼけ、圧縮ノイズ、照明ムラ、緑や青を含む衣服について、権利確認済みの素材を使った目視比較を別の品質ゲートとして行い、その結果が揃うまでは高品質な基本クロマキーとして扱う。
