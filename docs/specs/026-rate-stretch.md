# レート調整ツール

Issue #26。動画・音声の選択した素材区間を保ち、タイムライン上の長さで再生速度を調整する。

- ツールバーから「レート調整ツール」を選び、クリップの左端または右端をドラッグする。中央をドラッグした場合は右端を伸縮する。
- 反対側の端、素材IN、素材OUTを保持し、速度は0.25〜4倍、長さはシーケンスのフレーム単位とする。前後のクリップは移動しない。
- フェードは元素材に対する割合を保って伸縮する。映像とその音声は同じ速度になる。従来の音声速度処理を使う。
- 数値の速度表示、Inspector、プレビュー、保存、書き出しが同じ実数速度を使う。
- 1回のドラッグは1回のUndo。Esc、ポインター中止、ウィンドウのフォーカス喪失で取り消す。ロックしたトラックと静止素材は変更しない。
- 既存のRキーによる1フレーム送りを維持する。
- 単体テストで素材区間・境界・フレーム精度を確認し、Windowsの実操作からUndo/Redo、保存・再読込、映像と音声の出力を検証する。
