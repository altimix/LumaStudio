# 素材一覧とトランジションの直接操作

Issue: #33

## 素材パネル

- エフェクトは「切り替え」「色調」「音声」に分類し、見本と名称を一覧にする。説明はツールチップと必要な状態表示にまとめる。適用済みの効果は一覧から選択・解除できる。
- テキストは見本カードを小さく並べ、クリックで再生ヘッドへ追加する。狭いパネルでは見本と名前を横に並べる。
- 図形は形・色・表示時間を上部へまとめ、効果音の詳細を折りたたむ。効果音の選択名は閉じた状態でも見える。プレビューでの描画、中央への追加、描画終了を維持する。
- BGMは短いフォルダ名、検索、曲一覧を表示する。完全なフォルダパスはツールチップで確認できる。曲の左側で試聴・停止し、下部で音量・追加する長さを指定して再生ヘッドへ追加する。
- 冗長なキャッチコピーと長い常設説明を省く。追加位置、対象未選択、ロック、読み込みエラーなど操作に必要な情報は表示する。
- パネル幅248pxと最小ウィンドウで操作できる。スクロールは一覧を中心にし、高さが不足する場合でも設定と追加ボタンに届く。

## 効果の長さ

- 効果帯の中央をクリックすると、その効果を選択してエフェクト欄へ移る。数値欄は現在の長さを表示し、Enterまたは欄外への移動で編集を確定する。Escは入力を取り消す。
- テキスト・図形・BGMの追加などで選択が別のクリップへ変わったら、以前の効果を数値編集の対象にしない。現在の選択と関係するつなぎ目だけを調整する。
- 両端のつまみを外側へ動かすと長く、内側へ動かすと短くする。カット位置を中心に両側を伸縮し、奇数フレームの後半への配分を維持する。クリップ開始・in点・長さ・速度・全体尺は変更しない。
- ドラッグ中は秒数を表示し、エフェクト欄の数値にも反映する。最小1フレーム、両クリップの半分以下、最大60秒に制限する。小さい効果帯にも十分なつまみと中央クリック領域を確保する。
- フォーカスしたつまみの左右矢印で同じ方向に1フレーム、Shift併用で10フレーム調整する。Home/Endで最小/最大長にする。
- ドラッグの途中更新を一つの履歴へまとめる。元の長さへ戻した場合は不要な履歴を作らない。Esc、ポインター中断、ウィンドウのフォーカス喪失、プロジェクト切替、コンポーネント終了時は途中変更を取り消す。
- 同じ接続にある映像とリンク音声の効果は長さを揃える。未設定の音声効果は追加せず、リンクしていない音声や別の接続は変更しない。いずれかの対象トラックがロックされていれば変更を拒否する。
- `mode: fixed` の既存形式を使い、効果のID・映像種類・音声曲線を保持する。保存再読込とUndo/Redoを維持する。重なりに従う旧形式は配置を保ち、長さを変更できない理由を表示する。

## 検証

モデルでフレーム境界、最大・最小値、リンク・ロック・旧形式・保存・Undo/Redoを確認する。実アプリで左右ドラッグ、数値連動、Escとポインター中断、キーボード、最小サイズ、4タブの操作を検証する。既存の映像/音声トランジションのプレビューとMP4、BGM、図形の検証を継続する。
