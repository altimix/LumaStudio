# 1.9.0の正式配布

Issue: https://github.com/altimix/LumaStudio/issues/88

キーフレームの時刻ずれ修正（#82 / #83）、表示対象の案内とEscによるモニター編集終了（#84 / #86）、GPT Image 2.5と任意の参考画像（#85 / #87）を配布する。各機能の受け入れ条件は072、084、108の仕様に従う。

- 機能PRをそれぞれスカッシュマージする。マージ対象コミットのWindows / macOS CI、配布版検証、Website CI、Codexレビューを確認し、指摘に対応する。
- アプリ、ロックファイル、HTMLマニュアル、OS別ガイド、公式サイトを1.9.0へ揃え、旧版の更新履歴を残す。公開用の版数・ガイド・サイト変更はサムネイルPRと一緒に検証する。
- 成功したCIのWindows x64 EXEとMac arm64 ZIPを使用する。タグとCIで実際に使われたソースツリー、アプリの内蔵版数・マニュアルを照合し、Macの署名を確認する。
- 起動ガイド、HTMLマニュアル、ライセンス、メディアツールの対応ソースとビルド手順、SHA256を添付する。既存のリリースやタグは上書きしない。
- Windows未署名、Mac ad-hoc署名・Developer ID署名／公証未対応を明記する。テスト用API応答による生成処理の検証と、実際の人物の再現度・文字品質の確認を区別する。
- 公開ファイルを再取得し、サイズとSHA256を照合する。その後、公式サイトを更新し、PC / 390px幅、マニュアル検索、SEO、404、配布リンクを検証する。
- 公開と確認が完了してからIssue #88を閉じる。

配布版のトランジション・リンク編集検証は、保存後の復旧ファイルの整理も終わってから次の保存やテスト用プロジェクトの書き換えへ進む。ファイル更新時刻や未保存印の消失だけを完了とせず、以前の通知を閉じて今回の保存完了通知を確認する。後処理を遅延させた配布アプリでも検証する。
