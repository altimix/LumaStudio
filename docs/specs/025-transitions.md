# 映像・音声のトランジション

Issue #25。クロスディゾルブ、ページターン、ページピールと、音声のコンスタントゲイン・コンスタントパワーを追加する。

- 同じトラックの隣り合う2クリップを選択し、エフェクトから適用する。素材のつなぎ目へのドラッグでも適用できる。長さを指定する。
- 新規の効果は[全体尺を変えないトランジション](043-fixed-transitions.md)に従い、カット位置と全クリップの配置を保つ。未使用の映像を使い、不足時は端のフレームを複製する。
- 長さは1フレーム以上、双方の半分以下、最大60秒。三重のトランジション区間を作らない。画像も映像トランジションに使える。
- コンスタントゲインは線形の振幅、コンスタントパワーはsin/cosの等電力曲線。前後を同じ曲線でミックスし、プレビュー・正逆再生・MP4・文字起こし音声で同じ時刻を使う。
- クロスディゾルブはアルファを掛けた色を補間し、透明度で割り戻す。サイズ・位置・透明度が違う映像でも、下のトラックへ合成する際に縁や非重複部分を暗くしない。
- ページターンは横方向のページの回転と遠近・陰影、ページピールは右下の折り返しと紙の裏・影を描く。単純なワイプをページ効果と呼ばない。
- 解除は効果だけを外し、配置を保持する。適用は1回のUndoで戻せる。従来の重なりは読込時にも保持する。接続が編集で崩れた場合は無効な効果を解除する。保存時は壊れた接続を拒否する。
- ロックしたトラックを変更しない。プレビューとFFmpeg出力を、時刻・実画素・音声の波形で照合する。

- トランジションの画素読取・補間は専用WorkerとOffscreenCanvasで行い、画面のアニメーション処理を待たせない。処理中のフレームは1枚に制限し、出力用ImageDataを再利用する。停止・シーク後は現在の時刻と設定の結果だけを表示する。

- 音声のトランジション計画は不変のプロジェクト単位で保持する。隣接クリップと素材は索引で参照し、音声ブロックごとに全接続を探索し直さない。編集とUndoでは対応する計画へ切り替える。

- 初回再生などで片方の映像・画像・文字が準備中の場合、空の画像を合成せず、準備できた側の映像を保持する。両方の描画元が揃ってからトランジションを合成する。
- 映像効果だけを変更した場合、既存の音声カーブを保持する。音声の自動追加は未設定の場合だけに適用し、手動選択したカーブを標準設定で上書きしない。
- 位置を動かす前のトラック順で隣接を確認する。途中に別のクリップがある組み合わせは、クリップの位置や履歴を変更せず拒否する。
- 1クリップだけの選択は常に切り替え先として扱う。トラックの先頭には前のクリップがないことを案内し、位置や履歴を変更しない。先頭を切り替え元に使う場合は2クリップの選択またはつなぎ目へのドロップを使う。
- デコード済み映像のキャッシュは取得時の素材時刻も保持する。停止シークは指定時刻、再生中は移動する1シーケンスフレーム分の範囲で一致を確認し、両方が揃うまで古い時刻のフレームをトランジションへ渡さない。
