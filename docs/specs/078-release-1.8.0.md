# 1.8.0の正式配布

Issue: https://github.com/altimix/LumaStudio/issues/78

素材中心のピクセル座標・折りたたみスライダー（#70）、動画・画像・文字・図形の共通キーフレーム（#72）、入力とUI操作の統一（#73）、図形の追加前の塗りつぶし・不透明度（#74）を配布する。機能の受け入れ条件は070、072、073、074の仕様に従う。

- アプリ、ロックファイル、マニュアル、OS別ガイド、公式サイトを1.8.0に揃える。旧版の履歴は残す。
- 文章自体はクリップ全体で共有し、見た目だけをキーフレームで変更する。数値と色は補間し、フォントや有効・無効は点で切り替える。開始位置・表示時間・素材のin点・再生速度はクリップ全体の設定として案内する。
- 機能PRを個別にスカッシュマージし、配布候補のWindows / macOS CI、配布版検証、Website CI、静的解析、Codexレビューを確認する。
- 成功したCIのWindows x64 EXEとMac arm64 ZIPを使用する。タグのソースツリーとCIソースを一致させ、内蔵版数・マニュアル・Macの署名を確認する。
- 起動ガイド、HTMLマニュアル、ライセンス、メディアツールの対応ソースとビルド手順を同梱・添付し、SHA256を公開する。既存のリリースとタグを上書きしない。
- Windows未署名、Mac ad-hoc署名・Developer ID署名と公証未対応を明記する。実APIの検証とモックによる検証を区別する。
- 公開ダウンロードを再取得し、サイズとSHA256を照合する。その後に公式サイトを更新し、PCと390px幅、マニュアル検索、SEO、404、公開配布リンクを検証する。
- 音量メーターの配布版検証では、瞬間値・色・アクセシビリティ値を同じ描画フレームから取得して比較する。既知の左右振幅、許容誤差、0 dBでの表示上限、CLIP保持・停止・リセットの判定は維持する。
