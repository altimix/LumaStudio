# 編集メニューとOS別キー表示（#59）
- 上部の編集メニューから元に戻す・やり直す・コピー・貼り付け・複製・削除・全クリップ選択を実行する。対象はタイムラインのクリップで、ショートカットと同じストア操作を使う。
- 履歴なし、選択なし、クリップボードなし、ロックされた対象・貼付先では該当操作を無効にする。リンクした音声側のロックも尊重する。
- 開くと実行可能な先頭項目へフォーカスし、上下矢印/Home/Endで移動、Escapeで閉じてトリガーへ戻る。入力中の文字編集は既存のネイティブ編集とキーボードを維持する。
- MacではCtrlの表示を⌘、AltをOption、Deleteをdeleteとする。ツールバーのツールチップ・読み上げラベル、ファイル/素材/クリップ編集メニュー、操作ガイドへ反映する。Windowsでは従来のCtrl/Alt/Delete表示を維持する。
- ヘルプのショートカット一覧は引き続きWindows/Macを切り替えて参照できる。表示のみを変更し、既存のCtrl/Cmd両対応の入力判定は変えない。
