# 長尺素材とプロジェクト素材の削除


## 素材の長さ

- `makeClip` は動画・音声の素材全長を使う。タイムラインへ追加する三つの入口（追加ボタン、ドラッグ、ソースモニター）で共通。
- フレーム未満の末尾だけをシーケンスFPSに切り下げる。静止画の標準5秒とデモの演出用尺は維持する。
- 保存・入力の12時間、素材メタデータの7日という固定上限を除去する。非有限値・負値・数値表現の精度限界・素材外の参照は拒否する。
- 長尺では全体表示用の小さいズームを使える。CSSの座標上限で再生ヘッドが消えないよう、タイムライン幅は1000万px以内になる倍率に調整する。ルーラーは表示範囲前後の目盛りだけを描画し、低倍率では時間間隔を広げる。

## 素材一覧

- サムネイルか素材名のクリックで素材を選択する。Deleteキーは素材パネルにフォーカスがあるとき選択素材を削除する。削除アイコンも表示する。
- サムネイルのダブルクリック、または再生アイコンでソースプレビューを開く。追加ボタン・ドラッグによるタイムライン配置は継続する。
- タイムラインに配置済みなら素材名と使用クリップ数を確認画面に表示する。確定後、素材と全使用クリップを一つの編集履歴として取り除く。使用中のトラックにロックがあれば操作を拒否する。
- 元のファイルはPCに保持する。削除はプロジェクト内で完結し、Undo/Redoと保存・再読込に対応する。
- 消した素材のソースプレビュー、クリップボード、選択クリップ、YouTubeサムネイル参照を整理する。再生を停止し、再生ヘッドを新しいシーケンス内へ戻す。
- 検索入力・IME・モーダル中のDeleteは編集を起こさない。タイムラインにフォーカスがあれば既存のクリップ削除を使う。

## 検証

75秒の実動画でネイティブ読込、全長追加、末尾表示、保存・再読込、MP4末尾の映像と音声を確認する。13時間・9日などの長さをモデルと保存検証へ含める。素材の未使用/使用中/ロック/入力フォーカス/Undo・Redoと、元ファイルのハッシュ保持を実アプリで検証する。
