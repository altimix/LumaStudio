# 音声処理と音量に追従する波形（Issue #83）

編集タイムラインの波形は、素材ごとの最大値への自動拡大をせず、フルスケールを基準に描画する。素材の元ピークまたはノーマライズ／会話最適化後のPCMピークに、クリップ音量・音量カーブ・フェード・クリップミュートを掛ける。100%を超える描画振幅は表示枠でクリップする。トラック全体のミュート／ソロやクロストランジションの合成結果はマスター音量メーターで確認する。

処理後の波形は再生で使用する処理済みFLACキャッシュを使用する。縮小表示用のピーク索引がない初回は、処理済みファイル全体を一度走査して多段階の索引を保存する。以降の縮小表示は可視範囲に対応する索引だけを読み、細かい拡大表示は可視範囲のPCMを読み取る。同じ波形を参照する最後の表示が解除された場合、待機中・実行中のリクエストを中止し、音声処理と索引生成にも中止を伝える。別の参照が残る共有処理は維持する。絶対振幅と従来の相対波形はAPIオプションおよびキャッシュキーで区別する。音量だけの変更は取得済みピークを即座に再描画し、再デコードをしない。読込中は処理前の波形を処理後の波形として表示しない。

Windows検証で会話最適化前後・音量50%・Undoの描画像の変化を確認し、既存の正逆再生・高速再生と実MP4音声検証も維持する。

## 追加の操作性改善

波形更新中の表示と再読込ボタン、スクロールバーのダブルクリックによる全体表示／標準高さへの復帰、音量ポイントのキー操作ツールチップを追加する。プログラムモニター上の映像・テキスト・図形を覆う常設ナビ表示は廃止し、既存のツールチップとプロパティの説明を使用する。選択枠と実際の吸着ガイドは維持する。
- プロパティのスライダーは24pxの操作領域と20pxのつまみを維持し、現在値までの色分けを表示する。値を変更すると色分けも追随する。
- 未処理かつオンラインの素材は、詳細読込の待機中やブラウザープレビューで保存済みの概要波形を可視範囲へ再サンプルして表示する。従来の素材ごとの相対スケールなので「概要波形」と明示し、詳細読込後は絶対ピークへ置き換える。処理後・オフラインには元の概要を流用せず、詳細読込ができない環境には再読込ボタンを表示しない。
