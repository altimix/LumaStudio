# 左手用ショートカットとヒストリー


## キー配置

| キー | 動作 |
| --- | --- |
| 1 / Space | 再生・停止。通常再生は1倍 |
| Z | 再生ヘッドで全トラックに編集点を追加。ロックは除外 |
| Q / W | 前の編集点から再生ヘッドまで / 再生ヘッドから次の編集点までをリップルトリム |
| A / S | タイムラインを拡大 / 縮小。+ / −も維持 |
| Shift+D / Shift+Delete | 選択したクリップをリップル削除（削除したトラックごとに詰める） |
| E / Left、R / Right | 1フレーム戻る / 進む。Shift併用で10フレーム |
| J / K / L | 逆方向 / 停止 / 順方向シャトル |
| Ctrl+Z / Ctrl+Shift+Z | Undo / Redo。Ctrl+Yも維持 |
| N | スナップ切替。旧Sの割り当てを移動 |

## リップルトリム

- 編集点は全クリップの開始・終了とシーケンス先頭・末尾。再生ヘッドと同じ位置は除外し、指定方向に最も近い点を使う。
- 対象区間を全トラックから除き、後続クリップを同じ時間だけ前へ移動する。区間をまたぐクリップは必要に応じて分割し、残った素材の参照位置、再生速度、テロップの不透明度曲線を維持する。
- 区間内のマーカーは区間先頭にまとめ、以後のマーカーは同じ時間だけ移動する。
- 変更されるロック済みクリップがある場合は、同期を保つため操作全体を拒否して通知する。2000クリップ上限も部分的に変更せず拒否する。
- Qはシーケンス先頭、Wは末尾で何もしない。1回の操作が1回のUndoで戻る。保存形式はversion 1のまま。

## シャトルと入力保護

- 同じ方向を押すごとに1、2、4、8、16倍。長押しの自動リピートでは加速しない。反対方向は1倍から再開。
- 再生ヘッドはフレーム更新ごとに速度・方向を反映し、先頭・末尾で停止する。Jを先頭で押すと末尾から、Lを末尾で押すと先頭から再生する。
- 1.3.0以降は[007 シャトル音声](007-shuttle-audio.md)に従い、正逆・全倍率で音声を再生する。映像は必要に応じてフレームをシークして表示する。書き出しの再生速度には影響しない。
- テキスト入力、IME変換中、Alt併用、モーダル・メニュー表示中、タイムラインのドラッグ中は編集ショートカットを発火させない。矢印/E/Rとズーム以外は長押しで繰り返さない。
- Ctrlの既存操作と単キー操作を区別する。ショートカット画面から機能名・検索語・キーを検索できる。

## ヒストリー

- ウィンドウ → ヒストリーで常設パネルを切り替える。保持中の過去・現在・やり直し先を一覧表示し、任意の状態へ移動できる。
- 最大80操作。過去に戻ってから新しい編集を行うと、その先のやり直しを破棄する。プロジェクトを開き直すと履歴をリセットする。
- ドラッグをEscapeで取り消した場合は、操作前の履歴・やり直し・変更済みフラグを維持する。

`src/shortcuts.test.ts` でキー競合、Q/Wの素材参照・キー・同期・ロック・上限、シャトル、履歴を検証する。`scripts/verify-shortcuts.cjs` はWindowsアプリの実キー入力、入力欄・IME保護、検索、履歴、保存再読込と6秒MP4出力を検証する。既存のパッケージ検証に追加しWindows CIで実行する。
