# 新規トラックを既存素材の外側へ追加

Issue: https://github.com/altimix/LumaStudio/issues/141

新しく作る映像トラックはトラック一覧の先頭、音声トラックは末尾へ追加する。手動追加、重なったクリップの自動退避、動画の音声分離で共通の規則にする。上側の映像と下側の音声が外へ増え、既存トラックの間には挿入しない。

素材一覧の「タイムラインに追加」・カードの＋・素材プレビューの追加・タイムラインへの素材ドラッグは、毎回専用の新しいトラックを作って再生ヘッド（スライダー）の現在位置へ配置する。ドロップ座標や既存トラックの空き区間には配置しない。既存クリップの移動・リップルは行わない。

映像・画像は字幕がなければ最上段へ追加する。テキストを持つテロップ（kind: title、図形を除く）がある場合は、そのテロップを含むVideoトラックのうち最も下側の直下へ追加し、字幕を前景に保つ。字幕と映像が混在するトラックも対象とし、現在位置以外にある字幕や非表示・ロック中の字幕も保護する。音声は最下段へ追加する。音声付き動画は映像・音声の専用トラックをそれぞれ作り、同じ開始時刻でリンクする。

タイムラインへ外部ファイルをドロップした場合は、読み込み開始時の再生ヘッド位置を捕捉して、読み込み後に同じ位置へ一括配置する。複数ファイルはファイル順を保って各素材専用のトラックに追加し、1回のUndoで配置と追加トラックを戻す。素材パネルへのファイルドロップと通常の読み込みは素材一覧への登録を行う。

内蔵BGMも再生ヘッド位置の専用最下段Audioトラックへ追加し、同じ操作内の繰り返しクリップは1本の専用トラックへ並べる。図形と同時に新しく加える効果音も専用最下段Audioトラックへ配置し、24本上限なら図形を含む操作全体を拒否する。

手動のクリップ移動・コピー・貼り付け、テロップ作成、既存動画の音声分離はそれぞれの編集操作として維持する。これらで新規トラックが必要な場合は外側へ追加し、空き区間の再利用を維持する。

既存トラックの相対順序・ID・カスタム名、既存クリップの位置、タイミング、ミュート・ソロ・非表示・ロックを保持する。自動名は中心から Video1/Audio1 と数え、外側へ Video2/Audio2 と増やす。新しい重複回避トラックには元トラックの再生・表示設定を引き継ぐ。

複数トラックのクリップを一括コピー・移動して新規トラックが複数必要になる場合は、追加分も元のトラックの上下順に並べる。映像・画像・テロップの背景だけが重なって外側へ移るときは、同じ選択範囲の前景も外側へ配置し、元の前後関係を保持する。Videoトラック上の音声だけが移っても映像の前後関係は変わらないため、空いている前景を移動しない。クリップの作成順や一部だけの衝突で前景と背景の重なりを逆転させない。前後関係を維持すると24本を超える場合は、一括操作全体を拒否する。

AVリンクの同期、24本の上限での原子的な拒否、1回のUndo/Redo、保存・再読み込みを維持する。重なったAVの追加・コピーで映像が最上段、音声が最下段になることと、既存トラック・クリップが変わらないことを検証する。
