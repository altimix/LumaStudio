# 新規トラックを既存素材の外側へ追加

Issue: https://github.com/altimix/LumaStudio/issues/141

新しく作る映像トラックはトラック一覧の先頭、音声トラックは末尾へ追加する。手動追加、重なったクリップの自動退避、動画の音声分離で共通の規則にする。上側の映像と下側の音声が外へ増え、既存トラックの間には挿入しない。

配置先を指定したクリップや、再利用できる空き音声区間には従来どおり配置する。新規トラックが必要な場合に上記の規則を適用する。素材追加のたびに不要な空トラックを作らない。

既存トラックの相対順序・ID・カスタム名、既存クリップの位置、タイミング、ミュート・ソロ・非表示・ロックを保持する。自動名は中心から Video1/Audio1 と数え、外側へ Video2/Audio2 と増やす。新しい重複回避トラックには元トラックの再生・表示設定を引き継ぐ。

AVリンクの同期、24本の上限での原子的な拒否、1回のUndo/Redo、保存・再読み込みを維持する。重なったAVの追加・コピーで映像が最上段、音声が最下段になることと、既存トラック・クリップが変わらないことを検証する。
