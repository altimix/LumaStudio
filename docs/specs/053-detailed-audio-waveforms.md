# 音声タイムラインの高精細な波形

Issue: #53

メイン音声、ミュージック、ナレーション、効果音のすべてで、表示区間と拡大率に応じた実ピークを描画する。素材全体の固定240点を引き伸ばす表示を置き換える。

- 原音声の全チャンネルを48 kHzで読み、各時刻の最大絶対値を保持する。逆位相の左右チャンネルを合成して打ち消さない。
- フルスケールを超える浮動小数点音声もクリップせず、32 bit浮動小数点のピークを保存する。音源全体の最大ピークで表示時に正規化し、ピーク1.0と2.0の大小関係も保つ。キャッシュ形式を更新し、以前の整数キャッシュと混在させない。
- 1 msのピークと16倍ずつ粗くした階層をディスクへストリーム保存する。全PCMはメモリやプロジェクトへ保持しない。概要の2048点のみ既存の保存形式へ格納する。
- 表示の1ピクセルに相当する素材時間が1 ms未満なら、その短い区間を原音声から再集計する。長いクリップでも拡大時の精度を下げない。
- 波形の高さは音源全体のピークを基準とする。同じ音源の無音部や静かな区間を、表示区間ごとに拡大し直さない。波形は原音の形、音量ラインは適用する音量を示す。
- Canvasは画面に見える幅と小さい余白だけを生成し、DPIを考慮する。1取得8192点、同時取得2件、保持128件を上限とし、スクロールで不要になった待機取得・古い応答を破棄する。
- clip.in・speed・durationから素材時刻へ変換する。分割、トリム、レート変更、横スクロール、再読込、再リンクに追従する。
- 原音のパス・サイズ・更新時刻からキャッシュを識別する。旧プロジェクトの240点概要も読み込め、メディア再検査で詳細キャッシュを作成する。
- 音声レーンの表示高さを広げ、音量ラインと波形を併せて操作できる。細部を準備する間は概要を表示する。
- 画面処理が一時的に遅れても音切れしにくいよう、0.8秒先まで短いPCMブロックを予約する。開始の余白は30 msのまま、停止・シークでは予約を即座に取り消す。500 msのUI遅延でも正逆両方向でPCMが連続することを検証する。

実ファイルの72秒ステレオ音源で、1分以降の20 msの発音・無音部、逆位相、細かい倍率、素材in点・速度による参照区間、キャッシュ再生成、不正IPCを検証する。Windowsパッケージで各トラックのCanvas、ズーム、スクロール、音量ラインとの共存を確認する。

スクロール位置のオブジェクトを全クリップへ渡さず、クリップ内の256 px単位の表示範囲を数値で渡す。画面外は常に0／0とし、React.memoが不要なクリップ更新を省略できるようにする。素材ID・トラック別クリップ・選択IDの索引も再利用し、スクロールごとの繰り返し検索を避ける。2,000クリップで微小移動・タイル境界・大きいジャンプ時の更新範囲を検証する。
