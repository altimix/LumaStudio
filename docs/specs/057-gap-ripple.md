# 空白のリップル削除


## 操作と対象

タイムラインのトラックの空白を右クリックして「空白をリップル削除」を選ぶ。トラックにキーボードフォーカスを移してShift+F10を押した場合は、再生ヘッド位置の空白を対象とする。メニューに開始・終了のタイムコードと秒数を表示し、対象区間を全トラックでハイライトする。右クリックだけでは再生ヘッドと選択クリップを変更しない。再生は停止する。

対象は、クリックしたトラックにおける直前のクリップの終了（先頭なら0秒）から直後のクリップの開始まで。重複クリップは占有区間の和として判定する。フレーム境界は終了を含まない。クリック位置にクリップがある場合、末尾の余白、空トラック、無効な時刻では削除できない。

## 全トラックの時刻変換

対象区間を `[from, to)`、長さを `d = to - from` とする。非表示・ミュートを含む全トラックで同じ時間を取り除く。

- `from` 以前に終わるクリップは変更しない。
- `to` 以後に始まるクリップは開始を `d` 秒早め、素材in点・長さ・速度・効果を保持する。
- 区間と重なるクリップは区間外の部分を残す。両側に残る場合は分割し、右側の素材in点を速度に応じて進める。新たな切断面にフェードは付けない。元の音量・不透明度カーブの対応区間を保持する。
- 区間内だけにあるクリップは削除する。メニューはBGM・字幕等に対するこの動作も説明する。
- 映像と音声のリンクを維持し、分割後は左右それぞれ独立したペアにする。元の外側のつなぎ目を適切な断片へ接続し直す。接続条件を満たさなくなった効果は既存の検証処理で除外する。
- マーカーと再生ヘッドは、区間内なら`from`、区間後なら`d`秒前へ移す。削除後の再生ヘッドは動画末尾を超えない。

ロック中のトラック上でクリップの削除・分割・移動が必要なら、操作全体を拒否しトラック名を表示する。区間より前だけにあるロック済み素材は妨げない。ドラッグ中や上限2000クリップを超える操作も変更を行わない。

編集は1回の履歴にまとめる。Undo/Redoで元の配置・カーブ・リンク・効果と編集前後の再生ヘッドを復元する。元素材のファイルは変更しない。保存形式は変更しない。文字起こしなどの生成情報は従来の音声タイムライン一致判定で古い結果を検知する。

## メニュー

スクロール量と現在のズームからクリック時刻を求める。メニューを画面内に収め、Esc・Tab・外側クリック・ウィンドウのフォーカス喪失・プロジェクト変更で閉じる。開いている間はZ/Delete/Home/End等が通常のタイムライン操作へ伝わらない。古いメニューから別プロジェクトを編集しない。既存のクリップとつなぎ目の右クリック操作を維持する。

## 検証

`src/gap-editing.test.ts` は空白の検出、先頭・末尾・1フレーム、重複、無効値、全トラックの移動・区間分割、ソース位置、カーブ、リンク、効果、ロック、容量、履歴を検証する。

`scripts/verify-gap-ripple.cjs` はWindowsアプリで右クリック・キーボード・ハイライト・キャンセル・スクロール・ズーム・既存メニュー・ロック・Undo/Redo・保存再読込・正逆再生・MP4出力を検証する。出力の長さ、前後の映像の画素、実音声を確認し、`gap-ripple-verification.json` と `timeline-gap-ripple.png` を保存する。全23本のpackaged検証に含める。

前詰め後のモノラルAACに音量カーブがあるケースで、FFmpegのチャンネル別計算の異常終了を検出した。出力のステレオ構成へそろえてから音量を計算する。`tests/volume-automation.test.cjs` でモノラルAACを使った分割後のWAV/MP4とカーブなしの基準音量を比較する。
