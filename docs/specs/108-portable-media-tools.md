# Windowsポータブル版のメディアツール

Issue: https://github.com/altimix/LumaStudio/issues/108

WindowsポータブルEXEは実行時に一時フォルダへ展開される。アプリ起動時に、同梱FFmpegとFFprobeのSHA-256を照合し、アプリのユーザーデータ内のバージョン・内容別フォルダへコピーする。その起動中の映像・音声処理は、この永続フォルダの実行ファイルを参照する。一時展開先が消えても、タイムラインの音声チャンク再生、波形、サムネイル、書き出しを継続できる。既存キャッシュが正しい場合はコピーしない。更新で内容が変わった場合は別フォルダを使用する。

同梱バイナリが読めない場合は配布EXEの再取得を、コピーに失敗した場合は保存先の空き容量とアクセス権を日本語で案内する。実行中に同梱バイナリが消えた場合も、英語の `spawn ENOENT` をそのまま見せず再取得を案内する。ユーザーの素材やプロジェクトを移動・変更しない。macOS版とWindowsの展開済み開発版は従来の同梱パスを使う。

回帰検証では一時展開先の削除後にコピー済みツールが残ることを確認し、Windowsの配布EXEに両バイナリが含まれることを確認する。Windowsで実際に書き出したMP4を再取り込みし、音声チャンクのデコードまで確認する。
