# 再生ヘッドの全移動経路を追従


1.4.1の再生中の追従を、1.4.2で停止中の移動とマウス操作へ拡張する。表示制御は `usePlayheadViewport` に集約し、個々のボタンにスクロール処理を追加しない。

## 移動経路の監査表

| 入口 | 移動を行う箇所 | 追従する条件 |
| --- | --- | --- |
| J/L、1/Space、再生ボタン、自動停止 | Previewの音声時計・storeのtransport | 全倍率・両方向・最終フレーム |
| Home/End、E/R/矢印、Shiftで10フレーム | Appのショートカットからseek | 停止中・同じ時刻への再指定も追従 |
| プレビューの先頭/末尾/コマ送りボタン | Previewからseek | キーボードと同様 |
| マーカー | Timelineからseek | クリックとキーボードによるボタン操作 |
| クリップのEnter | ClipItemからseek | クリップ先頭を表示 |
| 不透明度キーフレーム | TitleOpacityからseek | 対象クリップ内の指定時刻を表示 |
| 字幕原稿のジャンプ | YouTubeStudioからseek | ダイアログを閉じて指定時刻を表示 |
| 素材をタイムラインへ追加 | store.addAsset | 追加されたクリップ先頭を表示 |
| Q/Wのリップルトリム | store.rippleTrim | 新しい再生位置を表示 |
| Undo/Redo/ヒストリー | store.restoreHistory | 復元した状態の再生位置を表示 |
| 新規/開く/再読込/復元 | store.load | 同じプロジェクト・同じ時刻でも表示を更新 |
| 再生ヘッドのつまみ・空いているトラック上の縦線、ルーラー、空トラックのドラッグ | usePlayheadViewport.scrub | 左右端で連続スクロール、縦スクロール中も縦線をつかめる |
| A/S、ズームボタン/スライダー/Ctrlホイール/全体表示 | zoomと表示幅の変化 | 停止中も表示内を維持 |
| ウィンドウ幅・パネル幅の変更 | ResizeObserver | 停止中も表示内を維持 |
| 追従OFF→ON、「再生ヘッドを表示」 | Timelineの表示操作 | 停止中も現在位置へ戻る |

## 表示規則

- 追従ONが標準。再生位置が変わる、明示的に同じ位置を指定する、ズームや幅が変わると表示内へ戻す。移動方向は実際の時刻差を使い、再生中はシャトル方向を使う。
- 明示的なseekには保存されない `seekRevision` を付ける。位置の数値が変わらないHome/Endなどでも表示を更新する。load、素材追加、リップルトリム、履歴復元も対象。
- 端へ近づいた場合のページ送りと余白は011の仕様に従う。移動先を含む表示幅を確保し、素材末尾より後の配置用時刻でも表示からはみ出さない。
- 停止中にスクロールバーやホイールで表示だけを動かす場合は、再生位置を変えず、表示を引き戻さない。追従OFFではキー移動やズームでも自動表示しない。「再生ヘッドを表示」は常に使える。
- クリップ長の編集やタイムラインの高さだけの変更など、時刻・表示倍率・表示領域の幅が変わらない操作では、停止中に手動で選んだ表示範囲を保持する。ResizeObserverとウィンドウのresizeは実際のclientWidthの変化を確認する。
- 横スクロールだけを変え、縦位置・トラック名・編集データ・Undo履歴を維持する。

## ポインター操作

- 左ボタンで停止して移動を開始する。ドラッグ中はポインターに位置を合わせ、通常のページ送りを抑える。
- 縦線の描画はクリックを遮らない。空いているトラック上の縦線には9pxのドラッグ領域を設け、同じ位置のクリップ選択・移動・トリミング・レーザーツールを優先する。
- 3px以上動かして左右端48px（表示幅の12%以下）に寄せると、requestAnimationFrameで連続スクロールする。速度は端への近さに比例し最大1200px/秒。ポインターを止めても続く。
- ポインターがタイムラインの左右外へ出た場合は、表示範囲内のフレームへ再生位置を制限する。スクロールと時刻更新を同じフレームで処理する。
- pointer captureを使い、pointerup、pointercancel、lostpointercapture、Escape、ウィンドウのblur、documentの非表示化、コンポーネント破棄でRAFとイベントを解除する。終了後に勝手に時刻が進まない。
- ドラッグ中はgestureActiveで編集ショートカットを抑止する。操作終了後に解除し、通常のキー操作へ戻す。

## 検証

`verify-playhead-navigation.cjs` で実際のキー、ボタン、マウスを使って各経路と終了処理を確認する。DOMの表示位置と時刻を検査し、storeや再生時計はテスト用に差し替えない。`verify-timeline-follow.cjs` のJ/L全10通りと音声等の既存検証も維持する。配布EXEは9本の実アプリ検証を通す。
