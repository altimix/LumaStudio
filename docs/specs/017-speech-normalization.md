# 017 会話音声の自動調整


## 操作と保存

- 音声付きのクリップのオーディオ欄に「音声の自動調整」。既定は「会話を聴きやすく」、代替は「音量をそろえる」。解析後に選択クリップへ一度の履歴で適用する。
- 元素材全体の音を解析する。会話は80Hzハイパスと緩やかな3:1コンプレッション、両モードともラウドネス目標−16 LUFS、True peak上限−1.5 dBTP。会話LRA7、一般LRA11。FFmpeg loudnormの測定値を使う2パスと出力測定を行い、目標からの差はピーク余裕内の一定ゲインで補正する。
- 解除・Undo/Redo・ロック・保存/再読込を維持。音量/フェードは処理済み音声に後段で反映する。他トラックとの合成・速度変更後の最終LUFSは素材単体の目標と異なる。
- 中止や失敗時はクリップを変更しない。処理中に素材/プロジェクトが変わった場合も古い結果を適用しない。無音・測定できない短い音声・過小音声は具体的なエラーを表示する。

## 音声経路

- `audioTreatment?: 'speech' | 'normalize'` を非破壊の設定として保存。任意パスや任意フィルターはIPCで受け付けない。既存プロジェクトの未設定は原音のまま。
- 原本パス/サイズ/更新日時/方式/処理版からキャッシュキーを作り、48kHzステレオFLACを一時ファイルから完成後に置換する。サンプル時間の原点を維持し、音声開始の遅延も保持する。
- PCMキャッシュは原音と各処理方式を区別する。同じ処理済み音声を通常/逆再生/全シャトル速度、MP4、文字起こしの共通入力にする。書き出しが未準備の処理を黙って省略することを禁止する。
- 音声キャッシュはローカルで再生成可能。最大2つの処理を共有し、参照中の他の処理を中止で巻き添えにしない。動画全体をメモリに読み込まない。長時間素材は初回処理時間とキャッシュ空き容量が必要。
- 文字起こしの古さ判定に処理方式を含める。未設定の既存ハッシュは維持する。

## 検証

- 実FFmpegで大小差の改善、ラウドネス/ピーク、原本ハッシュ、ステレオと時間の維持、キャッシュの分離/再生成/無音/中止を確認する。
- Windows実アプリで適用・解除・履歴・ロック・保存を操作する。既存のPCM捕捉テストを処理済み音声でも実行し、J/K/L・全10速度・8秒境界・トリム/速度/ゲイン/フェード/ミュート/ソロ、AAC書き出しを比較する。
- フィルター仕様: https://ffmpeg.org/ffmpeg-filters.html#loudnorm / https://ffmpeg.org/ffmpeg-filters.html#acompressor
