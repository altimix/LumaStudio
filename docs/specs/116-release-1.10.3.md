# 1.10.3の正式配布

Issue: https://github.com/altimix/LumaStudio/issues/116

Issue #110の初回成果である計測基盤、H.264の小さいモザイク・ガウスぼかしの範囲合成高速化、同じ素材の連続分割・カット切り替えの合成省略を配布する。機能ごとの適用条件と出力検証は `110-export-mosaic-performance.md`、`110-cut-export-performance.md`、`110-gaussian-region-performance.md`、`114-export-benchmark-suite.md` に従う。GPUデコード、永続キャッシュ、再圧縮省略はこの版には含めない。

- アプリ、ロックファイル、HTMLマニュアル、Windows / Macガイド、公式サイトを1.10.3へ揃え、1.10.2までの更新履歴を残す。
- Apple M2 Proの同梱デモ2秒・960×540・24 FPS・CPU標準品質を5回測った例のみ条件付きで紹介する。全PCや素材で同じ倍率は保証しない。
- モザイクとカットでは完成MP4の画素ハッシュが旧版と異なることを隠さない。フレーム数・長さ・48 kHz PCM音声は一致し、連続分割の新映像は無加工の単一クリップ出力と一致した。ガウスぼかし単独は完成フレームの画素ハッシュも一致した。
- リリースPRの同一コミットでWindows / macOS CI、パッケージ版操作検証、Website CI、Codexレビューを確認する。WindowsポータブルEXEでは展開元を削除した後の書き出し、再取り込み、音声再生を再確認する。
- 最終ソースに一致するCI由来のWindows x64 EXEとMac arm64 ZIPを使い、内蔵版数、ガイド、Macの署名、SHA256、メディアツールの対応ソースを照合する。
- 起動ガイド、HTMLマニュアル、ライセンス、メディアツールの対応ソースとビルド手順、SHA256をv1.10.3のGitHub Releaseに添付する。既存タグとリリースは上書きしない。
- Release公開後に公式サイトを配備し、PC / 390px幅、マニュアル検索、SEO、404、配布リンクとチェックサムを本番で確認する。公開と確認が完了してからIssue #116を閉じる。
