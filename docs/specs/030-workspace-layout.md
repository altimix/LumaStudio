# 編集画面のレイアウト

Issue: #30 / 先行機能: #28（写真保存）

## 素材パネル

- 「追加」メニューに「素材を読み込む」と「ブラックビデオを追加」をまとめる。
- 常設の大きい読み込み領域を取り除き、素材がない場合だけ一覧内にファイル選択の案内を表示する。ファイルのドロップはウィンドウ全体で引き続き受け付ける。
- 読み込み・ブラックビデオ作成中の進捗を表示し、同時実行を防ぐ。
- メニューはキーボードで開閉・移動できる。メニュー内のキーを編集ショートカットに渡さない。
- 素材のリスト／グリッド、検索、フィルター、選択、削除、追加、プレビューは維持する。

## パネルの幅とタイムラインの高さ

- 素材パネルとプロパティパネルの境界をドラッグして幅を変えられる。
- 各パネルの折りたたみボタンで細い再表示用のバーへ切り替える。折りたたんでも素材の検索などの状態を維持する。
- タイムラインとの境界をドラッグして高さを変えられる。
- 境界はTabでフォーカスでき、左右／上下矢印で10px、Shift併用で40px、Home／Endで最小／最大へ変更する。ドラッグ中のEscは変更前の表示サイズに戻す。
- 幅・開閉状態・高さはアプリのUI設定として保存し、再起動後にも復元する。プロジェクトデータ、未保存表示、Undo/Redoには含めない。
- localStorageの `luma.workspace-layout.v1` にバージョン付きで保存する。破損・未対応バージョンは初期値へ戻し、不正な個別値は初期値または範囲内へ補正する。保存不可でも操作を続けられる。
- 初期値は左288px、右286px、タイムライン354px、両パネル表示。左右の下限は248px／264px、上限520px。タイムラインは238〜1200pxの範囲で画面に収める。
- ウィンドウを縮める場合は、プレビュー幅400px・上部作業領域高さ280pxを確保するよう表示サイズを調整する。保存した希望サイズは画面縮小だけでは書き換えず、画面を戻すと復元する。アプリの最小ウィンドウサイズは従来の1100×720を維持する。
- 「ウィンドウ」メニューで各パネルの表示を切り替え、レイアウト全体を初期状態に戻せる。
- 片側の幅を変更しても、反対側の希望サイズは書き換えない。狭い画面では最後に調整した側を優先して収め、ウィンドウを広げたときに反対側の幅が戻る。最後に調整した側もUI設定に保存し、再起動後の配置を維持する。

## 読みやすさと導線

- 素材名・検索・数値欄は12px、主要な補助文字は11pxを基準にし、暗い背景で判読できる文字色へ調整する。
- タイムラインを最小高さにした場合も、音量メーターの目盛りと最大値を表示する。代替フォントに切り替わる環境でも下端まで収まるよう行の高さを揃える。
- 狭いパネルでもタブの名称を表示し、ファイル名やメタデータは領域からはみ出さない。狭いプレビューでは再生操作を2段に並べる。
- テキストテンプレートへの入口は左の「テキスト」タブ。上部の重複する「テキスト」ボタンは取り除き、上部は「編集」「カラー」「オーディオ」「YouTube」とする。
- 上部ワークスペースや使い方ガイドから編集へ移る操作では必要なパネルを表示する。プロパティからエフェクトを開く操作でも素材パネルを表示する。
- クリップの右クリックにある「プロパティを開く」「音量を細かく調整」などの明示的なプロパティ操作は、同じタブが選択中でも折りたたみを解除する。通常のクリップ選択だけでは勝手に開かない。

## 受け入れ確認

設定値の検証・画面内への配置の単体確認に加え、実際のパッケージでメニュー、マウス／キーボードでのサイズ変更、折りたたみ、再起動後の復元、画面縮小と復元、初期化、テキストの追加を確認する。プロジェクトの未保存状態とUndo/Redoを変えず、素材の読み込み・ブラックビデオ・写真保存の既存検証も通す。
