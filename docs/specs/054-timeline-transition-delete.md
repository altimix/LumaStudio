# タイムライン上でつなぎ目の効果だけを削除

Issue #54。タイムラインのトランジションを右クリックし、「トランジションを削除」を実行する。フォーカスしているトランジションのDelete / Backspace、Shift+F10のメニューにも対応する。

前後のクリップ、開始時刻・素材in点・尺・音量・動画全体の長さは維持する。映像効果と音声効果を一つの接続にまとめている場合は、接続の効果をまとめて外す。Ctrl+Z / Ctrl+Shift+Zで戻せる。

トラックのロックを保護し、削除キーが素材の削除に伝わらないようにする。メニューは画面内へ配置し、矢印・Home / End・Enterで操作でき、Escape・Tab・外側クリックで閉じる。プロジェクトの切替や編集で対象が変わったメニューは閉じる。

Windows検証では、映像・音声・両方の効果、右クリック、Delete / Backspace、キーボードのメニュー操作、小さい画面、ロック、保存・再読込、Undo / Redoを確認する。
