# 092 重なりを避けるトラック自動作成

Issue: #92

素材追加、図形、字幕、貼り付け、複製、ドラッグ移動で配置が重なる場合、操作した素材を新しいトラックへ移す。開始時刻と長さ、素材のin点、リンク同期は変更しない。端の接触は重なりではない。

複数の素材は元のトラックごとにまとめ、重ならない字幕の列などは同じ新規トラックを共有する。グループ内も重なる場合は必要な本数に分ける。新規トラックは元のトラックの隣に作成し、表示・ミュート・ソロ設定を継承する。

ドラッグではマウスを離した時に新規トラックを作る。ドラッグ途中のレイアウトは固定し、Escや失敗では操作全体を戻す。Undo/Redoは素材と自動追加トラックを一緒に戻す。ロックと24本の上限を保護し、失敗理由を表示する。

保存済みプロジェクトの読込や、音量・文字・見た目だけの変更で既存の重なりを変更しない。トリミングとトランジションの専用操作は対象外とする。

音声付き動画を追加するときは、分離音声の時間帯が空いている音声トラックを再利用する。ロックされておらず、元映像トラックとミュート・ソロ設定が同じ場合に限る。専用名のトラックを優先し、空きがなければ新規作成する。音声に不要なトラックを消費して、映像の重なりを分離する最後の1本が使えなくなることを防ぐ。明示的な既存映像の音声分離は従来の専用トラックとトランジションを維持する。

自動字幕の再適用では、以前の字幕の先頭があるトラックを基準にし、空になった以前の字幕トラックを再利用する。フレーム丸めによる重なりがあっても、再適用でトラックが増え続けない。

元トラックの既存素材を固定し、同時に重なる素材数が最大になる区間を調べて、元の段に残す素材を選ぶ。元トラックごとの追加トラック数が最小になるよう組み分けし、単純な先着順で空きを使い切らない。小規模な300パターンの全組み合わせによる最小解と比較検証する。字幕の時刻・長さが同じ更新では前の字幕ごとの配置先を優先する。
