# 素材収集と一括再リンク（#56）
- ファイル →「素材をまとめて保存」で、選択したフォルダ内に固有名のフォルダを作り、使用中の素材原本と project.luma を保存する。字幕サムネイル素材も対象。未使用素材と生成キャッシュは含めない。
- コピーが完成した一時フォルダを最後に移動する。失敗時はその一時フォルダだけを除去する。既存のプロジェクト・元素材・現在の編集は変えない。
- media/ 内の相対参照はプロジェクトファイル基準で解決し、フォルダごと別PCへ移動できる。再保存時に相対参照を再計算し、別の場所への保存では絶対パスに戻す。互換性のため従来の絶対参照も読み込める。
- 「フォルダから一括再リンク」は選択したフォルダ直下の同名ファイルを対象とする。名前・種類・長さ・音声有無・サイズ・解像度を検証し、候補が複数または不適合なら未接続のまま理由を通知する。既存の単一再リンクで手動指定できる。
- 完了した再リンクをひとつのUndoとして反映し、クリップの区間・IDを保持する。素材の内容まで同一であることは保証しないため、復旧後はプレビューを確認する。
