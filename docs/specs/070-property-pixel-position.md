# 中心座標のピクセル入力と数値スライダーの折りたたみ

Issue: #70

トランスフォームの「位置 X / Y」は動画・画像・テキスト・図形で共通のピクセル表示とする。シーケンス左上が (0, 0)、Xは右向き、Yは下向きで、素材の中心位置を表す。1920×1080の中央は (960, 540)、1080×1920の中央は (540, 960)。元素材の解像度やプレビュー画質・表示倍率によって座標基準を変えない。

表示は `x × シーケンス幅 / 100 + シーケンス幅 / 2` とYの対応する式を使う。入力時はその逆変換を行い、保存形式・プレビュー・書き出しには従来の中心からの移動率を使う。入力と数値欄の左右ドラッグは1px刻みとし、既存の小数座標は読み込み・表示だけでは丸めない。位置の範囲は従来の−200〜200%に相当する幅・高さの−1.5〜2.5倍。リセットは画面中央へ戻る。

数値欄に付属するスライダーは初期状態で折りたたむ。数値欄と単位は常に表示し、隣のボタンから個別に開閉する。位置・開始時間・長さなど元々スライダーのない欄には開閉ボタンを追加しない。対象はトランスフォーム、フェード、音量、カラー、文字サイズ、クロップ・マスク・クロマキーの共通数値欄。画面内で開閉状態を保持し、プロジェクトには保存しない。

ボタンは開閉状態と対象を支援技術へ伝え、Enter / Spaceでも操作できる。閉じたスライダーはTab移動や読み上げの対象にしない。開閉だけで編集履歴や未保存状態を変えず、数値入力・左右ドラッグ・開いたスライダー・Undo / Redo・トラックロックを維持する。

配布版検証で横型と縦型、低画質プレビュー、画面外座標、入力とドラッグ、保存再読込・実MP4出力、数値スライダーの開閉・キーボード操作・履歴を確認する。
