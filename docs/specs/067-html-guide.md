# HTML操作ガイドと全ショートカット一覧


## 対象

v1.14.0の利用者向けに、日本語の `README.html` をリポジトリ直下へ追加する。既存HTMLは正式リポジトリと旧作業フォルダのどちらにも存在しなかったため、新規作成する。アプリの編集・保存・再生処理とバージョンは変更しない。

## 内容

- 実装済みのモニター直接操作、V範囲選択、リンク編集、空白削除、固定長トランジション、音量ライン、高精細波形、BGM、テキスト枠・効果、図形、字幕・YouTube生成、保存・GPU出力を説明する。
- `EditorCommand` 全35件を別キーを含め1コマンド1行で掲載する。通常のキー、場面別のキー、マウス操作、キー未割り当ての機能を分け、機能名やキーで検索できる。
- Deleteの対象、Enter・矢印・Home/Endの局所操作、F2・Ctrl+Enter・Shift+F10・Esc、入力中の抑止、Q/Wとリップル削除の対象範囲を説明する。
- レート調整にRを割り当てた説明など、実装されていないキーや機能を掲載しない。キーのカスタマイズは未実装と明示する。
- HTMLは外部リソース不要。JavaScript無効でも全文を読み、印刷できる。検索・種類の絞り込み・結果件数・解除・該当なし表示を用意する。印刷時は検索状態にかかわらず全コマンドを表示する。
- 狭い画面は表をカード状に表示し、ページ全体の横スクロールを避ける。列見出しは視覚的に隠してもアクセシビリティツリーに残し、全データセルに列の表示ラベルを付ける。キーボードフォーカス、ラベル、見出し、表のヘッダー、結果件数の通知に対応する。
- README.mdから案内し、音量キーフレームの未実装表記とV選択時の空白ドラッグの古い説明を修正する。次回のパッケージとCI配布物にHTMLを含める。

## 検証

`npm run verify:readme` はHTMLのバージョン、内部リンク・ID、HTML/CSSからの別ファイル参照、35件の全コマンドとキー別名を実装から照合する。画像・スクリプト・CSSリンクに加え、音声・動画・iframe・source・SVG・poster等の読み込み属性、CSSのurl()/@import/image-set()も拒否する。`shortcuts.ts` をTypeScriptで読み、実際の `shortcutCommand` の戻り値とHTMLのキー表記を比較する。キー別名が新たに実装された場合も欠落を検出する。Windows CIに含める。

ブラウザーではオフライン読込、検索、種類フィルター、両者併用、ゼロ件、解除、キーボード操作、狭い画面、印刷で全コマンドが出ることを確認する。基本のデモ・単体/FFmpegテスト・ビルドとCIを確認し、実際のCodexレビュー後にスカッシュマージする。
