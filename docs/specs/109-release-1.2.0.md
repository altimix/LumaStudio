# 1.2.0統合リリース

Issue #16。カット・図形合成・音声境界の修正（#12 / #14）と、動画の特徴を反映する縦横サムネイル（#13 / #15）を統合する。

- Windows x64とmacOS arm64を同一のソースツリーからビルドする。必須CI、レビュー、両OSのpackage / verify:packagedを確認してから公開する。
- バージョンを1.2.0とし、操作ガイド・OS別手順・READMEを揃える。旧版の配布物は上書きしない。
- EXE / ZIPとSHA256、FFmpeg等の対応ソース・固定ソース一覧・ビルド手順・ライセンスをReleasesへ添付する。CI成果物とリリースタグのツリーが一致することを確認する。
- 編集済みプロジェクトを保存し、アプリを終了して手動で入れ替える。初期タイムラインは空、BGM001〜005は利用できる状態を維持する。
- サムネイルは16:9（1536×864）または9:16（864×1536）で、JPEGは2,000,000バイト未満。実APIでの仕上がりには生成ごとの差があり、再生数の増加を保証しない。
- 検証にAPIモックを使う場合は実APIでの画像品質確認と区別する。WindowsのGPU各社実機性能、Intel Mac対応、署名・公証は今回の完了条件に追加しない。
- 公開後に公式サイトの配布リンク・サイズとオンラインマニュアルを更新し、実際のダウンロードリンクを検証する。
