# プログラムモニターの表示倍率と枠外ベジェ編集

Issue: #80

- フィット / 25 / 50 / 75 / 100 / 200% を選べる。100%はシーケンスの1pxを1 CSS pxで表示する。画質選択、素材のトランスフォーム、出力解像度は独立する。
- ホイールとトラックパッドのピンチはポインター位置を基準に連続ズーム（1〜800%）。タッチの2本指ピンチも中点を固定する。ページズーム・スクロールには伝播しない。
- フィットは周囲に24px以上の余白を残し中央に配置する。新しいプロジェクト、解像度変更時はフィットに戻す。固定倍率ではウィンドウサイズ変更後も倍率を保つ。
- はみ出した画面には下に横、右に縦のスライダーを表示する。右へ動かすと右の領域、下へ動かすと下の領域を表示する。手のひらツールの左ドラッグ、中ボタンドラッグ、タッチの1本指でも表示を移動できる。各操作は連動する。
- パンは最低32pxの映像枠を表示領域に残す。Esc / フォーカス喪失 / タッチ取消 / レイアウト変更で進行中の表示ドラッグを取り消す。フィットは位置と手のひらモードをリセットする。
- 表示状態はプレビューのローカル状態。プロジェクト、保存内容、dirty、Undo / Redo履歴には含めない。編集ジェスチャー中は表示を変更しない。
- ベジェペンの追加領域は映像枠からモニター全体へ拡張する。点・ハンドル・輪郭は映像枠外にも表示する。全ツールの座標換算は表示中の映像枠を基準とする。
- 保存座標は素材に対する正規化座標。アンカー・ハンドル共通で有限の -10〜11 を許可する。矩形・楕円マスクの既存範囲は変更しない。元の座標制限内のファイルはそのまま読み込める。ラスター処理は映像寸法に制限する。
- ベジェのキーフレームにある全6座標も同じ保存範囲を使用する。キーフレームを水平方向だけに動かすときは、時刻だけを変更し、座標の丸めや形の変更を行わない。
- 縮小表示した文字でも移動対象とサイズ変更ハンドルが重ならないよう、ハンドル配置に画面上32px以上の幅・高さを確保する。文字そのものや保存されるテキスト枠の大きさは変えない。
- 既存のShift / Ctrl・Cmd / Alt・Option、始終点結合、Undo / Redo、取消、ロック、保存、出力を維持する。

検証: ビューポートの幾何、枠外座標検証・ラスター・キー操作の単体テストと、配布アプリの `verify-preview-viewport.cjs` / `verify-bezier-mask.cjs` / `verify-preview-transform.cjs`。Windows / macOS のCIで同じ配布アプリ検証を実行する。
