# 1.5.0の正式配布と公式サイト更新

Issue: https://github.com/altimix/LumaStudio/issues/35

素材パネルの配置とトランジション長の直接操作（#33 / #34）を1.5.0として公開する。機能の受け入れ条件は `033-library-interactions.md` に従う。写真保存・フォルダの記憶など1.4.0以前の機能と変更履歴を保持する。

## 配布

- アプリ、ロックファイル、HTMLマニュアル、OS別起動ガイドのバージョンと配布名を1.5.0に揃える。
- 最新のWindows / Mac CI、配布アプリの全検証、Website CI、CodeQL、Codexレビューを確認してスカッシュマージする。
- 成功したCIのWindows x64 EXEとMac arm64 ZIPを使用し、公開タグとCIのソースツリーを照合する。バージョン、内蔵マニュアル、Macのarm64とad-hoc署名を確認する。
- 起動ガイド、HTMLマニュアル、ライセンス、固定したメディアツールの対応ソース・ビルド手順を添付し、全添付ファイルのSHA256を記録する。公開後にダウンロードとハッシュを確認する。既存タグ・リリースは上書きしない。
- Windowsの未署名、MacのDeveloper ID署名・Apple公証未対応の案内を保持する。AI検証のモック応答と実API確認を区別する。

## 公式サイト

配布物の公開後に `lumastudio-official` Workerを更新する。効果帯の両端ドラッグと4つの素材タブの改善を紹介し、1.5.0の実アプリで撮影した編集画面を掲載する。従来の解説動画、音声編集例、素材のクレジットを保持する。

PCと390px幅で全ページ・内部リンク・マニュアル検索・404を検証し、最新版の配布物へのリンクがすべて利用できることを確認する。
