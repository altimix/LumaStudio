# 091 トラックの削除

Issue: #91

トラック名の右のごみ箱ボタンから削除する。空トラックは直接削除し、素材がある場合は名前と個数を表示して確認する。キャンセル、Esc、背景クリックでは変更しない。確認中は編集ショートカットを遮断する。

対象トラック上の配置だけを削除し、プロジェクト素材と他トラックの配置は保持する。残るリンク相手はリンク解除し、関連するトランジションを除去する。時間を詰めない。Undo/Redoで復元できる。

ロックした対象、リンク相手、または別トラックにある音声トランジションの相手、最後の1本は理由付きで削除ボタンを無効にする。ドラッグ中の削除を拒否する。確定時にも再検証し、プロジェクトが変わった確認画面は無効にする。

検証: ストアの削除、履歴、選択、リンク、ロック、最後の1本、ジェスチャーのテスト。Windows実画面で空トラック、確認、キャンセル、Undo/Redoと保存再読込を確認する。
