# 093 素材端の編集とカーソル

Issue: #93

音声素材のトリムを上端18pxへ制限していた指定を廃止する。左右端の当たり判定は全高・最大12px、短い素材は幅の30%ずつとして中央の選択領域を残す。音量の線・丸はそれぞれの当たり判定で優先し、丸の時間位置と広い操作範囲を維持する。

Vは通常の矢印、素材移動中はつかむ手、Alt複製ドラッグ中はコピー。トリムは端の印付き左右矢印、レートは速度計付き左右矢印、Cはハサミ。白と暗い縁で素材の色に依存せず形を見分けられる。ドラッグ中は素材を外れてもカーソルを保持し、終了・Esc・キャプチャ消失で戻す。

Cとレートでは音量の当たり判定を無効にし、素材の操作へ渡す。Cは端も分割操作となり、端だけトリムになる不一致を防ぐ。ロックしたトラックとリンク相手、レート非対応素材は操作不可カーソルで示す。タイムライン見出しに現在のツール説明を表示し、編集オブジェクトを覆うナビは増やさない。

左右トリムとレート、音量端点、C/V、リンク・ロック、取消・履歴・保存をWindowsの実際のポインター操作で検証する。
