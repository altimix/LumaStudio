# 公開初版 1.0.0

公開先はaltimix/LumaStudio。初期取り込みは新しいGit履歴として行い、旧Issue・PR・コミットは移さない。
Windows x64 / Mac arm64に対応し、素材・タイムラインは空で起動する。BGM001〜005を選択して利用できる。

アプリはGPL-3.0-only。第三者ライセンスを保持する。FFmpegとFFprobeは共有の固定ソースからビルドし、nonfree構成を使用しない。ソースアーカイブとビルド手順を配布する。

受け入れ条件: npm ci、verify:demo、verify:readme、npm test、build、両OSのpackageとverify:packaged成功。外部開発者が公開リポジトリと公開ビルド素材だけでビルドできること。公開ファイルに認証情報・個人データを含めないこと。

初版の同梱FFmpegはNVENC・QSV・AMFを含まない。MP4はlibx264のCPU方式で出力し、自動選択もCPUになる。GPU書き出しは再配布可能な依存構成と対応ソースを整備した後に追加する。

- Windowsの絶対パスを含む保存プロジェクトをMacで開いた場合、素材をオフラインとして保持し、編集内容を失わず再リンクできる。Mac上ではWindows形式のパスにファイルアクセスしない。

- プロジェクト読込・素材追加の処理中は編集・プロジェクト切替を停止し、完了後に再開する。トラック名はロック中に変更できず、名前の確定1回がUndo1回に対応する。

- 再リンクの処理中はプロジェクト切替を停止する。通常保存は編集を継続でき、プロジェクトの読込世代が変わったら古い保存結果を現在の編集状態へ反映しない。旧プロジェクトの保存完了は、切替後の保存先を変更しない。マーカーIDは空でない一意の文字列を要求する。

- 終了確認前にフォーカス中の入力を確定し、最新の未保存状態を確認する。書き出し素材は登録済みパス・リビジョンを要求する。TIFFは表示用PNGを作り、元ファイルを変更しない。

- 書き出し・音声処理・AI音声処理の開始時は、登録情報に加え現在のファイルサイズ・更新時刻によるリビジョンを確認する。外部で変更・削除された素材は再リンクを促して拒否する。

- 書き出し時の素材検証は実際に映像・音声に使う素材に限定し、未使用や非表示かつ無音のオフライン素材は妨げない。WindowsでMac由来のPOSIXパスを開く場合もオフラインとして保持する。

- Rendererは素材パス文字列を直接指定できない。ファイル選択はMainのダイアログを使い、ドロップは実ファイルのFileオブジェクトをpreloadで解決し、パスをRendererへ返さない。

- テロップIDと素材IDの重複は具体的なエラーで拒否する。マーカーは2000個を上限とし、読込と追加操作の両方で制限する。
- アプリ管理の初期BGMコピーが破損した場合は、チェックサム確認済みの同梱元から原子的に復旧する。同梱元も破損している場合は既存ファイルを変更せずエラーを表示する。
- GIF・APNG・WebPを含む画像は先頭フレームの静止画として扱い、プレビューと書き出しで同じフレームを使用する。アニメーション再生は1.0.0の対象外。
- 素材IDは英数字・ハイフン・アンダースコアの非空文字列に限定し、URL区切り文字などを含む保存データを拒否する。テロップ自動配置は表示中かつ未ロックの映像トラックだけを対象にする。
- プロジェクト・トラック・素材・クリップ・マーカーのID検証を統一し、空文字・URL区切り文字・オブジェクト予約名（__proto__、constructor、prototype）を拒否する。
