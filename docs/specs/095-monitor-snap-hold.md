# 095 吸着後の手ぶれを保持

Issue: #95

境界・中央への接触前は吸着しない。接触時の捕捉範囲4 CSS pxは維持し、捕捉後のみ8 CSS px以内の内外両方向の手ぶれを保持する。8 pxを超えて離れると解除し、再度接触するまで引き寄せない。開始時点で中央にあるだけでは引き留めない。

Altで即座に生のポインター位置を反映し、吸着後でも1 px以下の余白へ配置できる。ドラッグ中にAltを離せば保持範囲内の吸着を復帰する。吸着状態はドラッグ終了時に破棄し、プロジェクトには結果の座標だけを保存する。

動画・画像・文字・図形、回転、横型・Shorts、フル/1/2/1/4画質で表示上の距離を使う。四辺と中央、連続した内外の手ぶれ、解除、Alt、履歴と保存を検証する。071仕様の「内側への即解除」を今回の要望に従って置き換える。
