# 起動時の編集素材（Issue #96）

> 1.0.0以降の配布版は [素材なしのクリーン配布](101-clean-distribution.md) に従います。以下は旧版の仕様です。

- EXE 内の初期素材は movie05.mp4 と「英雄の奪っていったもの.mp3」の2点。ユーザー素材を Git に追加しない。
- 動画全編を0秒から配置し、素材に合わせた1080×1920、30fpsの縦型プロジェクトにする。音声はリンクした別トラックに配置。
- タイトル「英雄が残したもの」を冒頭5秒、白文字・青い縁取り4・影なしで配置。
- BGM は先頭から動画の終了まで、-20 dB、1秒のフェードインと2秒のフェードアウト。
- EXEを移動しても保存済みプロジェクトが開けるよう、素材をユーザーデータへ固定ハッシュ名でコピーする。起動時に整合性を検証し、破損時は同梱の原本から復旧する。
- 既存の外部「初期プロジェクト」指定は引き続き優先する。通常起動は新しい内蔵素材、従来の編集回帰試験は明示的な LUMA_DEMO_FIXTURE=1 で既知の短い素材を使う。通常起動のパッケージ検証を別途必須にする。
- ビルド入力は既存の非公開 v1.18.2 配布物から2点のみ取得し、固定SHA256を検証する。新しい配布物はEXEとチェックサムのみ。スターターZIPを作成しない。
