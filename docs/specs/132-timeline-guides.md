# 切断ガイド、再生ヘッドの吸着、音声専用トラック

Issue #132。Issue #19の全種別配置を、今後の配置に対して変更する。保存形式versionは1を維持する。

- ハサミを未ロックの素材に重ねると切断予定の時刻と縦線を表示する。ガイドと分割は同じ計算を使う。素材の端では破線で示し、0フレームのクリップを作らない。リンク相手がロック中なら分割しない。ツール変更、ポインター離脱、ウィンドウ非アクティブで不要なガイドを消す。
- スナップONでは、ポインター位置から8 CSS px以内の素材の開始・終了、マーカー、0秒へ吸着する。ズームと横スクロールを考慮し、フレーム丸めを吸着成功と区別する。旧プロジェクトの端数秒の切れ目も時刻を保ち、ガイド・分割・再生ヘッドを一致させる。再生ヘッド自身へは吸着しない。
- ハサミ、ルーラー・再生ヘッドのドラッグ、空白クリックで共通に適用する。OFFでもフレーム単位の時刻は維持する。再生やキーボードの1フレーム移動はこの吸着を使わない。
- トラック名、ロック、表示、ミュート、ソロ、削除を1列に配置する。Film/Musicアイコンと色で種類を区別する。Audioは表示切替を省略するが、旧プロジェクトに映像・画像・テロップがあるAudioでは表示切替を残す。ミュートとソロはどちらの種類でも音声に作用する。
- 高さは48〜180px、初期値とリセット値は最小48px。上下のバーで調整でき、ラベルと素材の高さを合わせる。高さ変更は編集履歴へ入れない。
- 新しいAudioへの配置と別トラックからの移動は音声クリップのみ。動画から分離した音声も含む。Videoには従来どおり全種別を置ける。素材一覧の不適合なドラッグはドロップを受け付けず、ストアでも拒否する。不適合・ロック中の段へ素材を移動して離した場合は、そのドラッグ全体を取り消す。
- タイトル・図形・字幕の追加はVideoへ配置する。Videoが使用できない場合にAudioへ代替配置しない。字幕の再適用で旧Audio上の字幕を置き直す場合はVideoへ配置する。
- 旧Audio上の映像の読込、既存の編集、分割、再生・書き出しを維持する。新しい複製（Altドラッグを含む）・貼付は空き区間のある未ロックのVideoへ自動配置する。同じ表示・ミュート・ソロ状態のVideoがない場合は上限24本の範囲で追加し、元の配置とリンクを保つ。既存の移動でも、重なりを避けるため新たなAudioへ映像を置く必要がある場合は変更を取り消す。Undo/Redoによる元の配置復元は許可する。
- 元素材を変更しない。リンク同期、ロック、24トラック・2000クリップ上限、保存と原子的な出力を維持する。

検証はモデルの配置・分割とフレーム丸め、実パッケージのガイド／クリック一致・ズーム／スクロール・スナップOFF・配置拒否・音声配置・高さ・ロック・Undo/Redoを含む。旧配置を読み込んで再生、保存再読込、MP4全フレームと音声を検査する。
