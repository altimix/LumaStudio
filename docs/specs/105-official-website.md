# 公式サイトとオンラインマニュアル

Issue: https://github.com/altimix/LumaStudio/issues/8

## 公開先と構成

`https://lumastudio.altimix.jp`をCloudflare Workers Static Assetsで配信する。ソースは`website/`で管理し、アプリのrendererや保存・編集・書き出し処理は変更しない。

- `/`: 機能紹介、編集画面、Windows / Macの公開安定版ダウンロード、使い方への導線。
- `/getting-started/`: 初めての編集を5ステップで案内。
- `/manual/`: 公開版のREADME.htmlから生成した全文マニュアル。既存のコマンド検索・印刷・操作説明を維持。
- `/support/`: 任意の開発支援、会社への支援問い合わせ、Issue・PRによる参加方法。
- `/about/`: 運営会社、著作権・ライセンス、画面例の映像クレジット、プライバシー、問い合わせ先。

本体はGitHub Releasesから配布し、サイトにEXEやアプリを複製しない。公開版は1.0.0。開発中のGPU書き出しや更新確認を、公開版の提供済み機能として表示しない。

## 会社情報

利用者が指定した公式サイト https://altimix.co.jp/company/ と https://altimix.co.jp/contact/ を2026-09-11に確認した。正式表記は株式会社Altimix（Altimix Inc.）。問い合わせは同社の問い合わせページへ案内する。同サイトのトップ・会社概要・問い合わせページに振込口座は見当たらなかったため、口座を推測・仮入力して公開しない。

## 受け入れ条件

1. 指定ドメインでHTTPS配信される。独自ドメイン以外の既存サイトやDNS設定を変更しない。
2. 各ページ・内部リンク・マニュアルの目次が動作し、PCと390px幅で横スクロールしない。
3. マニュアル検索と検索結果なしの表示が動作する。404には404ステータスと復帰リンクを返す。
4. 配布先は実在する安定版のWindows x64 EXE / Mac arm64 ZIP。対応CPU、未署名、公開版のCPU書き出しを明示する。
5. BGMのCC BY 4.0と画面例のSintel / Blender Foundation（CC BY 3.0）のクレジットを保持する。
6. 公開後のページ・リンク・検索を再確認する。Cloudflare認証情報はGitに保存しない。

## 運用

`website/README.md`のビルド・検証・公開手順に従う。アプリの新しい正式リリースに合わせてダウンロード先・対応条件・マニュアルを同じ変更で更新する。振込先の追記は、公開用の正確な銀行・支店・種別・番号・口座名義を利用者から受け取ってから行う。

## キーボード図説

マニュアルの`#commands`にQWERTY配列の概略図を表示する。Windows / Macと修飾キー（なし、Shift、Ctrl / Command、両方）を選べる。割り当てのあるキーを緑で示し、クリック・タップ・TabとEnterで操作説明を表示する。公開版READMEの`data-key`、`data-ctrl`、`data-shift`と説明文を読み取り、図のために別の割り当て表を持たない。図は文字キーと補助キーの概略で、JIS / USや機種による位置の違いを明記する。JavaScript無効時も従来の一覧を読める。

受け入れ条件: Spaceの再生、MacのCommand+S、Command+Shift+S、WindowsのJを検証する。390pxでもページを横にはみ出さず、既存の検索・一覧を維持する。

## 特徴の訴求

トップの主見出しを「右手はマウス。左手で、編集。」とし、よく使う操作が左手側にまとまる利点を説明する。Q/W（リップルトリミング）、E/R（コマ送り）、A/S（ズーム）、Z（全トラック分割）の概略図から詳しいキーボード図説へ案内する。すべての操作が左手だけで完結するとは表現しない。

タイムライン上の音量編集も主な特徴として紹介する。音量ラインへの点の追加・ドラッグと、声に合わせてBGMの音量を区間ごとに調整する例を示し、音声マニュアルにリンクする。自動ダッキングとしては表現しない。
