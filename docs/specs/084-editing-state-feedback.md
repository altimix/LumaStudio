# モニター編集の状態表示と終了

Issue: #84。キーフレームの表示対象の強調は [共通ビジュアルキーフレーム](072-visual-keyframes.md) に従う。

クロップ・マスク（長方形、楕円、ベジェ）・クロマキーの背景色採取を、Escで終了して通常の移動・変形へ戻す。プロパティに現在のモードとEscの案内を表示し、モニター上部にも「終了 Esc」を用意する。ボタンの押下状態とモニターの編集枠を一致させる。

確定済みの設定は保持し、終了自体は履歴を作らない。ドラッグ中のEscはそのドラッグだけを取り消してからモードを終了し、操作前のUndo/Redoを復元する。入力欄の編集中は入力の取消を優先し、ダイアログやメニューが開いている場合はそれらを先に閉じる。通常の変形・タイムライン・表示範囲のドラッグに固有の取消は維持する。

スポイトの非同期処理は、終了・素材や時刻の変更・再生開始後に届いても設定や通知を変更しない。スポイトを再開した場合も、前の操作の結果を適用しない。複数の採色が重なった場合は最後の操作だけを有効とする。

配布版で数値欄とラインの連動、無操作での終了、ドラッグ取消とUndo/Redo、入力欄・ダイアログの優先、終了後の採色結果の無効化、保存・再読込を確認する。
