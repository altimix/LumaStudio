# 共通のビジュアルキーフレーム

Issue: #72。位置のピクセル表示とスライダー折りたたみは [Issue #70](070-property-pixel-position.md) に従う。

タイムラインの動画・画像・テキストにポイントを追加し、その時点の見た目をプロパティで編集する。不透明度専用のキーフレーム欄は共通の操作欄へ統一する。文章はクリップ全体で共通とし、キーフレームでは変更しない。開始時間・素材のin点・長さ・再生速度など、時間配置の設定はクリップ単位で扱う。

位置X/Y、スケール、回転、不透明度、文字サイズ・色・フォント・太さ・スタイル・影・縁取り・字幕背景・テキスト枠、映像の露出・コントラスト・彩度・クロップ・マスク・クロマキーを対象にする。図形の見た目も同じ仕組みで扱う。数値と色は線形補間し、フォント・スタイル・有効無効などの離散値は次のポイントで切り替える。マスクの種類やベジェの点数が違う区間は形状を次のポイントで切り替える。

ポイントを線でつなぎ、プロパティで選択した項目の値をタイムラインに表示する。クリックで選択とシーク、左右ドラッグで時刻移動、削除操作を用意する。数値項目は値の変化を線の高さで表す。プロパティから再生ヘッド位置にも追加できる。キーがあるクリップの対象項目を変更すると、その時点のキーを追加または更新する。最初のキーを途中に作る場合は0秒の設定も残す。

自動配置の字幕は、文字サイズ・文章・シーケンスサイズが変わっても各キーの下端余白を保つ。位置・拡大率・回転・枠を手動変更した場合や字幕以外のスタイルを設定した場合は自動配置を解除する。YouTubeサムネイルの素材・文章の選定も共通キーの可視性を参照する。

時刻はクリップ先頭からのシーケンス秒。ポイントは最大64個、有限数、昇順、重複なしとし、値は元のプロパティと同じ制約で検証する。追加・変更・移動・削除はUndo / Redoに対応し、ドラッグは1回の履歴にまとめる。Escape・フォーカス喪失・中断では元の状態と履歴を復元する。ロック中は変更しない。

`.luma` バージョン1の任意フィールド `Clip.visualKeyframes` に `{time, values}` を保存する。旧 `opacityKeyframes` は同じ共通ポイントとして読み込み、編集時に曲線を保って移行する。分割・トリミングは補間した境界値を保持し、速度変更ではキー時刻も同じ比率で変更する。

プレビューと書き出しは共通の補間を使用する。文字の形・色・縁取りなどが変化する区間は時刻ごとの描画を出力へ反映する。書き出し準備中も中止でき、一時データを片付けて既存の出力と素材を保護する。

テキストの「文字色」は「スタイル」の上へ置き、影・縁取りと同じ色選択部品を使う。タイムラインとプロパティの選択状態、ラベル、追加・削除・移動の操作を動画・画像・テキストで統一する。

受け入れ検証では補間と境界、旧形式、入力の検証、分割・トリム、履歴・ロック、タイムラインでの実操作、保存再読込とプレビュー／実MP4の一致を確認する。
