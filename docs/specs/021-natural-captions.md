# 日本語字幕の自然な区切りと初期書式

Issue: #38

新規文字起こしでは1字幕20〜30文字を目安に、句点、読点、単語境界、発話の間を評価して区切る。0.5秒以上の無音をまたがず、通常6秒以内の単位にする。短い発話、長い固有名詞や単語は文字数を優先して壊さない。文末を優先する一方、極端に短い字幕が連続する場合はまとまりを作る。本文を省略・要約しない。

OpenAIから得た単語の開始・終了時刻を区切りに利用する。30文字を超える単一の時刻区間やセグメントだけの入力を細分化する場合に限り、その区間内で文字量による補間を行う。この細分時刻は推定であり、無音を含む別区間をつなぎ直して時刻を捏造しない。

新規の字幕は改行を最大1つとし、句読点を行頭へ送らず、英単語や結合文字・絵文字を途中で分割しない。一般的な助詞・助動詞から行や字幕が始まる区切りや、「や」などの接続語の直後の区切りにはペナルティを与え、他の自然な候補を優先する。横は24文字、縦は15文字程度で2行に振り分ける。長い単語には1行で小さく表示する場合がある。明示的に編集した改行はタイムライン適用時に保持する。

字幕プリセットと自動キャプションは共通の書式を使用する。Noto Sans JP、太さ700、白文字、影なし、青 #0064ff（RGB 0,100,255、Issue #40） の縁取り。1920×1080で基本72px、1080×1920で基本64pxとし、シーケンス幅と行の長さに合わせて収まるサイズへ調整する。縁取りの初期幅は4px。背景は不透明度25%（透明度75%）とし、プロパティ「字幕の背景の濃さ（%）」で0〜100%に調整できる。背景枠の下端が横型では画面下から4%、縦型では8%の位置になるよう、行数・文字サイズ・背景余白から位置を計算する。2行の字幕も下端で切れないようにする。新規のタイトル・ミニマルも同じ青い縁取りを使用する。

既存プロジェクトの字幕を自動変換しない。新規文字起こし、新規字幕プリセット追加、明示的な字幕の再適用に適用する。現在の字幕原稿を再度文字起こしすると置き換える既存の案内を維持する。

検証: 文字と句読点の保持、20〜30字のまとまり、単語時刻、無音、短文、長いセグメント、Unicode、2行、縦横の書式をテストする。Windows配布アプリではOpenAI応答だけをモックした既存の統合検証を使い、字幕書式の保存と両方のMP4の青い縁取り画素を確認する。

背景の濃さはクリップの `captionBackgroundOpacity` として保存する。設定を持たない旧字幕は従来の65%を使う。背景変更はプレビューのキャッシュを更新し、Undo/RedoとMP4書き出しでも同じ濃さにする。新しい位置・背景・線幅は新規字幕または明示的な字幕のタイムライン再適用で反映する。
