# 学校で気軽に使える動画編集アプリとしての公式サイト

Issue: https://github.com/altimix/LumaStudio/issues/147

## 目的

Luma Studioを、授業や学校での作品づくりに気軽に使える日本語動画編集アプリとして紹介する。授業の発表、行事・部活動の記録、先生の教材づくりを具体的な利用例にする。

## 表現と導線

- トップの主見出しは「学校で、気軽に動画づくり。」。初めての編集、基本操作、学びの利用場面を最初に伝える。
- トップに3つの学校での利用例と、5ステップの初めての動画編集・学校で使う前の確認事項へのリンクを掲載する。実際の導入事例としては扱わない。
- 開発者紹介は学校での学びを中心とし、仕事・趣味・YouTube用途は補足として案内する。本人提供の写真・経歴と、所属先による公式製品・推奨を示すものではない旨を維持する。
- title、description、OGP、SoftwareApplicationの説明も本文と同じ学校向けの位置付けにする。既存のcanonical、JSON-LD、所有権確認タグ、robots、sitemapを維持する。
- 他社製品との比較、対抗、他社からの注目防止、権利上の安全の保証、学校の採用実績を表現しない。オンラインマニュアルの互換性説明は「他の動画編集アプリの専用プロジェクト形式」などの一般表現にする。
- ショートカット、編集機能、公開版の変更点は引き続き正確に紹介する。AI字幕は任意の補助機能とし、生成結果の確認・修正を案内する。

## 利用条件の説明

広告なし・会員登録なし、基本編集とMP4・MP3出力が無料でPC内で処理されることを説明する。任意のAI機能にはOpenAI APIキーが必要で、外部送信とAPI利用料が発生する。起動時の更新確認はGitHub、追加フォントの初回取得は外部配布元に接続する。サイトの解説動画がYouTubeと通信する説明も残す。「完全オフライン」「通信なし」とは表現しない。

Windows x64 / Mac Apple Siliconの対応、Windows未署名、Mac ad-hoc署名・未公証、配布元と起動手順・SHA256へのリンクを維持する。学校の端末管理、素材・公開範囲の確認事項と、GPL-3.0-only、BGMのCC BY 4.0、画面例・第三者ソフトのクレジットを保持する。

## 変更範囲と検証

Webサイトの案内と生成したオンラインマニュアルの導入表現のみ変更する。アプリ本体、保存形式、配布済みv1.10.8のファイル・オフラインガイド・バージョンを変更しない。

既存のビルド、リンク・マニュアル検索・キーボード図説、SEO検証を実施する。PC / 390px幅で新しい見出しと利用例、開発者ページを確認し、横にはみ出さないこと、利用条件と署名・ライセンスが残ることを確認する。公開後にも本番サイトで表示・SEO情報・公開済み配布リンクを再確認する。
