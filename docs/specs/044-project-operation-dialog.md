# プロジェクト操作中の進行ダイアログ

Issue: #44

プロジェクトの読込、素材の読込、素材の再リンク、および終了前の保存中は、同じ進行ダイアログを表示する。ダイアログは操作名を見出し、補足文を状態として読み上げ、処理中であることを示すスピナーを持つ。

見出し、スピナー、補足文はダイアログの水平中央軸に揃える。本文には上下左右の余白と最低高さを設け、モーダルの左端・下端へ接触させない。日本語の長い操作名と補足文はダイアログ内で折り返す。ウィンドウサイズまたは表示倍率が変わっても、本文の中央配置と余白を維持する。

進行中は背面の編集操作を受け付けない。終了前保存では、既存どおりキーボード操作も抑止する。処理内容、保存形式、読込形式、エラー処理は変更しない。
