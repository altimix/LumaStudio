# プログラムモニターの磁石のような配置補助

Issue: #71 / v1.15.0

## 操作

- 停止中に動画・画像・テキスト・図形をドラッグすると、画面の上下左右の端・中央線に接触したときだけ吸着する。端のすぐ内側に近づくだけでは吸着しない。
- 動画・画像はアスペクト比を保って画面に収めた実寸、テキストは選択枠、図形は線幅を含む選択枠を使う。拡大率と回転を反映した外接矩形の左・右・上・下を、それぞれ画面の同じ辺へそろえる。
- ポインター移動前後の位置から接触を判定する。辺は内側から外側へまたいだ時刻、中央線はまたいだ時刻に吸着する。接触・通過時のはみ出しが4 CSS pxを超える大きい移動は拘束しない。吸着後は内外両方向の8 CSS px以内の手ぶれを保持し、8 pxを超えて離れると解除する（095仕様）。接触前の0.1〜数pxの余白は自由で、接触後の細かい配置はAltで解除できる。中央線も捕捉後は両方向へ8 pxまで保持する。元から中央にある素材を動かし始める場合は引き留めない。中央と端が同距離なら中央を優先する。吸着中は対象の辺・中央へ水色のガイド線を表示する。
- Altを押している間は吸着を解除する。ドラッグの途中でAltを押す・離すだけでも更新する。Esc、フォーカス喪失、ポインターの中止、モニターのサイズ変更で取り消す。
- モニターのフル・1/2・1/4画質、横型・Shortsでも閾値は表示上の距離で一定。画面外への配置は可能。既存の位置範囲（±200%）を超える候補には吸着しない。
- サイズ変更・プロパティの数値入力には吸着を適用しない。素材間の吸着とセーフマージンへの吸着は対象外。タイムラインのスナップ設定とは独立。

## 保存・履歴

吸着した値を既存のX/Yへ保存する。ガイドと吸着状態はドラッグ中だけのUI状態であり、保存・再生・MP4には含めない。1回のドラッグを1回のUndoで戻せる。ロック中のトラックは変更しない。

## 検証

- 幾何テストで四辺・中央、回転・拡大、横縦シーケンス、接触前の0.1/1/3/7 px余白と接触後の解除、4 pxの外側保持、Alt、上限を確認。
- Windowsパッケージの実マウス操作で動画・画像・文字・図形の吸着とガイド、途中Alt、離脱、Esc、Undo/Redo、画質変更、保存・再読込を確認。
- 既存のモニター変形・書き出し、文字編集とサイズ変更、図形、全パッケージ検証を維持する。

## ユーザーの調整（2026-09-09）

「ぎりぎりに配置したいケースもあるので、境界に接したときに吸着」という指定を受け、当初の8 px近接吸着／12 px解除を取りやめた。接触前に位置を引き寄せないことを受け入れ条件に追加する。

- 素材が端にある場合もつかめるよう、位置・大きさを戻すボタンはモニターの見出しへ配置する。映像上の案内はクリックを遮らない。実マウステストは開始点のelementFromPointが素材自身であることも検証する。
- 動画・画像と同じく、文字・図形をつかむとキーボードのフォーカスをモニターへ移す。画質の選択欄を操作した直後もCtrl+SとUndoが働き、プロパティで入力途中の数値を確定してからドラッグの開始位置を取る。
