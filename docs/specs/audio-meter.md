# ステレオ音量メーター

Issue #73。タイムライン右端の MASTER に合成後の音量を表示する。素材の音量・ミュート・ソロ・フェード・音量ポイント・音声処理・シャトル速度を適用済みのステレオ PCM を観測し、音声信号自体は変更しない。

## 表示と操作

- L/R を個別に表示する。−60〜0 dBFS の固定目盛り。緑は −12 未満、黄は −12 以上 −3 未満、赤は −3 以上。無音時も暗い色の領域を残す。
- 赤は上限への接近を示す。CLIP は左右いずれかのサンプル絶対値が 1 以上になった記録で、赤とは区別する。真のピーク（dBTP）や平均的な聴感音量（LUFS）の測定ではない。PC のスピーカー音量も測定対象外。
- 目盛り・色の境界・バー・白いピーク線には同じ座標系を使用する。上限超過でもバーを枠内へ制限し、数値には正の dBFS を表示する。
- 白線はチャンネルごとに 1.5 秒保持し、24 dB/秒で下降する。下部に現在の左右最大値と、リセット以降の最大値を表示する。
- CLIP と最大値は停止・シーク後も残す。「ピーク解除」／「CLIP」ボタン（Tab → Enter / Space）でリセットする。再生中に上限へ達し続けていれば再点灯する。新規作成・プロジェクト読込時にもリセットする。音量や編集履歴は変えない。
- マウスを置くと日本語の凡例と会話ピーク −12〜−6 dBFS の出発点を説明する。実際に聴きながら調整し、既存の会話自動調整の LUFS/dBTP とは区別する。

## 測定と負荷

TimelineAudio が再生予約した短いステレオ PCM バッファを参照し、AudioContext の時刻まで実際に進んだサンプルだけを消費する。先読み部分は表示しない。25 ms の音声スケジューラからメーター専用ストアへ通知するため、動画描画 RAF のサンプリング間隔に左右されず、短いピークや左右逆相の音を取りこぼさない。停止・シークの前にも消費済み区間を通知し、未再生のバッファ参照を破棄する。

保持する PCM は既存の約 0.8 秒の先読み範囲だけでコピーしない。メーターの更新を編集ストアへ流さない。実際の再生経路・ゲイン・保存形式・エクスポート処理は維持する。更新やバッファ消費はブラウザーのメインスレッドで行うため、画面が一時的に固まった場合は復帰時に表示を更新する。

## 検証

既知の PCM を使い、左右差・逆相・単一サンプルのピーク・予約時刻前の無音・停止直前の CLIP・キャンセルされた先読み・0 dBFS 到達・リセット・経過時間によるピーク保持を単体検証する。Windows の実パッケージでも既知のレベルを再生し、色の境界と目盛りの位置、左右表示、停止とリセット、シャトル再生を検証する。既存の実出力 PCM の正逆再生・音量・ミュート・ソロ・速度の相関検証を維持する。
