# 素材種別を問わないトラックと中央からの番号表示

Issue #19。1.3.0としてWindows x64 / macOS arm64へ配布する。

- 新規プロジェクトは上からVideo2、Video1、Audio1、Audio2。Videoは中央から上、Audioは中央から下に増える。`Track.kind`は初期配置と上下のグループを表し、配置できる素材の種類を制限しない。上の映像ほど手前に合成する。
- 両グループに動画・音声・画像・テロップ・図形を置ける。ドラッグ移動、貼付、分割、トリム、リンク同期、重なり回避を同じ条件で扱う。素材の区間・音声の有無はクリップと元素材で判断する。
- 全トラックに表示、ミュート、ソロ、ロックを設ける。表示は映像、ミュート・ソロは音声に作用する。トラックとクリップの高さは既存の高さ調整に追従して統一し、最初のAudioの上辺に中央の境界を表示する。
- 新規・自動作成トラックは任意フィールド`autoName: true`を持ち、追加・削除時にグループ内の順番で番号を振り直す。手動の名前変更ではfalseにして名前を保持する。自動番号と配置変更は同じUndo/Redoで戻る。
- 旧版そのままの4本の初期名・並び・種別が一致しautoNameがない場合だけ初期名を移行する。他の既存名と配置順は保つ。既存プロジェクトを読むため形式versionは1を維持するが、Audio側へ映像を保存したプロジェクトは1.3.0以降で開く。
- 下側の映像もプレビューの先読み、MP4合成、参考フレーム抽出に含める。上側の音声も再生・書き出しの音量・ミュート・ソロを適用する。ロックした配置先への移動を拒否する。
- 明示的な音声分離で作る段には任意の`audioSourceTrackId`を保存し、表示名を番号に変更しても同じ元トラックからの分離音声を再利用する。このIDは配置候補のヒントで、元トラック削除後も読込を妨げない。
- 元素材を変更せず、24本・2000クリップ上限、既存の保存・復旧・切り替え効果を維持する。
- Mac実アプリとWindows CIで番号・上下移動・ロック・Undo/Redo・保存再読込・表示切替・音量メーター・MP4全フレームとPCMを検査する。全配布版検証、必須CI、レビューを経て同じツリーの配布物を公開し、SHA256と対応ソースを添付する。公式サイトとマニュアルも更新する。
