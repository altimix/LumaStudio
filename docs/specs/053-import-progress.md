# 素材読み込みの進捗と中止

Issue: #53

中央ダイアログに現在のファイル名、何件目か、完了・残り件数、解析／再生用変換／サムネイル／波形の処理段階を表示する。件数の進捗バーは処理時間の割合として扱わない。

「読み込みを中止」またはEscapeで中止する。中止要求はFFprobe、FFmpeg、波形生成に伝達する。プロキシとサムネイルは一時ファイルの完成後に置換し、中止時に片付ける。中止までに完了した素材だけを一度の素材追加として取り込み、失敗・中止した素材や残りの素材は追加しない。既存の編集と元素材は変えず、中止後に再実行できる。

処理中はエディターのショートカットを遮断し、ダイアログ内のTab・Enter・Escapeは利用できる。進捗の更新でフォーカスを奪わない。既存の保存・読込ダイアログは中止機能を追加せず従来の保護を維持する。

単体検証は部分完了、中止、再実行、実プロセスの終了待ちを確認し、配布アプリでは進捗表示とキーボードによる中止を確認する。
