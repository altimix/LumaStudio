# 範囲指定ガウスぼかし

Issue: #95

動画・画像クリップの「ビデオ」プロパティに、モザイクと独立したガウスぼかしを追加する。設定はクリップ単位で、素材ファイルは変更しない。初期範囲は素材中央の幅30%、高さ30%、強さは素材幅の1%を標準偏差とする。

範囲は素材の正規化座標で、中心X・中心Y・幅・高さを0〜1として保存する。四辺は素材内に収め、幅と高さは1%以上とする。強さは素材幅の0.1〜3%とする。プロパティで5項目を数値指定でき、モニターで矩形を移動・四隅で拡縮できる。Esc、ポインタ中断、Undo / Redoは既存のモニター編集と同じ扱いにし、ロック済みトラックは編集できない。

プレビュー、フレーム保存、MP4出力では素材のクロマキー・拡縮処理後に画像全体からガウスぼかしを計算し、指定範囲内の画素だけを置き換える。範囲外の画素は変えず、境界の内側のぼかしには境界外の元画像も利用する。素材端より外側は端画素を延長して参照し、全面指定でもプレビューと出力の端を暗くしない。モザイクぼかしも設定した場合は、その前にガウスぼかしを適用する。その後にクロップ・マスク・色補正・クリップ変形を適用する。強さは回転メタデータを反映した画面上の素材幅を基準とし、縦向き動画でもプレビューと出力をそろえる。範囲はクリップの移動・回転・拡大とともに追従し、音声には影響しない。既存プロジェクトでは設定がなければ従来の描画と出力を維持する。不正な種類、NaN、素材外の範囲は読込・書き出し・編集時に拒否する。

映像から音声を分離するときは、ガウスぼかし設定を映像側だけに残す。静的な長方形のみを扱い、追跡や時間方向のキーフレーム操作は含めない。
