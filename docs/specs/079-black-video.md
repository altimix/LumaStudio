# ブラックビデオ（Issue #79）

素材パネルの「ブラックビデオを追加」で現在のシーケンスと同じ解像度の黒いPNGをローカル生成する。映像・音声ファイルや外部APIは不要。素材はアプリの永続データ領域へ保存し、一時キャッシュに依存しない。通常の画像としてタイムラインに配置し、トリミングで長さを変更できる。素材ライブラリの削除、Undo/Redo、トラックロック、保存・再読込、MP4書き出しは既存の画像と共通。

IPCは整数・偶数の幅128〜7680／高さ128〜4320だけを受け付ける。保存パスはメインで生成しレンダラーから受け取らない。失敗時は生成途中のファイルのみ削除する。生成途中に別プロジェクトへ切り替えた場合は素材追加を中止する。
