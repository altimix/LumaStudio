# 範囲指定モザイクぼかし

Issue: #89, #97

動画・画像クリップの「ビデオ」プロパティでモザイクぼかしを適用する。設定はクリップ単位とし、素材ファイルを変更しない。初期範囲は素材中央の幅30%、高さ30%、粗さ2%。

範囲は素材の正規化座標で、中心X・中心Y・幅・高さを0〜1として保存する。四辺は素材内に収め、幅と高さは1%以上とする。粗さは素材幅の0.5〜10%を1ブロックの目安にする。プロパティで5項目を数値指定でき、モニターで矩形を移動・四隅で拡縮できる。Esc、ポインタ中断、Undo / Redoは既存のモニター編集と同じ扱いにし、ロック済みトラックは編集できない。

プレビュー、フレーム保存、MP4出力では素材のクロマキー処理後に対象範囲を画素化し、ブロック幅の15%をガウスぼかしの標準偏差として粒の境界を滑らかにする。ぼかしが参照する範囲外の画素も、境界のブロックで延長したモザイク画像から取る。元の細部が境界へ混ざらず、指定範囲外の画素は元のままにする。独立したガウスぼかしも設定した場合は先に適用し、最後にモザイクぼかしを重ねる。続いてクロップ・マスク・色補正・クリップ変形を適用する。範囲はクリップの移動・回転・拡大とともに追従する。音声は変更しない。既存プロジェクトでも保存済みの粗さを使って境界を滑らかにする。設定がなければ従来の描画と出力を維持する。不正な種類、NaN、素材外の範囲は読込・書き出し・編集時に拒否する。

このIssueでは静的な長方形だけを扱う。被写体追跡や時間方向のキーフレームは含めない。

映像から音声を分離するときは、モザイク設定を映像側だけに残す。
