# 範囲指定モザイク

Issue: #89

動画・画像クリップの「ビデオ」プロパティでモザイクを適用する。設定はクリップ単位とし、素材ファイルを変更しない。初期範囲は素材中央の幅30%、高さ30%、粗さ2%。

範囲は素材の正規化座標で、中心X・中心Y・幅・高さを0〜1として保存する。四辺は素材内に収め、幅と高さは1%以上とする。粗さは素材幅の0.5〜10%を1ブロックの目安にする。プロパティで5項目を数値指定でき、モニターで矩形を移動・四隅で拡縮できる。Esc、ポインタ中断、Undo / Redoは既存のモニター編集と同じ扱いにし、ロック済みトラックは編集できない。

プレビュー、フレーム保存、MP4出力では素材のクロマキー処理後に対象範囲だけを画素化し、その後にクロップ・マスク・色補正・クリップ変形を適用する。範囲はクリップの移動・回転・拡大とともに追従する。範囲外の画素と音声は変更しない。既存プロジェクトでは設定がなければ従来の描画と出力を維持する。不正な種類、NaN、素材外の範囲は読込・書き出し・編集時に拒否する。

このIssueでは静的な長方形だけを扱う。被写体追跡や時間方向のキーフレームは含めない。

映像から音声を分離するときは、モザイク設定を映像側だけに残す。
