# 1.1.0統合リリース

Issue: #10

GPU書き出し（#3/#5）、Windowsビルド修正（#7）、ヘルプ・更新確認（#4/#6）、公式サイト（#8/#9）を統合する。バージョンを1.1.0にし、READMEとオンラインマニュアルのCPU限定という旧版説明を更新する。

Windows x64とmacOS arm64の同一統合コミットをCIでビルドし、package / verify:packaged / checksums成功後の成果物を配布する。各成果物のSHA256と同梱バージョンを照合する。FFmpeg・依存ライブラリの対応ソース、固定ソース一覧、ビルドスクリプト、ライセンスを同リリースから取得できるようにする。

更新は自動確認と手動入れ替えの案内。自動置換ではない。1.0.0には更新確認がないため、最初は公式サイトから取得する。Macは未署名・未公証のまま。Windowsの各GPUベンダーの実機性能は未確認で、CIは組み込みとGPU非搭載環境の挙動を検証する。高速化の固定倍率は保証しない。

サイトは正式リリースの配布ファイルが揃った後に更新する。1.0.0は上書きしない。初期タイムラインを空に保ちBGM001〜005を残す。
