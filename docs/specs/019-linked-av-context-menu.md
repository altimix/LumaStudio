# 映像・音声の分離と右クリック編集

Issue: #33 / 関連する再生ヘッド履歴の修正: #34

## 操作

音声を含む動画をタイムラインへ追加すると、映像と音声を別トラックに配置する。同じ素材・素材IN・開始・長さ・速度を参照するリンクした2クリップを1回のUndoで追加する。波形は音声クリップに表示し、リンクの鎖アイコンと選択相手の枠を表示する。

旧プロジェクトは自動変換しない。動画を右クリックして「音声を別トラックに表示（リンク維持）」で変換できる。「リンクを解除」は既存のリンクを解除し、未分離動画の場合は分離して独立させる。元の動画ファイルは変更しない。

「映像と音声を再リンク」は同じ素材とタイミングの映像・音声をShift+クリックで2つ選んだ場合に実行できる。ずれている場合は勝手に位置を合わせない。

## 編集と音声

- リンク中は移動・トリム・レート・速度・分割・コピー・複製・削除が相手へ追従する。色・音量・ミュート・自動調整は対象メディアごとの設定。
- クリップ選択は実際にクリックした対象を維持し、プロパティはその対象を表示する。音声分離済み映像のオーディオ欄からリンクした音声を選択できる。
- 元の映像クリップは `audioDetached:true` となり、リンク解除や別音声の削除後も内蔵音声を再生しない。音量リセットで二重再生が復活しない。正逆プレビュー、MP4、文字起こしの音声候補判定を共有する。
- 分離済み映像だけのフェードや表示変更では文字起こしを古いと判定しない。音声側の変更と、後方の無音長にも影響するシーケンス末尾の変更は検出する。
- `audioMuted` は音量値を保持するクリップ単位のミュート。`linkId` は同じ素材区間の映像・音声2つだけに共有する。分割・コピー・複製で新しいペアIDを割り当てる。
- 分離先は「元のトラック名の音声」。ミュート・ソロ状態を引き継ぎ、該当する非ロック音声トラックを利用する。存在しない場合は追加し、24トラック・2000クリップ上限を超える操作は全体を取り消す。
- 既存クロスフェードは分離後の音声へ接続し直す。片側のみ分離した音声の接続は異なるトラック間も許可する。映像効果は映像側に保持する。新規の映像トランジションはリンク音声のタイミングと音声効果も同期する。
- ロックされたリンク相手を変更しない。全トラック分割Zはロックされたペアをまとめて除外し、他の非ロッククリップを分割する。連動する複数のリップル操作でタイミングが矛盾する場合は全体を拒否する。

## 右クリック

音量ノーマライズ、会話音声の最適化、自動調整の解除、ミュート、分離、リンク解除／再リンク、速度0.5／1／2倍、プロパティ、分割、コピー、複製、削除、リップル削除を提供する。選択外を右クリックすると選択を切り替え、選択済みなら複数選択を維持する。

音声調整は選択時に解析と適用まで進む。リンクした映像を選択した場合も音声側へ適用する。複数選択は重複を除去して順番に解析し、すべて成功した場合だけ1回のUndoで適用する。進行表示・中止操作をタイムラインとプロパティで共有する。解析中にプロジェクトの編集・読込・Undo・トラックロックが発生した場合は中止し、古い結果を適用しない。選択だけの変更では中止しない。

Shift+F10／メニューキー、上下キー・Home／End・Enter・Escape／Tabに対応する。画面端へメニューを収め、縦のスクロールを許可する。メニュー中は編集ショートカットを抑止し、閉じた後はクリップへフォーカスを戻す。

## 履歴

QとWのリップルトリムは編集前の再生ヘッドを履歴に保持する。Undoで編集前の位置へ戻り、RedoではUndo前にいた位置へ戻る。通常の変更は従来どおり現在位置を可能な範囲で維持する。履歴の80件制限、任意履歴への移動、ロード時の履歴初期化、ジェスチャー取消時の履歴復元も同じ配列で処理する。再生ヘッド変更は既存の自動追従を発火する。

## 検証

モデルの連動編集・ロック・上限・非同期中止・Q/W/Undo/Redo、実FFmpegの分離前後の単一音声と文字起こしWAVの一致、保存形式の拒否／再読込を検証する。Windows配布アプリでは新規配置、波形、右クリック、実ノーマライズ、キーボード、リンク解除／再リンク、Undoの位置、保存再読込、MP4の音量一致を検証する。既存の配布アプリ検証も継続する。
