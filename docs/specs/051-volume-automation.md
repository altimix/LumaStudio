# タイムラインの音量ライン

Issue #51。音声波形に重ねた音量ラインへ点を追加し、時間ごとの音量を直接調整する。

- 音声クリップの波形上にラインを表示する。線のダブルクリックまたはCtrl+クリックで点を追加し、上下で音量、左右で時刻を動かす。選択した点のDeleteでその点だけを削除する。
- 点の間の線を上下にドラッグすると、その区間の両端を一緒に動かして音量を調整する。既存の傾きを保ち、倍率の上下限を超えない。
- 音量ラインや点の上でもShift+クリックはクリップの複数選択・選択解除として扱う。画面サイズにかかわらず、一括BGM音量調整とUndoを維持し、選択操作で音量カーブを変更しない。
- 点はクリップ先頭からの秒数と倍率を持ち、基本音量の0〜200%で線形補間する。点がない場合は100%。BGMの−20 dB／−15 dB、通常の音量、フェード、ミュート、会話処理と併用する。先頭／末尾の外側は端の値を保持する。
- 点を最大64個まで設定できる。矢印キーで時刻・音量を微調整でき、基本音量に対する%と実際のdBを確認できる。音声プロパティにも再生ヘッド位置への追加とリセットを用意する。
- 1回のドラッグを1回のUndo/Redoにまとめ、Escape・フォーカス喪失で取り消せる。トラックのロックを保護し、点の操作がクリップ移動やクリップ削除へ伝わらないようにする。
- 保存・再読込、分割、トリム、Q/W、速度変更、リンクした映像からの編集でも素材の同じ時点に音量変化を保つ。
- 正逆シャトルを含むプレビュー、MP4、文字起こし用の音声で共通の曲線を使う。元ファイルは変更しない。文字起こしの変更検出にも曲線を含める。
- 早送り・スロー再生中も音量カーブを出力サンプル単位で計算し、1フレームだけ音量を下げる操作を間引かない。点のフォーカスが外れると強調表示も解除し、削除キーの対象を明確にする。
- 不正な値・重複時刻・個数上限を検証する。モデル、実FFmpeg音声、Windowsパッケージで操作と音声を確認する。
