# テロップの不透明度キーフレーム


## 動作

- テロップのプロパティからクリップ内の時刻と不透明度を指定し、キーフレームを追加・更新・削除できる。時刻は秒、値は0〜100%。一覧からその位置にシークできる。
- 時刻順に線形補間し、最初の前・最後の後は端の値を維持する。0秒0%、1秒100%なら0.5秒50%。
- キーフレームがある場合は基礎の不透明度に優先する。フェードイン・アウトは補間値に乗算する。最後のキーフレームを削除すると基礎の不透明度に戻る。
- 分割と左右トリムは、境界に補間した値を作り、残った範囲の曲線を維持する。延長した部分では端の値を維持する。
- `.luma` バージョン1の `Clip.opacityKeyframes` に `{time, value}` 配列として保存する。省略された旧形式の動作は変わらない。
- 最大64個。時刻は0〜クリップ長、有限数・重複なし・昇順、値は0〜1。上限を超える編集は全体を拒否する。ロックしたトラックは変更しない。Undo / Redoに対応する。
- CanvasプレビューとFFmpeg出力は共通の補間定義を使用する。出力の動的アルファは [FFmpeg geq](https://ffmpeg.org/ffmpeg-filters.html#geq) の時刻式により適用する。

## 受け入れ検証

- 中間値、端点、旧形式、フェードとの積、分割・トリム後の曲線保存をテストする。
- ロックとUndo / Redo、範囲外・重複・上限の検証。
- 実際のWindows UIでキーを追加・更新・削除し、保存・再読込を確認する。
- プレビューとMP4の0%、50%、100%の画素を比較する。日本語テロップを使用する。
- ベジェ補間、位置・回転・音量のキー、グラフエディター、映像クリップへの適用はこのIssueに含めない。
