# トラック間移動で開始位置を維持

Issue: #89

スナップ（N）が有効なとき、移動可能な別トラックへドラッグし、元の開始位置からの横移動が16 CSS px以内なら、元の開始時刻を優先して維持する。表示倍率によらず同じ操作範囲とし、横スクロール量も移動量に含める。開始位置に既存の吸着ガイドを表示する。

16pxを超えて横に動かす場合、同じトラック上の場合、スナップが無効な場合は従来の時刻移動とする。近くに別の編集点があっても、開始位置維持を優先する。フレーム間にある開始時刻や、リンクした映像・音声の開始時刻も丸め直さない。

Altで複製する場合にも適用する。ロックしたトラックや種類が不適合のトラックへの移動は許可しない。複数素材の明示選択は既存の移動規則を維持する。Escapeは移動・複製を取り消し、Undo/Redoは1操作で戻せる。
