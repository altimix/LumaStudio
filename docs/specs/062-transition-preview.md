# つなぎ目の滑らかなプレビューと紙のページピール

Issue: #62

クロスディゾルブは前後のRGBAを進行率で混ぜ、透明な余白の下のトラックも残す。Canvasの加算合成で重み付けした2枚を描き、合成用のgetImageDataとJavaScriptの全画素ループをUIスレッドで実行しない。ページ系はWebGL2で計算し、利用できない環境では長辺640pxを上限とするワーカーへ切り替える。GPUプログラムは再利用し、使用中4個・待機中2個を上限として待機時は画像領域を解放する。

再生中は前後のデコーダーを連続再生させ、細かな時刻差によるシークの繰り返しを避ける。次のつなぎ目を事前に読み込み、短いデコード遅延で効果が消えないようにする。停止中のシークでは古いフレームを合成しない。

Windowsでは動画のデコードと表示用フレームをCPU側に保ち、GPUに置かれたNV12画像の同期読み戻しによる長い停止を避ける。Chromiumの`disable-accelerated-video-decode`と`disable-gpu-memory-buffer-video-frames`を起動時に指定する。WebGLの合成とFFmpegのGPU書き出しは維持する。固定フレームは再利用する。高解像度・高ビットレートのデコード負荷はCPUにかかるため、長時間4Kの耐久性能は別途評価する。

フレームの準備完了は素材秒で1シーケンスフレーム以内（停止中は8ms以内）と判定する。連続再生中の読み取り待ちは、同じシーク世代の直前のデコード済みフレームを最大0.5再生秒まで使って現在の進行度で合成し、効果自体の消失を防ぐ。未来のフレームや別のシークのフレームは使わず、予測が先行した場合は最新のデコード時間へ補正する。通常再生は最大±25%の速度補正で時計に追随する。連続再生では500ms以上のずれでシークし、明示的なシーク操作は8ms精度で即時に要求する。再生開始のPromiseが完了するたびにシークを追加せず、シーク中の速度変更も避け、CPUデコーダーの繰り返し読み直しを防ぐ。合成フレームの許容差はシークの閾値とは分離する。逆方向などシークで進む再生では、実測したデコード待ち時間を使って最大800ms先のシーケンス位置を準備し、停止中は先読みしない。末尾の再生呼び出しによる先頭への巻き戻りを防ぎ、手動シークは古い待機要求を置き換える。明示的なシーク操作の世代を参照し、同じ再生位置をクリックし直した場合も未完了の要求を出し直す。素材端の静止区間では先読みの目標を端に固定し、映像が動き出す前に次のシークへ進めない。読み込みが早く終わった未来のフレームは再生位置が追いつくまで保持し、次の予測で破棄しない。つなぎ目の2秒前から準備する。デコーダーの復帰は2秒または実測待ち時間の3倍の長い方を超えた場合に限り、同じ操作につき一度だけ行う。

効果の一時保持は再生中の300ms未満に限る。ワーカーの受信フレームにも要求時の時刻・プロジェクト世代・寸法・種類を結び付け、編集・画質変更・効果変更後は使わない。GPUのテクスチャ・レンダーバッファ・ビューポート上限を事前に確認し、容量超過や確保失敗はワーカーへ切り替える。確保時以外は同期的なGPUエラー照会を繰り返さない。

ページピールは右下から斜めに紙をめくり、曲面で元の画像を変形する。前面は曲がりの陰影、裏面は光沢のあるグレーとし、下には柔らかい影を付ける。GPU、CPU、FFmpegで同じ座標と色の計算を使用する。

完成尺・素材の位置・音声のタイミング・元の素材を変えない。余りのない素材の端フレーム補完、透明度・配置・色調整、正逆再生を維持する。

検証は共有CPU計算とFFmpegの複数進行率での比較、Windows実画面での未デコード素材とシークの保護、描画方式の切替とGPU上限、1/2・1/4の3種類の効果と繰り返し再生後の逆再生の計7ケースを含む。効果が区間全体で進み、描画処理の95パーセンタイルが150ms未満であることを確認する。描画周期、効果の表示割合と出力画像を記録する。描画周期は素材の実フレーム更新数とは区別し、すべてのPCと素材で一定fpsが出るとは保証しない。

シークのずれはシーケンス秒から素材秒へクリップ速度で換算し、0.25倍速でも補正開始が遅れないようにする。メインウィンドウが背面・非表示になっても映像時計を維持する。Windows検証は1/4のページターンでウィンドウを隠した再生も確認する。

画質変更でフレームがGPU上限内に収まった場合は同じ停止位置のままGPU合成を再試行し、変更前のワーカー結果を破棄する。
