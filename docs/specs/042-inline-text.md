# プレビューでの直接文字編集とテキスト枠

Issue #42、altimix/LumaStudio #21。

- プレビューのテキストをダブルクリック、または選択枠でF2を押すと直接入力欄を開く。Enterは改行、Ctrl+Enterは確定、Escは取り消し。欄の外にフォーカスを移した場合も確定する。日本語IMEの変換中は確定・中止のキーを横取りしない。
- 確定まで原稿は下書きとして保持し、1回の確定を1回のUndoで戻せる。編集中は共通の操作所有権を取得し、プロジェクト切替や編集中の対象変更で古い入力を適用しない。
- 選択したテキストの四隅と辺にハンドルを表示する。反対側の辺・角を基準に幅・高さを変更し、回転・拡大縮小を座標に反映する。Escは変更した枠と位置を戻す。
- `textBox: {width,height}` はシーケンスのピクセル単位で保存する。範囲32〜16000px、タイトルのみ、図形との併用不可。未設定の旧テキストの描画を変えない。
- 文字サイズを保ち、枠幅で英単語・日本語・絵文字を折り返す。手動改行を保持する。高さ不足は枠の外をクリップしてプレビューに警告し、プロパティの「枠の高さを文字に合わせる」で広げられる。
- プレビューと書き出しで同じ行分割・枠寸法・クリッピングを使う。背景・縁取り・影を引き継ぐ。枠変更はプレビューキャッシュを更新する。
- 枠の幅・高さを数値でも変更できる。ロックしたトラックを保護し、保存・再読込・Undo/Redoを検証する。

- 文字編集時の操作ガイドバーとテキスト・枠ハンドルのホバーメッセージは表示しない。入力欄を開くと自動的にフォーカス・全選択し、すぐに文字を置き換えられる。欄外クリックで確定するための追加ボタンは置かない。操作方法はヘルプ・取扱説明書で確認できる。
