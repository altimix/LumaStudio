# 1.10.1の正式配布

Issue: https://github.com/altimix/LumaStudio/issues/101

PR #100で実装した、モザイクとガウスぼかしの数値欄の左右ドラッグ操作を配布する。中心 X・Y、幅・高さ、粗さ／強さを共通の数値入力部品で調整する。機能の受け入れ条件は `099-region-effect-number-scrub.md` に従う。エフェクト画質、文字起こしのモデル、プロジェクト保存形式は変更しない。

- アプリ、ロックファイル、HTMLマニュアル、Windows / Macガイド、公式サイトを1.10.1へ揃え、1.10.0の更新履歴を残す。
- リリースPRの同一コミットでWindows / macOS CI、パッケージ版操作検証、Website CI、Codexレビューを確認する。
- 最終ソースに一致するCI由来のWindows x64 EXEとMac arm64 ZIPを使い、内蔵版数、ガイド、Macの署名、SHA256を照合する。
- 起動ガイド、HTMLマニュアル、ライセンス、メディアツールの対応ソースとビルド手順、SHA256をv1.10.1のGitHub Releaseに添付する。既存タグとリリースは上書きしない。
- リリース後に公式サイトを更新し、PC / 390px幅、マニュアル検索、SEO、404、配布リンクとチェックサムを本番で確認する。
- 公開と確認が完了してからIssue #101を閉じる。
