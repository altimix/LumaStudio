# 素材なしのクリーン配布（Issue #101）

Windows・Macの通常起動は「新しいプロジェクト」、1920×1080・30fps。素材・クリップ・マーカーは0件。空の編集トラックは維持する。旧初期プロジェクト・キャッシュ済み素材を自動配置しない。

利用者の保存済みファイルや素材、キャッシュは削除しない。自動保存があれば復元バナーを表示し、明示的な復元操作で編集を戻す。既存プロジェクトは通常の「開く」で読み込む。

デモとopening-mediaは配布物に同梱せず、パッケージ作成時の初期素材取得も不要。例外として利用者指定のbgm001.mp3〜bgm005.mp3の5曲をBGMライブラリに同梱する。素材・タイムラインへは自動配置しない。Windowsの一時展開先が変わっても保存プロジェクトが参照できるよう、初回のBGM利用時にユーザーデータ配下へ検証済みのコピーを保存する。音源はGitへ追加せず、公開リポジトリのビルド素材用リリースから取得し、shared/bundled-bgm.jsonのSHA256で検証する。FFmpeg・FFprobe・日本語フォントは機能維持のため同梱する。Electronの言語リソースは日本語と英語のフォールバックに限定し、配布アーカイブは最大圧縮を使用する。既存編集テストだけが、独立テストプロファイルとLUMA_DEMO_FIXTURE=1を指定して、配布物外の固定テスト素材を読む。パッケージ検証ではLUMA_TEST_FIXTURESにリポジトリ内public/demoを指定する。

旧仕様 #80 / #96 / #99 の自動読み込み・素材同梱方針を、この仕様で置き換える。ブラウザ用デモは維持する。

受け入れ条件はscripts/verify-clean-start.cjsで空の起動・保存、旧テンプレートの非読み込みと保持、素材追加、自動保存と明示復元、配布フォルダに初期素材がないことを検証する。既存の保存・編集・出力テストも配布版で実行する。公開成果物は1.0.0として新しく作成する。
