# 編集UIの統一

Issue: #73。#70 の数値入力、#72 のキーフレームを前提に、既存の素材・プレビュー・プロパティ・タイムラインの配置を維持する。

## 点検で見つかった不一致と変更

- トランスフォームだけ数値の横ドラッグ・スライダー開閉に対応し、影・縁取り・図形・文字枠は通常の入力欄だった。`ClipPropertyFields` に共通化し、直接入力、横ドラッグ、1回のUndo、Escape取消、ロック、現在時刻のキーへの記録をそろえる。
- 影の入力欄の初期値が実際の描画の既定値と違っていた。ぼかしは文字サイズの0.22倍、距離は0.035倍を表示する。
- px・%をラベルと値の右に二重表示していた。単位は値の右にまとめる。枠の幅・高さは広い範囲を直接指定するためスライダーを出さない。
- 文字・縁取り・図形・クロマキーで色入力の寸法が異なった。`ColorField` に共通化し、ラベルと48×27の色選択をそろえる。現在の色コードはツールチップでも確認できる。
- 素材とプロパティのタブで選択状態・キーボード操作が異なった。現在の項目だけTabでフォーカスし、左右キー・Home・Endで選択、Enter・Spaceで操作する。タブ操作で再生ヘッドや再生状態を変更しない。
- プロパティの数値をフォーカスすると、対応するキーフレームの表示項目も合わせる。音量・フェード・時間配置も含め、すべての数値入力で再生を停止し、入力確定まで調整対象の時刻が進まないようにする。見た目以外の項目では表示中のグラフを変えない。
- 書き出しFPSの選択肢にシーケンス固有のFPSがなかった。現在のFPSを選択肢へ含める。準備中の説明は映像と音声の両方を対象にする。
- ダイアログのTab移動は表示中で操作可能な要素だけを巡回し、折りたたんだ入力へフォーカスしない。

無効状態は共通のdisabled表示、操作の説明は日本語ラベル・ツールチップを使う。既存のロック、素材の非破壊編集、保存・復旧・書き出しのエラー表示を維持する。新しい配色や別の画面構成は導入しない。

検証はレイアウト、素材パネル、数値ドラッグ、文字枠、図形、字幕、キーフレーム、保存・MP4出力を配布アプリで通す。編集内容を変更しないタブ・折りたたみ操作が履歴や未保存状態を変えないことも確認する。

音声の実出力検証は、音声処理の操作後にタイムラインへフォーカスを戻してからHome／Endで移動する。再生開始前にフレーム位置を照合し、音声波形の不一致と操作対象の誤りを区別する。逆再生・音量補正のPCM比較基準は維持する。
