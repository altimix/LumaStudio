起動と編集の流れ

1.0.0以降のWindows・Mac配布版は、素材・クリップ・マーカーが空の新規プロジェクトで起動します。初期設定は1920×1080・30fpsです。BGMライブラリにはbgm001.mp3〜bgm005.mp3の5曲を同梱し、必要な曲を選んで追加できます。「読み込み」から動画・画像・音声を追加してください。旧版の初期素材や外部「初期プロジェクト」は自動配置しません。保存済みプロジェクトは「開く」、自動保存は「復元する」で再開できます。

Windowsでは Luma-Studio-1.1.0-Windows.exe を起動します。Macでは配布ZIPを解凍し、Luma Studio.appを「アプリケーション」へ移動して起動します。Macの初回起動で開発元の確認が表示される場合は、別添のMac用手順を参照してください。Node.jsやFFmpegの別途インストールは不要です。MP4出力はCPUに加え、MacのVideoToolbox、WindowsのNVENC・Quick Sync・AMFに対応します。実際に使える方式はGPU・ドライバー・環境により異なります。

  1. 画面の向きを選ぶ：「ファイル → 新規プロジェクト」で横動画 1920×1080 または Shorts 1080×1920 を選びます。初期値は30fps。後から「シーケンス」で変更できます。
  2. 素材を入れる：「読み込み」または Ctrl + I。動画・画像・音声のファイルをウィンドウへドラッグしても読み込めます。
  3. タイムラインに並べる：左の素材を選んで「選択素材をタイムラインに追加」、またはトラックへドラッグします。左から右へ再生されます。
  4. 不要な部分を切る：V で選択、Z で全トラックをカット。Q / W のリップルトリムや右クリックの空白削除を使えます。困ったら Ctrl + Z。
  5. 見やすく・聴きやすくする：モニターで映像の配置を調整し、テキスト・図形・BGMを追加。「YouTube」から自動字幕も作れます。
  6. 保存して動画にする：Ctrl + S で編集用の .luma を保存。Ctrl + E で再生・投稿用のMP4を書き出します。
まず覚えるキー：再生は 1 / Space、停止は K、選択は V、元に戻すは Ctrl + Z。上部の「使い方」も編集手順を案内します。

素材とタイムライン

下と右の太いバーはダブルクリックで全体表示・標準高さに戻り、中央をドラッグしてスクロール、両端の丸をドラッグして横方向の拡大率・トラックの高さを調整します。素材はAlt＋ドラッグで複製できます。複数選択とリンクした映像・音声もまとめて複製し、Escで中止、Ctrl＋Zで元に戻せます。吸着は素材の先頭と末尾の両方に対応します。

「メディア → ブラックビデオを追加」で黒一色の背景素材を作れます。タイムラインに配置し、プロパティの「長さ」で必要な秒数に調整してください。テロップの背景や無地の区間に使えます。

素材を管理する

素材一覧はリスト表示が初期値です。検索、動画／音声／画像フィルター、グリッド表示に切り替えられます。素材をクリックすると選択、再生アイコンまたはサムネイルのダブルクリックで素材プレビューを開きます。

素材を選んで Delete またはゴミ箱を押すとプロジェクトから削除できます。使用中なら配置済みのクリップも削除する確認が出ます。PCの元ファイルは消しません。ロックしたトラックで使用中の素材は先にロックを解除してください。Ctrl+Zで戻せます。

動画・音声は元の長さ全体を追加します。1分・12時間で素材を切り詰める制限はありません。ただし、プロジェクトは最大24トラック・2000クリップで、AI文字起こしには別の上限があります。

選択・移動・カット

V の選択ツールでは、空白をドラッグすると枠に触れたクリップを複数トラックから選べます。Shift を押して開始すると追加選択。Shift+クリックは個別の追加・解除です。素材本体をドラッグすると選択素材をまとめて移動し、左右端でトリミングできます。範囲選択はロック中のトラックを除きます。

新しく追加した音声付き動画は、映像と音声を別トラックへ配置してリンクします。移動・分割・トリム・複製・削除・速度変更はリンク相手も連動します。既存の動画は右クリックの「音声を別トラックに表示（リンク維持）」から分離できます。リンク解除後は別々に編集できます。

再生位置を見失わない

「再生ヘッドの自動追従」は初期状態でON。J/L、Home/End、コマ送り、マーカー・字幕・キーフレームへの移動に合わせて表示が追従します。ルーラーや再生ヘッドの線・つまみをドラッグし、画面の端に寄せると横へ連続スクロールします。

別の場所を見たいときは自動追従をOFFにできます。「再生ヘッドを表示」で現在位置へ戻れます。Vのとき、トラックの空白のドラッグは範囲選択です。再生位置を動かすにはルーラー・再生ヘッドを使います。

トラック名の変更、表示、ロック、ミュート、ソロ、追加、マーカー、スナップ、ズーム、タイムラインの高さ調整にも対応します。上の映像トラックほど手前に表示します。

映像・画像をモニターで配置する

  1. K で停止し、配置したい素材が表示される時刻へ移動します。
  2. プログラムモニターの動画・画像をクリックします。選択枠が表示されます。
  3. 枠の中をドラッグすると移動、四隅をドラッグすると縦横比を保って拡大縮小できます。素材の端が画面の端に触れると吸着し、水色のガイドが表示されます。近づくだけでは吸着しないため、端のすぐ内側にも配置できます。中央線をまたぐと中央にも吸着します。吸着後は小さな手ぶれで外れにくく、表示上8pxより離すかAltで解除できます。
  4. モニターの見出しにある「位置・大きさを戻す」で中央・100%へ戻せます。Esc で進行中のドラッグを取り消し、操作後は Ctrl + Z で1回分戻せます。

Alt を押している間は吸着を解除して微調整できます。一度吸着すると内外8pxまでの手ぶれを保持し、それ以上離すと解除します。細かい余白へ配置する場合はAltを押してください。テキスト・図形にも同じ操作が使えます。リサイズや数値入力には吸着しません。

位置とスケールは右側のプロパティと連動し、保存・MP4出力にも反映します。拡大率は10〜300%。大きく拡大した場合もハンドルをモニター内の端に表示します。回転・不透明度・色調整はプロパティで設定します。

画像を動画に重ねるには、画像を上側の映像トラックへ置きます。停止中のメインモニターで直接操作できます。再生中やロック中、非表示・オフラインの素材は直接編集できません。

モニターのフル／1/2／1/4画質はプレビューの負荷を調整します。書き出し解像度は変わりません。セーフマージンと全画面表示はモニター下のボタンから使えます。

テキスト・図形・効果音

文字を直接編集する

左の「テキスト」からタイトル、ミニマル、字幕を追加します。停止中のモニターで文字をダブルクリック、または文字の移動ボタンにフォーカスして F2 を押すと、その場で編集できます。Enter は改行、Ctrl + Enter で確定、Esc で取り消しです。入力欄の外へフォーカスを移しても確定します。

文字をドラッグして移動し、選択枠の四隅・辺でテキストボックスの幅・高さを変えられます。枠の変更は文字サイズの変更とは別で、幅に合わせて折り返します。文字が隠れるときはプロパティの「枠の高さを文字に合わせる」を使います。

初期フォントは同梱のNoto Sans Japanese。登録済みのGoogle Fonts日本語書体を選択でき、同梱以外は初回に取得して保存します。フォント、太さ、文字サイズ、色、影の有無・色、縁取りの有無・色・太さを変更できます。

新規テキストの共通初期値：影なし、縁取りあり・4px、縁取り色 R0・G100・B255（#0064FF）。ミニマルの中心は横型で960・540、縦型で540・960です。既存テキストの設定は維持します。

テロップの「不透明度キーフレーム」では最大64点を設定できます。たとえば開始0秒を0%、1秒を100%にすると徐々に表示できます。線形補間、点の追加・更新・削除、Undo、保存・出力に対応します。

注目させたいところに図形を置く

「図形」タブで矢印・四角・丸を選び、モニターをドラッグして描きます。「選択した図形を中央に追加」も使えます。追加後はドラッグ移動、右下のハンドルでサイズ変更。線・塗りつぶし・太さ・表示時間はプロパティで調整します。

図形の初期設定は赤い線、チャイム、音量90%。ピーン、チャイム、短いジングル、効果音なしから選べます。音は同時に音声クリップとして追加し、後から個別に編集できます。Esc または「図形の描画を終了」で描画モードを終了します。

音声・BGM・音量ライン

音量メーターの色を見ながら調整する

タイムライン右端のMASTERで、再生中の左右（L/R）の音量を確認できます。緑：−12 dBFS 未満、黄色：−12〜−3 dBFS 未満、赤：−3 dBFS 以上です。声のピークは−12〜−6 dBFS程度を出発点にし、実際に聴きながら調整してください。

赤は上限に近いことを知らせる目安です。CLIPが点灯したら0 dBFS以上に達した記録なので、音量や重なったトラックを確認してください。白い線はピークを約1.5秒保持し、下部の「最大」とCLIPは停止後も残ります。上の「ピーク解除」／「CLIP」をクリック（またはTabで選択してEnter / Space）すると記録を消せます。音量自体は変わりません。

音量を変えるには素材を選んで「プロパティ → オーディオ → 音量」、部分的な調整には波形上の音量ラインを使います。メーターはトラックを合成したサンプルピークで、平均的な聴感音量（LUFS）・真のピーク（dBTP）・PCのスピーカー音量とは異なります。新規作成・プロジェクト読込でピーク記録をリセットします。

声の音量を整える

音声付きクリップを選び、「プロパティ → オーディオ」で基本音量0〜200%とフェードを調整します。右クリックの「会話音声を聴きやすく」は低い振動音と声の大小差を抑え、「音量をノーマライズ」は音の質感を保って音量をそろえます。解析から適用まで進み、解除・中止・Undoに対応します。

会話の自動調整を高速化：「会話を聴きやすく（おすすめ）」は解析しながら音声を生成し、音量の精度が必要な素材だけ追加で仕上げます。同じ元素材から分割・複製したクリップはまとめて準備し、処理済み音声は再利用します。

「解析して適用」を押すと、右側のオーディオとタイムライン上部に進捗％・バー・処理段階・素材番号・経過時間・残り時間の目安を表示します。％は実際の音声処理位置から算出し、適用完了後に100％になります。最初は残り時間を算出中と表示し、応答を待つ間も経過時間を更新します。右クリックからの開始でも進捗を確認・中止できます。長さとPCの性能により所要時間は変わり、高速な可逆圧縮のキャッシュは従来より大きくなる場合があります。

素材単体の処理目標は−16 LUFS、ピークの目標上限は−1.5 dBTPです。調整後のクリップ音量や複数トラックの合成で最終的な大きさは変わります。元の音声ファイルは変更せず、処理済み音声を正逆プレビュー、速度変更、MP4、文字起こしに使います。

BGMを入れる

  1. EXEと同じ場所の bgm フォルダへ曲を入れ、左の「BGM」を開きます。「フォルダを選択」で別の場所も指定できます。
  2. 後から曲を追加した場合は「更新」。曲を選んで試聴し、「BGMをタイムラインに追加」を押します。
  3. 初期音量は10%（−20 dB）。動画の終わりまで合わせる場合は、長い曲を切り、短い曲を繰り返します。「曲をそのまま追加」も選べます。

MP3 / WAV / M4A / AAC / FLAC / OGG / OPUSとサブフォルダに対応します。追加後は右クリックの「BGM音量調整」で−20 dB（10%）、−15 dB（約17.8%）を設定できます。同じ項目を押し直しても音量は累積して下がりません。Shiftで複数選択すれば一括適用できます。

同じ設定は「オーディオ → 音声の自動調整 → 調整方法」でも選べます。BGMプリセットは基本音量の設定で、自動ダッキングではありません。会話中心では−20 dBを出発点にして聴きながら調整してください。

音量ラインで部分ごとに変える

波形の高さにもノーマライズ・会話最適化・音量・音量ライン・フェードが反映されます。全素材を共通の振幅基準で表示するため、小さい音は小さい波形になります。トラックの高さを広げると細部を確認しやすくなります。

素材を選ぶと両端の丸が表示されます。丸の選択はプロパティへ移っても維持され、音量の％とライン位置が同期します。点がある場合は選択した点、それ以外は再生ヘッド位置の音量を編集します。点がないときはクリップ全体の音量を変更します。

波形上の黄色い線をダブルクリック、または Ctrl + クリックすると音量ポイントを追加できます。点を上下にドラッグで音量、左右にドラッグで時刻を変更。点の間の線を上下へ動かすと、その区間の両端を一緒に調整できます。

ポイントへフォーカスして Delete / Backspace でその点だけを削除。左右キーは1フレーム、Shift併用で10フレーム移動します。上下キーは音量を1ポイント、Shift併用で10ポイント変えます（例：100% → 101%／110%）。Ctrl+Zで戻せます。

最大64点、基本音量に対する0〜200%の倍率です。音量0%で無音にできます。プロパティの「音量ライン」から再生ヘッド位置への追加・リセットもできます。BGMプリセット、フェード、会話調整と併用でき、保存、正逆再生、MP4、文字起こしに反映します。

メイン音声・ミュージック・ナレーション・効果音は、ズームに応じた細かい波形を表示します。A で拡大して発音の始まりや無音を確認してください。波形は元音声の形、黄色いラインは適用する音量です。

つなぎ目の効果・再生速度

「エフェクト」で効果を選び、切り替え先のクリップに適用するか、つなぎ目へドラッグします。

ページターン紙のページをめくるように次の映像へ切り替えます。
ページピール右下から紙が丸まってめくれ、光沢のあるグレーの裏面と陰影が見えます。

カット位置と完成動画の長さは変えません。未使用の映像区間を優先し、足りない部分だけ前の最後・後ろの最初のフレームで補います。音声の不足部分はカット前後でフェードします。効果の長さには前後の素材の長さに応じた上限があります。

プレビューは次の素材を先読みし、ページ効果をGPUで描画します。GPUが利用できない場合は軽量な代替処理へ切り替わります。重い場合はモニターの「1/2 画質」「1/4 画質」を選んでください。

素材の速度を変える

タイムラインのレート調整ツールを選び、動画・音声の端を伸縮します。使う素材区間を保ちながら0.25〜4倍速に変更します。Esc で中止、Ctrl+Zで戻せます。右クリックでは0.5／1／2倍の設定が使えます。Vは矢印、移動中はつかむ手、Alt複製中はコピー、Cは縦向きのハサミになります。刃の間の金色の縦線をカットしたい位置に合わせてクリックします。素材の左右端は全高で長さを調整でき、レート調整では速度計付きの左右矢印になります。音量の丸はその位置で操作し、C・レート中はカット・速度調整を優先します。Rキーはコマ送りで、レート調整ツールにはキー割り当てがありません。

J/Lのシャトルは確認用の一時的な再生速度です。J/Lを繰り返すと1 → 2 → 4 → 8 → 16倍、反対方向は1倍から、Kで停止します。正逆どちらも音声を再生し、Kの後にLで現在位置から順方向1倍に戻ります。シャトル速度は書き出しへ反映しません。

自動字幕・YouTubeの投稿素材を作る

上部の「YouTube」から制作スタジオを開きます。AI機能の実行にはOpenAI APIキーが必要で、音声や入力内容を外部へ送信し、API利用料が発生します。

  1. API設定：キーを入力、または「.envから読み込む」で OPENAI_API_KEY のあるファイルを選びます。Windowsユーザー用に暗号化して保存し、プロジェクトには含めません。
  2. 日本語で文字起こし：編集済みタイムラインの音声を使います。固有名詞・専門用語をヒントに入力できます。会話が埋もれる場合はBGMをミュートして実行します。
  3. 字幕を確認：20〜30文字を目安に、句読点や発話の間で区切ります。原稿・開始秒・終了秒を修正でき、検索／置換、SRT／VTT保存に対応します。
  4. 字幕をタイムラインに適用：「日本語字幕」トラックへ追加します。再適用は以前の自動字幕を置き換え、通常のテキストは残します。Ctrl+Zで戻せます。
  5. タイトル・概要欄：タイトル3案、概要本文、チャプター、検索ワード10個、画像生成指示を作成します。内容を修正し、個別コピー・一括コピー・TXT保存できます。
  6. サムネイル：動画の参考画像と字幕・投稿文から、主役と見せ場を強調した画像を高品質で生成します。希望する見出しは任意で指定できます。横1536×864（16:9）、縦864×1536（9:16）に自動対応し、2MB未満のJPEGで保存します。

自動字幕は白い太字、影なし、青 #0064FF・4pxの縁取り、背景不透明度25%が初期値。横型は下余白4%、縦型は8%に背景下端をそろえ、行数に合わせて文字を下部へ配置します。プロパティで文字サイズ、位置、背景の濃さを調整できます。

投稿文のコピーはタイトル3案の個別ボタン、チャプター付き概要欄、検索ワード、投稿素材一括の計6ボタンです。現在の編集内容をWindowsのクリップボードへ書き込み、成功または失敗を画面に表示します。検索ワードは10個のカンマ区切り。コピー後、貼り付け先で Ctrl + V を押してください。

チャプターは00:00開始・3項目以上・各10秒以上というアプリの検証条件を満たすと概要欄に付きます。タイトル・概要欄などを作成・保存する機能で、YouTubeへの自動投稿は行いません。

概要欄の末尾にハッシュタグを付ける

「YouTube → タイトル・概要欄 → 投稿文を生成」で、内容に合うハッシュタグ3個も生成します。「概要欄の末尾に付けるハッシュタグ」で編集でき、空白またはカンマ区切りで入力すると # を補います。空欄にすると付けません。検索ワード10個は別項目です。

「コピーされる概要欄」で、本文 → チャプター → ハッシュタグの順を確認できます。「概要欄をチャプター付きでコピー」「投稿素材を一括コピー」「テキスト保存」に反映します。短い動画などチャプター条件を満たさない場合も、タグは概要欄の最後に付きます。本文・チャプター・タグを合わせて5000文字以内です。以前の投稿文はそのまま開けます。タグを追加するには再生成するか、ハッシュタグ欄へ入力してください。

プロジェクトの保存・MP4の書き出し

Ctrl + S で保存、Ctrl + Shift + S で名前を付けて保存します。.luma は編集情報と素材の参照先を保存し、動画・画像・BGM本体を埋め込みません。素材を移動した場合は素材一覧から再リンクしてください。

編集が止まって約1.5秒後に自動保存します。次回起動時に復元の案内が出ますが、手動のプロジェクト保存とは別です。未保存で右上の×を押すと「編集を続ける」「保存せずに終了」「保存して終了」を選べます。保存のキャンセルや失敗では編集画面へ戻ります。

「書き出し」または Ctrl + E から、H.264映像＋AAC音声のMP4を作成します。横1920×1080、Shorts1080×1920、HD、4Kなどの設定に対応します。Shortsプリセットは縦型9:16・3分以内を確認し、長さを勝手に切り詰めません。

書き出し方式「自動」は利用できるGPUを検出します。MacのVideoToolbox、WindowsのNVIDIA NVENC・Intel Quick Sync・AMD AMF、CPUに対応し、自動設定でGPUが失敗した場合はCPUで再試行します。GPUは主にH.264圧縮を担当し、合成・音声処理はCPUも使用します。

進捗表示、中止、保存先を開く操作に対応します。新しい出力が完成するまで既存の出力は置き換えません。元の素材と同じ場所・ファイル名への書き出しはできません。

ヘルプとアップデート

ヘルプメニューから「初めての動画編集」「ショートカットキー一覧」「アップデート」を開けます。ショートカット一覧にはWindows / Macと修飾キーを切り替えられるキーボード図があります。

起動時にGitHubの最新安定版を確認し、対応する新しい配布版があると「更新あり」を表示します。「アップデート」から再確認とダウンロードページの表示ができます。自動でアプリを置き換える機能ではありません。編集を保存し、書き出しを終えてアプリを終了してから入れ替えてください。1.0.0からの初回更新は公式サイトから1.1.0を取得してください。

困ったとき

キーを押しても動かない／違うものが消えた

入力欄・ダイアログを閉じ、タイムラインのクリップやモニターをクリックしてから操作してください。Deleteはメディア一覧では素材、音量点では点、⋈では効果を削除します。Ctrl+Zで戻せます。日本語変換中の文字キーは編集操作に使いません。

再生ヘッドが見えなくなった

タイムライン上部の「再生ヘッドを表示」を押します。追従を続けるには「再生ヘッドの自動追従」をONにします。Vで空白をドラッグすると選択枠になるため、位置移動はルーラー・再生ヘッドをドラッグしてください。

映像をマウスで動かせない／拡大した映像を元に戻したい

Kで停止し、対象の素材が表示される時刻に移動します。トラックのロック・表示、素材の再リンクを確認してください。選択後モニターの見出しにある「位置・大きさを戻す」で中央・100%へ戻せます。

音が出ない／BGMが声より大きい

トラックのミュート・ソロ、クリップのミュート、基本音量、音量ラインの0%を確認します。「音声準備中」は準備の完了を待ちます。BGMを右クリックして−20 dBへ設定し、聴きながら微調整してください。

効果の再生が重い

プログラムモニターを1/2または1/4画質に下げます。Windowsのプレビューは動画デコードにCPUを使い、ページ効果にはGPUを利用します。書き出しのGPU設定とは別です。長時間4K・大量素材での一定フレームレートは保証していません。

字幕の誤字・時刻ずれ／APIエラー

固有名詞をヒントへ追加し、必要ならBGMをミュートして再実行します。本文と時刻の照合に大きな不一致がある場合は既存字幕を保持してエラーになります。401はキー、403はモデル利用権限、429は利用上限や残高を確認してください。

コピーした投稿文を貼り付けられない

コピーボタンの成功表示を確認し、貼り付け先の文字入力欄でCtrl+Vを押します。失敗表示の場合は再試行できます。TXT保存から内容を取り出す方法もあります。

プロジェクトを別のPCへ移したい

.lumaだけでなく、参照している動画・画像・BGMも一緒に保管・移動してください。素材の場所が変わった場合は再リンクします。APIキーはプロジェクトに含まれないため、別PCで設定してください。

対応範囲・開発用の確認

Windows用の日本語マルチトラック動画編集アプリです。編集と動画書き出しはローカルで処理し、AI機能の実行時はOpenAI APIへ送信します。追加フォントの初回取得にもインターネットを使います。

Premiere Proのプロジェクト読込、After Effects連携、外部プラグイン、マルチカム、位置・回転のキーフレーム、汎用グラフエディター、モーショントラッキング、人物の自動リフレーム、HDRの色管理は未実装です。音量ラインとテロップの不透明度キーフレームは実装済みです。

このガイドはv1.1.0の実装を基準としています。長時間4K・大量素材の耐久性能は未確認です。動画素材の長さ制限を外したことは、メモリやディスク使用量が無制限という意味ではありません。

ソースから起動する

Node.js 22.12以上を使い、リポジトリで次を実行します。

npm ci
npm run prepare:media
npm run prepare:bgm
npm run verify:demo
npm run build
npm start

開発用は npm run dev。ブラウザーの画面確認は npm run dev:web です。ネイティブのMP4出力などはWindows・Macアプリで利用します。

ガイドのコマンドとキー割り当ては npm run verify:readme で実装と照合できます。通常の検証は npm test、npm run build。操作仕様とレビュー記録は GitHubリポジトリで管理します。
