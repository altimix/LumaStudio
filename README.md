# Luma Studio

altimixが開発する、Windows・macOS向けの日本語動画編集ソフトです。
ソースコードをGPL-3.0-onlyで公開し、研究・教育・個人・商用で利用できます。

[公式サイト](https://lumastudio.altimix.jp/) · [ダウンロード](https://github.com/altimix/LumaStudio/releases/latest) · [操作ガイド](README.html) · [開発手順](docs/DEVELOPMENT.md) · [開発に参加](CONTRIBUTING.md)

## 1.8.0

- 動画・画像・文字・図形の位置、大きさ、回転、不透明度や見た目を共通キーフレームで編集。数値と色はなめらかに変化し、文章はクリップ全体で共通です。
- タイムラインの点を線で接続。左右ドラッグで時刻、上下ドラッグで選択した数値を変更でき、線のダブルクリックで点を追加できます。旧不透明度キーも同じ操作で扱えます。
- 素材中心の位置をシーケンスのピクセル座標で表示。数値欄のスライダーは必要なときに開けます。
- 文字色をスタイルの上へ配置し、縁取りなどと共通のカラーパレットに統一。数値ドラッグ、単位表示、タブのキーボード操作も揃えました。
- 図形の追加前に塗りつぶし・色・不透明度を設定でき、描画中の見本と中央への追加に反映します。
- 数値の編集を始めると再生が止まり、入力を始めた時刻のキーフレームや図形の追加位置を保ちます。保存・Undo / Redo・トラックロック・MP4出力に対応します。

## 1.7.0

- ベジェのShiftによる45度刻みの制限、Ctrl/Cmdによる一時的な点編集、Alt/Optionによる片側ハンドル操作。始点クリックや端点の結合でパスを閉じられます。
- 素材読込のファイル名・件数・処理段階と中止操作、基本設定の整理、プレビュー優先の画面配置。
- 映像を見ながら字幕を編集し、字幕間の移動や選択区間の反復再生ができます。
- 使用素材をまとめて保存し、別PCへ持ち運び。同名素材のフォルダから一括再リンクできます。
- プロジェクトごとに最大10世代のバックアップを保持し、選んで復元できます。
- 任意の軽量プロキシでプレビューの負荷を軽減。書き出しは原本を使用します。
- 編集メニューからよく使う操作を実行でき、キー表示はWindows / Macに合わせます。

## 1.6.0

- 動画・画像を上下左右からクロップし、長方形・楕円・ベジェのマスクで非破壊に切り抜けます。マスクの反転と境界ぼかしにも対応します。
- 「カラー → クロマキー」で背景色をスポイト採色し、色の許容範囲、境界のなめらかさ、緑・青の色かぶり除去を調整できます。キーマット表示で除去範囲も確認できます。
- プロパティの数値入力欄を左右へドラッグして値を変更できます。右で増加、左で減少し、1回の操作としてUndo / Redoできます。
- プロジェクトの保存・読込、素材の読込・再リンク中に表示するダイアログの文字、スピナー、余白を中央へ整えました。
- クロップ、マスク、クロマキーは保存・分割・複製・Undo / Redo・トラックロックに対応し、プレビューとMP4書き出しで同じ処理を使用します。

## 1.5.0

- エフェクトを「切り替え・色調・音声」に分類し、見本から選べる配置に整理。
- テキストは小さな見本カード、図形は基本設定と折りたたみ式の効果音、BGMは曲ごとの試聴と追加操作に整理。
- タイムラインの効果帯の両端をドラッグして、長さを1フレーム単位で調整。数値欄と連動し、Undo/Redo・Esc取消に対応します。
- カット位置・動画全体の長さを保ち、リンク音声・ロック・保存再読込・旧形式のプロジェクトを保護します。

## 1.4.0

- 現在のコマをPNG / JPEGで指定フォルダへ保存。「プロジェクトの素材にも追加」は初期値オン。写真保存先と素材読み込み先を別々に記憶します。
- 素材の読み込みと黒い背景の作成を「追加」メニューに集約。
- 左右パネルの幅変更・折りたたみとタイムラインの高さを記憶。「ウィンドウ」から初期配置へ戻せます。
- 補助文字を読みやすくし、テキスト追加への入口を左の「テキスト」タブへ整理。

## これまでの主な機能・修正

- Mac版の不完全な署名を修正。配布ZIPの署名とリソースの整合性を検証します（Developer ID署名・公証は未対応）。

- 長い音声を自動で区切り、時刻が合わない区間だけ細分化して再認識。短い区間でも一致しない場合は実測時刻付きの本文を採用します。
- 中央から上へVideo1、Video2…、下へAudio1、Audio2…と番号順に表示。どの段でも映像・音声・画像・テロップを配置・編集できます。
- テキスト編集を遮るガイド表示を廃止。ダブルクリックですぐ入力し、欄外クリックで確定できます。

- カット境界と図形の重ね合わせで映像が黒くなる問題、音声のつなぎ目のノイズを修正。
- 動画の代表フレーム・字幕などを使うサムネイル生成。横16:9・縦9:16を編集から自動選択し、2MB未満のJPEGで保存。

- Windows x64 / macOS Apple Silicon（M1以降）に対応。
- 素材・タイムラインは空で起動。BGMタブから初期BGM5曲を試聴・追加できます。
- 動画・画像・音声の読込、複数トラック、分割・トリミング、Undo/Redo。
- 日本語テロップ、トランジション、描画、タイムライン上の音量調整、MP4書き出し。
- MacのVideoToolbox、WindowsのNVENC・Quick Sync・AMFに対応。利用できる方式はGPU・ドライバーによって異なり、自動選択では利用可能なGPUを優先します。
- 単一無加工映像などで不要な合成を省き、書き出し処理を軽量化。
- ヘルプのキーボード図と、起動時の更新確認・ダウンロードと手動入れ替えの案内。
- プロジェクト保存、自動保存からの明示的な復元。
- AI字幕・投稿素材の生成は利用者自身のAPI設定が必要です。

## インストール

Releasesから自分のOS用のファイルを取得してください。Node.jsやFFmpegを
別途インストールする必要はありません。

Windows: EXEを開きます。署名されていないため警告が表示される場合があります。
Mac: ZIPを解凍し、Luma Studio.appを「アプリケーション」へ移動します。
Developer ID署名・公証は未対応です。初回の開発元確認で止まる場合は、
同梱の起動説明書を参照してください。Intel Mac・Linux用の配布版はありません。
