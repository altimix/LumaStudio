Luma Studio 1.10.1 — Mac公開版

対応するMac
・Apple Silicon搭載Mac（M1以降）。Intel Macには対応していません。
・アプリの最低OS設定はmacOS 13です。すべてのmacOSバージョンで検証済みという意味ではありません。
・Node.jsやFFmpegを別途インストールする必要はありません。

インストールと初回起動
1. Luma-Studio-1.10.1-macOS-arm64.zipを解凍します。
2. Luma Studio.appを「アプリケーション」フォルダへ移動します。
3. Luma Studio.appを開きます。
4. 開発元を確認できない旨の警告で起動できない場合は、警告を閉じます。
5. 「システム設定」→「プライバシーとセキュリティ」を開きます。
6. Luma Studioの案内にある「このまま開く」を選び、画面の指示に従って認証します。
7. 再度確認が出た場合は、開くことを確認します。

この版はDeveloper ID署名・Appleの公証を受けていません。
アプリ全体と同梱実行コードには整合性確認用のad-hoc署名を付け、配布ZIPを解凍した状態で署名を検証しています。これは開発元の認証やAppleの公証ではありません。
上の例外許可は、配布元とファイルを信頼できる場合に行ってください。
「このまま開く」は、起動を試してから約1時間以内に表示されます。
「コンピュータに損害を与える」「破損している」など別の警告の場合や、会社等が管理するMacで許可できない場合は、操作を進めず警告文を配布元にお知らせください。
Mac全体のセキュリティ設定を無効にする必要はありません。

Appleの公式案内
https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac

基本操作
・画面にあるCtrl系ショートカットはMacではCommand（⌘）でも操作できます。
・保存はCommand+S、元に戻すはCommand+Zです。
・Windowsから移したプロジェクトは、素材もコピーして再リンクしてください。
・追加フォントの初回取得やAI機能にはインターネット接続が必要です。
・AI機能には別途API設定が必要です。

検証状況
開発に使用したApple Silicon Macで、編集・保存・再生・日本語字幕・MP4出力を確認済みです。
別のMacでのダウンロード後の初回起動は未検証です。


配布ファイルの確認
同封のSHA256SUMS.txtにZIPのSHA-256を記載しています。
不具合の連絡時は、Macの機種、macOSのバージョン、操作内容、警告文をお知らせください。

この版は素材・クリップ・マーカーが空の状態で起動します。動画・画像・音声を「読み込み」から追加してください。旧版の初期素材は同梱していません。保存済みプロジェクトは「開く」、自動保存は「復元する」で利用できます。

初期BGM: bgm001.mp3〜bgm005.mp3の5曲を同梱しています。BGMライブラリから試聴・追加できます。素材とタイムラインには自動配置されません。

1.8.0の追加: 動画・画像・文字・図形の見た目を共通キーフレームで編集できます。タイムラインの点と線で時刻と値を調整し、数値と色はなめらかに変化します。文章はクリップ全体で共通です。素材中心の位置をピクセル表示にし、スライダーを折りたたみました。数値入力・色選択・タブ操作を揃え、図形を追加する前の塗りつぶし・色・不透明度の設定を追加しました。

1.7.0の追加: ベジェのShiftによる角度制限、Ctrl/Cmdによる一時的な点編集、Alt/Optionによる片側ハンドル操作と、始点クリック・端点結合に対応しました。素材読込の進捗と中止、基本設定とプレビュー優先配置、映像を見ながらの字幕編集、素材収集と一括再リンク、10世代のバックアップ、任意の軽量プロキシ、編集メニューとOS別キー表示を追加しました。

1.5.0の追加: エフェクト・テキスト・図形・BGMの一覧と設定を整理しました。タイムラインの紫色の効果帯は、両端をドラッグして長さを調整できます。数値欄と連動し、Undo/Redo・Esc取消に対応します。カット位置や動画全体の長さを保ち、リンク音声も同じ長さに調整します。

1.4.0の追加: 現在のコマをPNG / JPEGで指定フォルダへ保存できます。「プロジェクトの素材にも追加」は初期値オン。写真保存先と素材読み込み先を別々に記憶します。素材の「追加」メニュー、左右パネルの幅変更・折りたたみ、タイムラインの高さの記憶、補助文字の読みやすさ、テキスト追加への入口も改善しました。

1.3.1の修正: アプリ全体のad-hoc署名と配布ZIPの整合性検証を追加し、1.3.0で署名が不完全だった問題に対応しました。

1.3.0から利用できる機能: 中央から上へVideo1、Video2…、下へAudio1、Audio2…と番号順に表示。すべての段で映像・音声・画像・テロップを配置・編集できます。テキスト編集のガイド表示を廃止し、ダブルクリックですぐ入力できます。カット・図形を重ねた映像の黒化と音声の境界ノイズを修正。動画の内容に沿ったサムネイルを横16:9・縦9:16で生成し、2MB未満のJPEGで保存できます。GPU書き出し・ヘルプ・更新確認も利用できます。更新は案内に従ってダウンロード・手動で入れ替えます。
公式サイト: https://lumastudio.altimix.jp/

1.9.0の追加: GPT Image 2.5によるサムネイル作成で、人物・商品などの参考画像を任意で1枚選べます。画像なしでも生成でき、選択画像はプロジェクトに保存されます。キーフレームの時刻ずれを修正し、ラインが示す数値欄を黄緑の枠で表示します。クロップ・マスク・スポイトはEscで終了できます。

1.10.0の追加: 動画・画像に角ばったモザイクと別エフェクトのガウスぼかしを適用し、それぞれの範囲、モザイクの粒の大きさ、ガウスぼかしの強さを数値やモニター操作で指定できます。モザイクの粒の境界はぼかされません。プレビュー、写真保存、MP4書き出しに反映されます。YouTube投稿文の生成ではGPT-6 AstraとGPT-6 Solを選べます。文字起こしのモデルは変更していません。

1.10.1の改善: モザイクとガウスぼかしの中心 X・Y、幅・高さ、粗さ／強さの数値欄を左右にドラッグして調整できます。直接入力とUndo / Redoも使えます。
